# МОНОГРАФИЯ METACOD · Углублённый разбор · Гематология

## ТРОМБОФИЛИИ И ВЕНОЗНАЯ ТРОМБОЭМБОЛИЯ (ВТЭ) — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика, лечение и профилактика венозной
тромбоэмболии и тромбофилий: здесь реальная помощь. Поверх — фильтры METACOD (двигатель, мембрана,
маркёр, граница). Связь с Томом 2, гл. 4 (свёртывание) и разбором «ТЭЛА». Данные сверены (ASH/ESC и
рекомендации по ВТЭ, июнь 2026; сверять локально). Препарат, доза, решение — лечащий врач.

> Прикладной разбор болезни для направления 1 (гематология). Связан с: `metacod-tom1.md` (Т1.1),
> `metacod-tom2.md` (гл. 4 свёртывание), `metacod-pulmonary-embolism.md`, `metacod-sle.md`,
> `metacod-glomerular.md`, `metacod-atrial-fibrillation.md`, `metacod-thrombocytopenia-hemostasis.md`.

## 1. Что это в системе: кровь сворачивается там, где не нужно
Венозная тромбоэмболия (ВТЭ) — тромб в венозной системе: **тромбоз глубоких вен (ТГВ**, чаще ноги)
и/или его осложнение — **ТЭЛА** (`metacod-pulmonary-embolism.md`). Это **сторона тромбоза** двигателя
**Свёртывание (Т2.4):** баланс смещён к избыточному свёртыванию. **Триада Вирхова** — механизм
METACOD здесь: застой (Влажность-клиренс — иммобилизация), повреждение стенки, гиперкоагуляция
(тромбофилия/состояние). Мембранно/энергетически — патологический сгусток в потоке.

**Тромбофилия** — повышенная склонность к тромбозам (наследственная или приобретённая),
объясняющая часть ВТЭ, особенно ранних/рецидивирующих/необычной локализации.

## 2. Маркёр: диагностика ВТЭ
- **ТГВ:** претестовая вероятность (шкала Wells для ТГВ) → **D-димер** (нормальный при низкой
  вероятности исключает) → **компрессионное УЗИ вен**;
- **ТЭЛА:** см. `metacod-pulmonary-embolism.md` (Wells/PERC → D-димер → КТ-ангиопульмонография);
- **оценка провокации:** спровоцированная (операция, травма, иммобилизация, эстрогены,
  беременность, рак — преходящий vs стойкий фактор) vs неспровоцированная — определяет длительность
  лечения и нужду в поиске причины.

## 3. Тромбофилии (когда искать и какие)
- **наследственные:** фактор V Лейден, мутация протромбина G20210A, дефициты антитромбина/
  протеина C/протеина S;
- **приобретённые:** **антифосфолипидный синдром** (связь с СКВ — `metacod-sle.md`; тромбозы +
  потери беременности + антитела), рак (Т1.1 — паранеопластическая гиперкоагуляция), нефротический
  синдром (`metacod-glomerular.md`), миелопролиферативные, пароксизмальная ночная гемоглобинурия,
  эстрогены/беременность;
- ⚠️ **тестирование на тромбофилию — избирательно (не всем!):** результат редко меняет тактику при
  явно спровоцированном эпизоде; время тестирования (не в острую фазу/на антикоагулянте искажает);
  обсуждать целесообразность. Антифосфолипидный синдром искать активнее (меняет лечение).

## 4. Вектор: лечение и профилактика
- **Антикоагуляция — основа лечения ВТЭ:**
- **DOAC** (апиксабан/ривароксабан и др.) — предпочтительны для большинства;
- **НМГ** — беременность, рак (хотя DOAC всё чаще при раке без ЖКТ-опухоли); **НФГ** — при тяжёлой
  почечной недостаточности/нестабильности;
- ⚠️ **антифосфолипидный синдром (тройная позитивность) — варфарин, не DOAC** (DOAC хуже в этой
  группе);
- **длительность:**
  - спровоцированная преходящим фактором → ~3 месяца;
  - неспровоцированная/рак/стойкий фактор/рецидив → продлённая (взвешивая риск кровотечения);
- **массивная ТЭЛА (шок) → тромболизис/эмболэктомия** (`metacod-pulmonary-embolism.md`);
- **профилактика ВТЭ** — ключевая часть стационара/хирургии: оценка риска, механическая (компрессия)
  и/или фармакологическая профилактика по риску тромбоза vs кровотечения;
- **поиск причины:** при неспровоцированной — онконастороженность (Т1.1) по возрасту/симптомам.

**На языке мембраны (рамка):** ВТЭ = сторона тромбоза двигателя Свёртывание (Т2.4): баланс смещён к
сгустку (триада Вирхова — застой/стенка/гиперкоагуляция). Вектор — остановить и не дать нарастать
сгустку (антикоагуляция), при шоке — растворить/удалить, и профилактика у групп риска.

## 5. Граница (НЕОТЛОЖНОЕ)
- **Массивная ТЭЛА с шоком** (`metacod-pulmonary-embolism.md`) → реперфузия немедленно;
- **обширный/угрожающий конечности ТГВ** (флегмазия) → срочно;
- **тромбоз необычной локализации** (церебральные вены, мезентериальные, портальные) → срочно +
  искать причину (миелопролиферативное, ПНГ, антифосфолипидный);
- ⚠️ баланс с кровотечением: при активном кровотечении/высоком риске — взвешивать антикоагуляцию,
  кава-фильтр как опция.

## 6. Перекрёстки
- **ТЭЛА:** лёгочное осложнение ВТЭ — единый процесс.
- **Свёртывание (Т2.4):** механизм; противоположная сторона — кровоточивость (гемостаз).
- **СКВ/антифосфолипидный:** тромбозы + варфарин (не DOAC).
- **Онкология (Т1.1):** рак — фактор риска; неспровоцированная ВТЭ → онкопоиск.
- **Нефротический синдром, ФП:** другие протромботические/эмболические состояния.

## 7. Карманная версия
1. ВТЭ = **тромб в венах** (ТГВ ± ТЭЛА), сторона тромбоза Свёртывания (Т2.4); механизм — **триада
   Вирхова** (застой/стенка/гиперкоагуляция).
2. Маркёр: ТГВ — Wells → D-димер → УЗИ вен; ТЭЛА — см. разбор «ТЭЛА»; определить спровоцированность
   (преходящий vs стойкий фактор).
3. **Тромбофилии — избирательно тестировать;** антифосфолипидный синдром искать активнее (меняет
   лечение).
4. Вектор: **антикоагуляция** (DOAC — большинство; НМГ — беременность/рак; **варфарин при
   антифосфолипидном**); длительность — 3 мес (спровоцированная преходяще) или продлённая
   (неспровоцированная/рак/рецидив); профилактика ВТЭ в стационаре/хирургии.
5. Граница: массивная ТЭЛА (реперфузия), флегмазия, тромбоз необычной локализации; баланс с
   кровотечением.
6. Мембрана/энергия: патологический сгусток в потоке; вектор = остановить + профилактика. Решение,
   препарат, доза — лечащий врач.

> Диагностика ВТЭ (Wells/D-димер/УЗИ; ТЭЛА — отдельный разбор), избирательное тестирование на
> тромбофилию, антикоагуляция (DOAC; варфарин при антифосфолипидном), длительность по провокации,
> профилактика ВТЭ — доказательная медицина (ASH/ESC и рекомендации, сверено июнь 2026; сверять
> локально). Двигатель Свёртывание (Т2.4), энергии — рамка-навигатор METACOD, не основание для
> назначения. Вектор = направление + класс; препарат, доза и решение — за лечащим врачом.
