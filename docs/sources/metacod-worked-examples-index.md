# МОНОГРАФИЯ METACOD · Углублённые разборы · СВОДНЫЙ УКАЗАТЕЛЬ

## Сводный указатель компендиума (карта 60 разборов, неотложности, индекс по двигателям, перекрёстки)

**Как пользоваться.** Это навигатор по всем 60 разборам книги. Четыре части: (1) **карта разборов**
(болезнь → двигатель → мембрана/энергия → красные флаги), (2) **все неотложности** в одном месте,
(3) **обратный индекс по двигателям METACOD**, (4) **карта перекрёстков и кластеров**. Пороги и
схемы — в самих разборах (доказательный стержень); здесь — быстрая навигация. Везде: рамка
METACOD — навигатор, решение/препарат/доза — за врачом.

> Сквозной навигатор по 12 системам / 60 worked examples (направление 1). Точка маршрутизации в
> программе. Сами разборы — в `docs/sources/metacod-*.md`; фундамент-трилогия —
> `metacod-index.md`. Связан со всеми разборами компендиума.

## 2. Все неотложности в одном месте (распознать → действие)

**Сердечно-сосудистые/сосудистые**
- ОКС/STEMI → реперфузия (PPCI), ОКС-разбор.
- Массивная ТЭЛА (шок) → тромболизис/эмболэктомия; ТЭЛА-разбор.
- Инсульт → КТ (тип!), глюкоза сразу, тромболизис ≤4,5 ч / тромбэктомия ≤24 ч; Инсульт-разбор.
- Расслоение аорты (маска «колики»/боли) → Том 3.
- Злокачественная гипертензия; острая СН/отёк лёгких.

**Инфекционные**
- Сепсис/септический шок → hour-1 bundle, антибиотик ≤1 ч; Сепсис-разбор.
- Бактериальный менингит → антибиотик немедленно (не ждать ЛП/КТ) ± дексаметазон.
- Некротизирующий фасциит → немедленная хирургия + широкий спектр.
- Обструктивный пиелонефрит (камень+лихорадка) → декомпрессия.
- Холангит (Шарко) → ERCP ≤24 ч; Желчные-разбор.

**Метаболические/электролитные**
- Тяжёлая гиперкалиемия (ЭКГ) → кальций + инсулин-глюкоза + выведение.
- ДКА/гиперосмолярное; тяжёлая гипогликемия.
- Гиперкальциемический криз → регидратация + бисфосфонат.
- Кризы надпочечников/щитовидной (аддисонический, тиреотоксический, микседема-кома).
- Синдром лизиса опухоли → гидратация/расбуриказа/электролиты.

**Гематологические/онкологические**
- TTP (шистоциты+тромбоцитопения) → плазмаобмен (не тромбоциты!).
- HIT → отменить гепарин → негепариновый антикоагулянт.
- Фебрильная нейтропения → антибиотик ≤1 ч.
- Компрессия спинного мозга → МРТ + стероиды + лучевая/хирургия немедленно.
- Синдром верхней полой вены; гипервязкость → плазмаобмен.
- Иммунотерапия: миокардит/тяжёлый пневмонит/неврология → приостановить + стероиды.

**Неврологические/психиатрические**
- Эпилептический статус ≥5 мин → бензодиазепин + эскалация.
- Громоподобная головная боль → САК (КТ/ЛП); менингизм → менингит; новая>50+↑СОЭ → ГКА
  (стероиды, риск слепоты).
- Гийен-Барре → следить за дыханием; ВВИГ/плазмаобмен.
- Суицидальный риск → безопасность, не оставлять одного, срочная специализированная помощь.
- Серотониновый синдром (гиперрефлексия/клонус) vs ЗНС (ригидность); опиоидная передозировка →
  налоксон; delirium tremens; Вернике → тиамин.

**Ревматологические/нефрологические**
- ГКА с угрозой зрения → стероиды немедленно (до биопсии).
- Лёгочно-почечный синдром / быстропрогрессирующий ГН → индукция ± плазмаобмен.
- Септический артрит (горячий моносустав) → пункция, исключить инфекцию.
- Диализ A-E-I-O-U (ОПП-разбор).

**Гериатрические**
- Перелом шейки бедра; субдуральная гематома (особенно на антикоагулянте); острая задержка мочи;
  острый функциональный обвал → искать причину.

## 3. Обратный индекс по двигателям METACOD
- **Т1.1–1.3 (деление/рак/фиброз/гиперплазия):** онкология (все), лейкозы, лимфомы/миелома;
  фиброзный полюс (Т1.2, M-S) — печень, ХБП, ИЗЛ, ХОБЛ-ремоделирование, ВЗК (Крон).
- **Т1.4 (Ветер-нервы):** эпилепсия, астма (бронхоспазм), нейропатии/проводимость, тревога/делирий
  (дисрегуляция), фибрилляция (ритм).
- **Т1.7 (Влажность-обмен):** диабет, GLP-1/вес, дислипидемия, подагра, кластер.
- **Т1.8 (Сухость-иммунитет):** РА, СКВ, спондилоартриты, васкулиты, ВЗК, гломерулярные болезни, РС.
- **Т1.9 (Сухость-атрофия):** остеопороз, анемии (эритропоэз), нейродегенеративные, хрупкость/
  саркопения.
- **Т1.10 (Тепло/воспаление, инфекция):** сепсис, пневмония, ИМП, кожа/мягкие ткани, эндокардит/
  менингит, панкреатит, ГЭРБ/язва.
- **Т1.12 (Атеросклероз/сосуд):** гипертония, ИБС, ОКС, инсульт, кластер, СН.
- **Т2.4 (Свёртывание):** ТЭЛА, тромбофилии/ВТЭ, тромбоцитопении/гемостаз, ОКС, ФП (эмболия),
  инсульт.
- **M-S (склеротический/фиброзный полюс мембраны):** печень-цирроз, ХБП, ИЗЛ/ИЛФ, ХОБЛ, Крон.
  ⚠️ «рассеянный склероз ЦНС» (РС) — **не** этот фиброзный M-S.

## 4. Карта перекрёстков и кластеров
- **Кардио-ренально-метаболический кластер:** Диабет ↔ ХБП ↔ Гипертония ↔ СН ↔ Дислипидемия ↔
  ожирение/GLP-1; общие 4 столпа (РААС + SGLT-2 + GLP-1 + финеренон); опасности — Triple Whammy,
  гиперкалиемия. (Разбор «Кластер».)
- **Свёртывание (Т2.4) как ось:** ТЭЛА ↔ Тромбофилии/ВТЭ ↔ ОКС ↔ ФП ↔ Инсульт ↔ нефротический
  синдром; противоположный полюс — кровоточивость (Гемостаз).
- **Фиброз (Т1.2, M-S) как сквозной исход:** печень, почка, лёгкое, кишка — один механизм
  рубцевания в разных органах.
- **Инфекция (узел Том 2 гл. 8):** Сепсис в центре; очаги — пневмония, ИМП, кожа, эндокардит/
  менингит, холангит, фебрильная нейтропения; принцип — Антибиотикотерапия/стюардшип.
- **Снять маску = онконастороженность:** Рак как маска/CUP ↔ Анемии (железодефицит→ЖКТ) ↔ Желчные
  (безболевая желтуха) ↔ Головные боли (red flags) ↔ Тромбофилии (необъяснённая ВТЭ) ↔ Кальций/
  SIADH (паранеопластика) ↔ потеря веса (Том 3).
- **Гериатрический узел:** Хрупкость ↔ Полипрагмазия ↔ Падения ↔ Делирий ↔ Гериатрические
  синдромы ↔ Цели лечения; общий принцип — резерв, мультифакторность, соразмерность.
- **Лекарственные ловушки:** НПВС (Triple Whammy, ЖКТ, почки), антихолинергические/бензодиазепины
  (делирий, падения), стероиды (кость, надпочечники, диабет), серотонинергические (серотониновый
  синдром), антипсихотики (ЗНС, тельца Леви).
- **Электролиты/КЩР (Том 2 гл. 5, 6):** перекрёсток ХБП, ОПП, надпочечников, кальция, лизиса
  опухоли, сепсиса; pH крови 7,35–7,45 — инвариант.

> Указатель — навигатор по разборам; пороги, схемы и дозы — в самих главах (доказательный стержень,
> сверено 2024–2026). Двигатели Тx.y, мембраны (M-S), энергии — рамка-навигатор METACOD, не
> основание для назначения. Вектор = направление + класс; препарат, доза и решение по конкретному
> человеку — за лечащим врачом.
