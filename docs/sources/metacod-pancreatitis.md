## ПАНКРЕАТИТ — острый и хронический через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение панкреатита: здесь реальная помощь,

## 1. Что это в системе: железа переваривает сама себя
**Острый панкреатит** — самопереваривание поджелудочной: ферменты активируются внутри железы →
воспаление, отёк, в тяжёлых случаях некроз и системный воспалительный ответ (SIRS, органная
недостаточность). Двигатель — **Тепло/воспаление (Т1.10)** в железе с потенциальным системным
выходом; мембранно (рамка) — острое катаболическое разрушение ткани. **Хронический панкреатит** —
повторное/длительное воспаление → фиброз (Т1.2, **M-S**) → утрата экзо- и эндокринной функции.

**Главный фильтр (маска):** боль в эпигастрии с иррадиацией в спину + рвота — но снять маску:
перфорация язвы, мезентериальная ишемия, расслоение аорты, ОКС нижней стенки, кишечная
непроходимость (Том 3, гл. 8).

## 2. ОСТРЫЙ ПАНКРЕАТИТ
### 2.1. Диагноз (2 из 3)
характерная боль (эпигастрий → спина); **липаза (или амилаза) >3× верхней границы**; характерная
визуализация (КТ/УЗИ/МРТ). Двух из трёх достаточно.

### 2.2. Причины (снять маску — определяет лечение)
- **Желчные камни и алкоголь** — две главные;
- **гипертриглицеридемия** (особенно >1000 мг/дл / >11,3 ммоль/л);
- гиперкальциемия, лекарства, после-ЭРХПГ, аутоиммунный;
- ⚠️ **>40 лет без причины → исключить опухоль поджелудочной** (визуализация в течение ~3 мес;
  связь с потерей веса, Том 3 гл. 5).

### 2.3. Оценка тяжести
Большинство (~80%) — лёгкие; ~20% — тяжёлые (некроз, органная недостаточность, ~20% летальность).
Следить за SIRS/органной дисфункцией, мочевиной (BUN), гематокритом; КТ с контрастом для некроза —
обычно отсроченно (не в первые часы).

### 2.4. Вектор (современная парадигма — ACG/AGA 2024)
- **Инфузия — умеренная, целенаправленная (НЕ агрессивная):** Рингер-лактат предпочтительнее
  физраствора; переоценивать каждые 6 ч первые 24–48 ч, цель — снизить мочевину;
- **раннее питание** (перорально/энтерально в 24–48 ч, как переносит) — не голодать долго, не
  парентеральное по умолчанию;
- обезболивание (опиоид/неопиоид по ситуации, Т2.7);
- ⚠️ **профилактические антибиотики НЕ показаны** (даже при некрозе/тяжёлом) — только при
  доказанной инфекции (инфицированный некроз, холангит, бактериемия);
- **ЭРХПГ — только при сопутствующем холангите (≤24 ч)** или стойкой билиарной обструкции; при
  подозрении на камень холедоха без холангита — сначала МРХПГ/эндоУЗИ, не диагностическая ЭРХПГ;
  ректальный индометацин — профилактика пост-ЭРХПГ-панкреатита у группы риска;
- **билиарный лёгкий панкреатит → холецистэктомия в ту же госпитализацию** (профилактика
  рецидива);
- **инфицированный некроз:** стабильный — антибиотик + отсроченное (>4 нед) минимально инвазивное
  дренирование/некрэктомия (дать сформироваться стенке); нестабильный — раньше;
- гипертриглицеридемический — снижать ТГ; алкогольный — отказ от алкоголя.

### 2.5. На языке мембраны (рамка)
Острый панкреатит = острое Тепло/катаболизм железы; вектор — поддержать (умеренная инфузия,
питание, обезболивание), убрать причину (камень/ТГ/алкоголь), **не вредить** (не гипергидратация,
не лишние антибиотики, не лишняя ЭРХПГ).

## 3. ХРОНИЧЕСКИЙ ПАНКРЕАТИТ (фиброзный исход)
- **Суть:** повторное воспаление → фиброз (M-S) → боль + недостаточность: экзокринная
  (мальабсорбция, стеаторея) и эндокринная (**панкреатогенный диабет, тип 3c** — связь с Т1.7);
- **причины:** алкоголь (главная), генетические, обструктивные, аутоиммунный;
- **вектор:** отказ от алкоголя/курения; боль (мультидисциплинарно, Т2.7); **ферментозамещение
  (липаза)** при экзокринной недостаточности + жирорастворимые витамины; лечение диабета 3c;
  эндоскопия/хирургия при обструкции/камнях; ⚠️ повышенный риск рака поджелудочной (Т1.1).

## 4. Граница (НЕОТЛОЖНОЕ)
- **Тяжёлый острый панкреатит** (органная недостаточность, некроз, SIRS) → ОРИТ;
- **Сопутствующий холангит** (триада Шарко, Том 3 гл. 11) → ЭРХПГ ≤24 ч + антибиотики;
- **Инфицированный некроз с нестабильностью** → срочное вмешательство;
- Снять опасные маски острого живота (перфорация, ишемия — Том 3 гл. 8).

## 5. Перекрёстки
- **Желчные:** камни — ведущая причина; холецистэктомия после лёгкого билиарного.
- **Дислипидемия:** очень высокие ТГ (≥1000) — причина и мишень профилактики.
- **Кальций:** гиперкальциемия как причина.
- **Обмен/диабет (Т1.7):** панкреатогенный диабет 3c при хроническом.
- **Онкология (Т1.1):** опухоль как причина (>40 лет без причины) и риск при хроническом.

## 6. Карманная версия
1. Острый = самопереваривание (Тепло Т1.10); диагноз **2 из 3** (боль / липаза >3× / визуализация);
   снять маску острого живота.
2. **Причина определяет лечение:** камни, алкоголь, ТГ >1000, кальций, лекарства; >40 без причины
   → исключить опухоль.
3. **Вектор (2024):** умеренная инфузия Рингер-лактатом, раннее питание, обезболивание; **без
   профилактических антибиотиков; ЭРХПГ только при холангите (≤24 ч)**; холецистэктомия в ту же
   госпитализацию при лёгком билиарном.
4. Хронический: фиброз (M-S) → боль + экзо/эндокринная недостаточность (ферменты, диабет 3c);
   алкоголь — отказ; риск рака.
5. Граница: тяжёлый панкреатит/некроз/холангит → неотложно.
6. Мембрана/энергия: острое Тепло → фиброз M-S; вектор = поддержать + убрать причину + не
   навредить. Решение, препарат, доза — лечащий врач.

> Диагноз 2 из 3, умеренная инфузия (Рингер-лактат), раннее питание, отказ от профилактических
> антибиотиков, ЭРХПГ только при холангите, холецистэктомия при лёгком билиарном — доказательная
> медицина (ACG 2024, AGA 2024, сверено июнь 2026; сверять локально). Двигатели Тепло/Фиброз,
> мембрана M-S, энергии — рамка-навигатор METACOD, не основание для назначения. Вектор =
> направление + класс; препарат, доза и решение — за лечащим врачом.
