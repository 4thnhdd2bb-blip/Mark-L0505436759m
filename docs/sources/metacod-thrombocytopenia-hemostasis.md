# МОНОГРАФИЯ METACOD · Углублённый разбор · Гематология

## ТРОМБОЦИТОПЕНИИ И НАРУШЕНИЯ ГЕМОСТАЗА — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение тромбоцитопений и нарушений
свёртывания: здесь реальная помощь, часть из них — неотложности. Поверх — фильтры METACOD
(двигатель, мембрана, маркёр, граница). Темы связаны с Томом 2, гл. 4 (свёртывание). Данные сверены

## 1. Что это в системе: сломан баланс «остановить кровь ↔ не тромбировать»
Гемостаз — тонкий баланс между **остановкой кровотечения** (тромбоциты + факторы свёртывания) и
**сохранением жидкой крови**. Поломка в сторону кровоточивости (мало/плохие тромбоциты, дефицит
факторов) или в сторону тромбоза (`metacod-thrombophilia-vte.md`). Это прямое выражение двигателя
**Свёртывание (Т2.4)**. Здесь — преимущественно сторона **кровоточивости** и тромбоцитопении, плюс
смешанные состояния (DIC — и то, и другое сразу).

**Два типа кровоточивости (фильтр локализации дефекта):**
- **тромбоцитарный/сосудистый** (первичный гемостаз): петехии, пурпура, слизистые кровотечения
  (нос, дёсны), меноррагии — «поверхностные, точечные»;
- **факторный** (вторичный гемостаз, коагуляция): гематомы, гемартрозы, отсроченные глубокие
  кровотечения — «глубокие».

## 2. ТРОМБОЦИТОПЕНИИ
### 2.1. Три механизма
- **снижено производство** (костный мозг: лейкоз/миелодисплазия/инфильтрация, B12/фолат,
  лекарства, алкоголь — `metacod-leukemia.md`, `metacod-anemia.md`);
- **повышено разрушение/потребление** (иммунное — ITP; TTP/HUS — микроангиопатия; DIC; HIT —
  гепарин-индуцированная; лекарства; инфекции);
- **секвестрация** (спленомегалия — цирроз/портальная гипертензия, `metacod-liver-masld-cirrhosis.md`).

### 2.2. Маркёр (исключение и распознавание опасного)
- ⚠️ исключить **псевдотромбоцитопению** (агрегация в пробирке с ЭДТА — пересдать в цитрате);
- **мазок крови — ключ:** шистоциты → микроангиопатия (TTP/HUS/DIC — неотложно!); бласты → лейкоз;
  крупные/мелкие тромбоциты → наследственные;
- сопутствующие цитопении (панцитопения → костный мозг), гемолиз-панель (ЛДГ, гаптоглобин,
  билирубин), коагулограмма (для DIC), функция почек;
- **ITP — диагноз исключения** (изолированная тромбоцитопения без другой причины).

### 2.3. Векторы по причине
- **ITP:** лечить при кровоточивости/очень низких тромбоцитах — глюкокортикоиды (± IVIG при
  кровотечении/срочности), затем агонисты тромбопоэтиновых рецепторов/ритуксимаб/спленэктомия при
  хронической; не у всех нужна терапия (по счёту/кровоточивости);
- ⚠️ **TTP** (микроангиопатия + тромбоцитопения + неврология/почки, шистоциты, ↑ЛДГ) —
  **НЕОТЛОЖНО: плазмаобмен** (+ иммуносупрессия/каплацизумаб) — **НЕ переливать тромбоциты**
  (подкормит тромбоз!); смертельна без лечения;
- **HIT** (падение тромбоцитов на 5–10-й день гепарина + тромбозы): отменить гепарин, перейти на
  негепариновый антикоагулянт — ⚠️ парадокс: это **протромботическое** состояние;
- **DIC:** лечить причину (сепсис, акушерское, опухоль); поддержка компонентами по кровотечению/
  тромбозу;
- **секвестрация/продукция:** лечить основную болезнь.

## 3. НАРУШЕНИЯ КОАГУЛЯЦИИ (факторный гемостаз)
- **Наследственные:** **гемофилия** (дефицит фактора VIII/IX — гемартрозы, глубокие кровотечения;
  заместительная терапия факторами/новые агенты), **болезнь Виллебранда** (самое частое
  наследственное; слизистые кровотечения; десмопрессин/концентраты);
- **приобретённые:** дефицит витамина K (печень, антикоагулянты, мальабсорбция), болезнь печени
  (`metacod-liver-masld-cirrhosis.md` — сложный гемостаз), DIC, ингибиторы факторов;
- **маркёр:** ПВ/МНО и АЧТВ (какой путь удлинён), фибриноген, факторы; смешивающие пробы.

**На языке мембраны (рамка):** это **сторона кровоточивости** двигателя Свёртывание (Т2.4) — баланс
смещён от тромбоза к кровотечению (кроме TTP/HIT/DIC, где парадоксально сосуществуют тромбоз и
тромбоцитопения). Вектор — восстановить недостающее звено (тромбоциты/фактор/витамин K) ИЛИ
погасить разрушающий механизм (иммунный/микроангиопатический), убрав причину.

## 4. Граница (НЕОТЛОЖНОЕ)
- ⚠️ **TTP** (шистоциты + тромбоцитопения + неврология/почки) → немедленно плазмаобмен, не
  переливать тромбоциты;
- **HIT** → отменить гепарин, негепариновый антикоагулянт (тромботическая угроза);
- **DIC** с кровотечением/тромбозом + критическая причина (сепсис, акушерское) → неотложно;
- **тяжёлое кровотечение** (Том 2, гл. 4) при тромбоцитопении/коагулопатии → компоненты +
  остановка источника + реверс антикоагулянта;
- **панцитопения / бласты** → срочно гематолог.

## 5. Перекрёстки
- **Свёртывание (Т2.4) и Тромбофилии/ВТЭ:** другая сторона баланса; HIT/DIC/TTP — смешанные.
- **Печень:** цирроз — сложный гемостаз + секвестрация (спленомегалия).
- **Лейкозы:** костномозговая причина цитопений; промиелоцитарный лейкоз → DIC.
- **СКВ/антифосфолипидный:** тромбоцитопения + тромбозы.
- **Анемии:** микроангиопатия — общий мазок (шистоциты).

## 6. Карманная версия
1. Гемостаз — баланс **остановка↔текучесть**; здесь сторона кровоточивости + тромбоцитопении
   (двигатель Свёртывание Т2.4).
2. Тип кровоточивости: **тромбоцитарный/сосудистый** (петехии, слизистые) vs **факторный**
   (гематомы, гемартрозы).
3. Тромбоцитопения — 3 механизма (продукция/разрушение/секвестрация); **мазок — ключ** (шистоциты
   → TTP/HUS/DIC; бласты → лейкоз); исключить псевдотромбоцитопению; ITP — диагноз исключения.
4. ⚠️ **Неотложные: TTP** (плазмаобмен, НЕ тромбоциты), **HIT** (отменить гепарин → негепариновый
   антикоагулянт), **DIC** (лечить причину).
5. Коагуляция: гемофилия (факторы), болезнь Виллебранда (десмопрессин/концентраты), дефицит
   витамина K/печень; маркёр — ПВ/АЧТВ/фибриноген.
6. Граница: TTP, HIT, DIC, тяжёлое кровотечение, панцитопения/бласты → неотложно. Мембрана/энергия:
   сторона кровоточивости Свёртывания; вектор = восстановить звено / погасить разрушение. Решение,
   препарат, доза — лечащий врач/гематолог.

> Типы кровоточивости, механизмы тромбоцитопении, мазок (шистоциты/бласты), ITP как диагноз
> исключения, TTP = плазмаобмен (не тромбоциты), HIT-парадокс, гемофилия/болезнь Виллебранда —
> доказательная медицина (ASH и рекомендации, сверено июнь 2026; сверять локально). Двигатель
> Свёртывание (Т2.4), энергии — рамка-навигатор METACOD, не основание для назначения; острые
> состояния ведутся по протоколам. Вектор = направление + класс; препарат, доза и решение — за
> лечащим врачом/гематологом.
