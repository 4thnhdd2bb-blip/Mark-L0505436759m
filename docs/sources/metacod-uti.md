# МОНОГРАФИЯ METACOD · Углублённый разбор · Инфекционные болезни

## ИНФЕКЦИИ МОЧЕВЫВОДЯЩИХ ПУТЕЙ — цистит и пиелонефрит через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение инфекций мочевыводящих путей (ИМП):
здесь реальная помощь. Поверх — фильтры METACOD (двигатель, маска, маркёр, вектор, граница). Связь
с узлом «Инфекция» (Том 2, гл. 8). Данные сверены (IDSA/EAU и рекомендации, июнь 2026; сверять
локально). Препарат, доза, решение — лечащий врач.

## 1. Что это в системе: инфекция по ходу мочевого потока
ИМП — инфекция в мочевыводящем тракте; **тяжесть и подход определяются уровнем** (где инфекция) **и
наличием осложняющих факторов**. Двигатель — **Инфекция (Том 2, гл. 8) + Тепло (Т1.10)** при
воспалении; фундамент ПОТОК × ГРАНИЦА — застой/обструкция мочи (`metacod-nephrolithiasis.md`)
способствует.

**Главный разводящий фильтр:**
- **нижние (цистит)** — мочевой пузырь: дизурия, учащение, императивные позывы, без лихорадки/
  системности;
- **верхние (пиелонефрит)** — почка: + лихорадка, боль в боку, системные признаки — серьёзнее;
- **неосложнённые** (здоровая небеременная женщина, нормальный тракт) vs **осложнённые** (мужчины,
  беременность, катетер, обструкция/камень, диабет, иммуносупрессия, аномалии, почечная
  недостаточность) — определяют тактику и длительность.

**Главный фильтр (маска):** ⚠️ **бессимптомная бактериурия лечится НЕ всем** — только беременные и
перед урологическими вмешательствами (иначе — лишние антибиотики, резистентность); снять маску
дизурии (вагинит, уретрит/ИППП, простатит); у пожилых «спутанность» приписывают ИМП ошибочно —
нужны мочевые симптомы, не только мутная моча.

## 2. Маркёр: диагноз
- клиника + **анализ мочи** (лейкоцитурия, нитриты, бактериурия); **посев мочи** — при осложнённых/
  пиелонефрите/рецидивах/беременности (не нужен при типичном неосложнённом цистите);
- **пиелонефрит:** лихорадка + боль в боку/реберно-позвоночном углу + мочевые симптомы; оценить
  тяжесть/сепсис; визуализация (УЗИ/КТ) при тяжёлом/неответе/подозрении на обструкцию-камень/
  абсцесс;
- ⚠️ **камень + лихорадка = обструктивный пиелонефрит** (`metacod-nephrolithiasis.md`) —
  неотложность.

## 3. Вектор: лечение (по уровню/осложнённости, с учётом локальной резистентности)
- **Неосложнённый цистит:** короткий курс перорального антибиотика по локальным рекомендациям
  (нитрофурантоин, фосфомицин, триметоприм-сульфаметоксазол при низкой резистентности — выбор
  локальный); ⚠️ беречь фторхинолоны (резервировать);
- **Пиелонефрит (амбулаторный, нетяжёлый):** пероральный антибиотик с хорошим почечным
  проникновением по чувствительности/локальным данным, дольше;
- **Пиелонефрит тяжёлый / осложнённый / сепсис / рвота:** госпитализация, в/в антибиотик широкого
  спектра, ресусцитация (`metacod-sepsis.md`), затем деэскалация по посеву;
- **осложнённые/особые:** беременность (безопасные препараты, лечить и бессимптомную бактериурию),
  катетер-ассоциированные (по возможности убрать/сменить катетер), мужчины (думать о простате);
- ⚠️ **обструкция/камень с инфекцией → дренирование (стент/нефростома) + антибиотик** — неотложно
  (`metacod-nephrolithiasis.md`); абсцесс — дренирование;
- **рецидивирующие ИМП:** устранимые факторы, негормональные/поведенческие меры, по показаниям
  профилактика — без избыточных антибиотиков.

**На языке мембраны (рамка):** ИМП = инфекция по ходу мочевого потока (Инфекция + Тепло), хуже при
застое/обструкции. Вектор — подавить инфекцию по уровню/чувствительности + восстановить отток при
обструкции + **не лечить лишнего** (бессимптомную бактериурию).

## 4. Граница (НЕОТЛОЖНОЕ)
- **Обструктивный пиелонефрит** (камень + лихорадка/сепсис) → дренирование + антибиотик
  (`metacod-nephrolithiasis.md`; Том 2, гл. 8);
- **уросепсис** (ИМП + органная дисфункция) → протокол сепсиса (`metacod-sepsis.md`);
- **почечный/паранефральный абсцесс, эмфизематозный пиелонефрит** (диабет) → срочно;
- беременность с пиелонефритом → госпитализация (риск осложнений).

## 5. Перекрёстки
- **Сепсис:** уросепсис — частый источник.
- **Нефролитиаз:** обструкция + инфекция = неотложность.
- **Диабет:** тяжёлые/атипичные ИМП (эмфизематозный пиелонефрит).
- **Антибиотикотерапия:** стюардшип — не лечить бессимптомную бактериурию, беречь фторхинолоны,
  деэскалация.
- **ОПП:** при тяжёлом пиелонефрите/уросепсисе.

## 6. Карманная версия
1. ИМП — **по уровню и осложнённости:** цистит (нижние, без системности) vs пиелонефрит (почка,
   лихорадка/бок); неосложнённые vs осложнённые (мужчины, беременность, катетер, обструкция, диабет).
2. ⚠️ **Бессимптомную бактериурию лечить только при беременности/перед урологией;** снять маску
   дизурии (вагинит, ИППП, простатит).
3. Маркёр: анализ мочи; посев при осложнённых/пиелонефрите/беременности; визуализация при тяжёлом/
   обструкции.
4. Вектор: цистит — короткий пероральный курс (беречь фторхинолоны); пиелонефрит — дольше, тяжёлый/
   сепсис → в/в + ресусцитация → деэскалация; беременность/катетер/мужчины — особо.
5. ⚠️ **Граница:** обструктивный пиелонефрит (камень+лихорадка → дренирование), уросепсис, абсцесс,
   эмфизематозный пиелонефрит.
6. Мембрана/энергия: инфекция по мочевому потоку; вектор = подавить + восстановить отток + не
   лечить лишнего. Решение, препарат, доза — лечащий врач.

> Разведение по уровню/осложнённости, не лечить бессимптомную бактериурию (кроме беременности/
> урологии), посев при осложнённых, короткие курсы при цистите, обструктивный пиелонефрит =
> неотложная декомпрессия, стюардшип фторхинолонов — доказательная медицина (IDSA/EAU и
> рекомендации, сверено июнь 2026; сверять локально). Двигатели Инфекция/Тепло, энергии — рамка-
> навигатор METACOD, не основание для назначения. Вектор = направление + класс; препарат, доза и
> решение — за лечащим врачом.
