**Как читать.** Стержень — доказательная диагностика и лечение гломерулярных болезней: здесь

## 1. Что это в системе: повреждён сам фильтр (клубочек)
Клубочек — мембрана-сито потока: пропускает воду/шлаки, держит белок и клетки. Гломерулярные
болезни — повреждение этого сита. Двигатель чаще **иммунный (Сухость-иммунитет Т1.8 / Тепло-
воспаление Т1.10)**: отложение иммунных комплексов, антитела, комплемент. Исход без контроля —
**фиброз клубочка (Т1.2, M-S)** → ХБП. Мембранно (рамка) — прямое повреждение фильтрующей мембраны.

**Главная разводящая логика — два синдрома (по тому, что течёт через сито):**
- **Нефротический** — сито «дырявое» для белка: массивная протеинурия;
- **Нефритический** — сито «воспалено»: кровь + воспаление.

## 2. Два синдрома (снять маску — это и есть диагноз направления)
### 2.1. Нефротический синдром (потеря белка)
- **протеинурия >3,5 г/сут** + гипоальбуминемия + **отёки** + гиперлипидемия;
- осадок «мягкий» (без активного воспаления);
- ⚠️ **тромботический риск** (теряется антитромбин III) — венозные тромбозы, в т.ч. почечной вены;
- причины: болезнь минимальных изменений (дети), ФСГС, мембранозная нефропатия (анти-PLA2R),
  **диабетическая нефропатия** и амилоидоз (системные).

### 2.2. Нефритический синдром (воспаление, кровь)
- **гематурия (дисморфные эритроциты, эритроцитарные цилиндры)** + протеинурия (обычно <3,5) +
  гипертония + отёки + ↓eGFR;
- причины: постинфекционный ГН, IgA-нефропатия, люпус-нефрит, ANCA-васкулит, анти-БМК
  (Гудпасчер), мембранопролиферативный.

### 2.3. ⚠️ Быстропрогрессирующий ГН (БПГН) — НЕОТЛОЖНОЕ
Нефритический осадок + **падение функции за дни–недели** = подозрение на БПГН (полулуния).
Причины: ANCA-васкулит, анти-БМК, люпус. → **срочно биопсия + иммуносупрессия** (промедление =
необратимая утрата почки; при анти-БМК с лёгочным кровотечением — плазмаферез).

## 3. Маркёр
- **анализ мочи + осадок** (микроскопия!) — дисморфные эритроциты/эритроцитарные цилиндры =
  гломерулярное; протеинурия — количественно (ACR/суточная);
- **серология по картине:** ANA/анти-ДНК (люпус), ANCA (васкулит), анти-БМК, анти-PLA2R
  (мембранозная), комплемент C3/C4, серология гепатитов B/C, ВИЧ; СКФ/креатинин;
- **биопсия почки** — ключевой шаг для типа и тактики (кроме явных случаев — напр. типичная
  диабетическая нефропатия или минимальные изменения у ребёнка).

## 4. Вектор: лечение (две линии — поддержка + специфика)
**Линия 1 — нефропротекция (всем, фон):**
- **РААС-блокада (иАПФ/БРА)** — снижает протеинурию и давление;
- **SGLT-2** — при протеинурической ХБП (кардио-ренальная защита);
- контроль АД (<130/80), соль, отёки (диуретик), липиды (статин при нефротическом);
- ⚠️ **тромбопрофилактика** при тяжёлом нефротическом (низкий альбумин) — антикоагуляция по риску.

**Линия 2 — специфическая (по типу, после биопсии):**
- иммуносупрессия по гистологии: стероиды (минимальные изменения), стероид+цитостатик/ритуксимаб
  (мембранозная, люпус, васкулит);
- **БПГН/васкулит** — индукция (стероид + циклофосфамид/ритуксимаб) срочно ± плазмаферез;
- диабетическая нефропатия — вектор как ХБП/диабет (SGLT-2/РААС/финеренон/GLP-1, см. `metacod-ckd.md`);
- лечить причину при вторичных (инфекция, лекарство, гепатит).

**На языке мембраны (рамка):** повреждена сама фильтрующая мембрана клубочка иммунным двигателем;
вектор = снизить нагрузку на сито (РААС/SGLT-2/АД) + по типу приглушить иммунную атаку, **не дав
уйти в фиброз M-S**.

## 5. Граница (НЕОТЛОЖНОЕ)
- **Быстропрогрессирующий ГН** (нефритический + падение функции за дни–недели) → срочно биопсия +
  иммуносупрессия;
- **Лёгочно-почечный синдром** (кровохарканье + ОПП — Гудпасчер/ANCA) → плазмаферез + иммуносупрессия;
- **Тяжёлый нефротический** с тромбозом (почечной вены, ТЭЛА) / анасаркой → неотложно;
- осложнения: тяжёлая гиперкалиемия/перегрузка (показания к диализу — `metacod-aki.md`).

## 6. Перекрёстки
- **ОПП:** гломерулярное — одна из ренальных причин (эритроцитарные цилиндры — красный флаг).
- **ХБП:** гломерулярные болезни — частая причина прогрессирования к M-S.
- **Свёртывание (Т2.1/Т2.4):** нефротический = протромботическое состояние.
- **Диабет:** диабетическая нефропатия — самая частая гломерулярная причина ХБП.
- **Аутоиммунное (Т1.8):** люпус-нефрит, ANCA-васкулит — системные с почечной мишенью.
- **Отёк (Том 3, гл. 7):** нефротический отёк в дифдиагнозе с сердечным/печёночным.

## 7. Карманная версия
1. Гломерулярные = повреждён сам фильтр (клубочек, иммунный двигатель Т1.8/Т1.10); исход без
   контроля — фиброз M-S.
2. **Два синдрома:** нефротический (белок >3,5 г/сут + отёки + ↓альбумин + тромбориск) vs
   нефритический (гематурия с эритроцитарными цилиндрами + гипертония + ↓eGFR).
3. **Ключ — осадок мочи + серология + биопсия** (дисморфные эритроциты/цилиндры = гломерулярное).
4. **Вектор две линии:** фон всем — РААС + SGLT-2 + АД + (тромбопрофилактика при нефротическом);
   специфика по типу после биопсии — иммуносупрессия.
5. ⚠️ **БПГН (нефритический + падение за дни–недели) = неотложно:** биопсия + иммуносупрессия (±
   плазмаферез при анти-БМК/лёгочном кровотечении).
6. Мембрана/энергия: повреждена фильтрующая мембрана; вектор = разгрузить сито + приглушить
   иммунитет по типу. Решение, препарат, доза — лечащий врач/нефролог.

> Развилка нефротический/нефритический, осадок мочи + серология + биопсия, две линии (нефропротекция
> + иммуносупрессия по типу), БПГН как неотложность, тромбориск при нефротическом — доказательная
> медицина (KDIGO ГН 2024, сверено июнь 2026; сверять локально). Двигатели Сухость-иммунитет/Тепло/
> Фиброз, мембрана (повреждение фильтра → M-S), энергии — рамка-навигатор METACOD, не основание для
> назначения. Вектор = направление + класс; препарат, доза и решение — за лечащим врачом.
