# МОНОГРАФИЯ METACOD · Углублённый разбор · Нефрология

## ХРОНИЧЕСКАЯ БОЛЕЗНЬ ПОЧЕК (ХБП) — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение ХБП: здесь реальная помощь.
Поверх — фильтры METACOD (двигатель, мембрана, маска, маркёр, вектор, граница). Данные сверены
(KDIGO 2024, ADA 2025–2026, июнь 2026; сверять локально). Препарат, доза, решение — лечащий
врач/нефролог.

## 1. Что такое ХБП в системе: фильтр, который медленно зарастает
Почка — фильтр потока: очищает кровь, держит объём, электролиты, КЩР, давление, кость, кровь
(эритропоэтин). ХБП — постепенная необратимая утрата фильтрующей способности (≥3 мес).
Двигатель в основе — чаще **метаболически-сосудистый** (диабет Т1.7 + гипертония/атеросклероз
Т1.12 — две ведущие причины в мире) с исходом в **фиброз почечной ткани (Т1.2)**. Мембранно
(рамка) — путь к склеротическому полюсу (**M-S**): клубочек и интерстиций рубцуются. Поэтому
современный вектор — **затормозить фиброз/прогрессирование, а не только «снизить креатинин».**

**Ключ — ХБП тихая:** ранние стадии бессимптомны; находят по анализу. Скрининг групп риска
(диабет, гипертония) — основа.

## 2. Маркёр: диагноз и стадирование (двумерное!)
ХБП ставится при **eGFR <60 ИЛИ маркёре повреждения** (чаще альбуминурия), стойко ≥3 мес.
Стадируется по **двум осям сразу** (обе нужны — определяют риск и лечение):
- **Категории eGFR (мл/мин/1,73м²):** G1 ≥90 · G2 60–89 · G3a 45–59 · G3b 30–44 · G4 15–29 ·
  G5 <15 (почечная недостаточность).
- **Категории альбуминурии (ACR — альбумин/креатинин мочи):** A1 <30 мг/г · A2 30–300 (умеренно
  ↑) · A3 >300 (выраженно↑).
Чем хуже обе категории — тем выше риск прогрессирования и ССС-событий (матрица риска KDIGO).
Дополнительно — причина ХБП (диабет, ГН, поликистоз, обструкция и т.д.).

## 3. Маска: снять прежде «возрастной/диабетической ХБП»
- обструкция (камни, простата, опухоль — **УЗИ!** устранимо);
- реноваскулярная (стеноз почечной артерии);
- гломерулярная болезнь (активный осадок, гематурия, выраженная протеинурия — биопсия);
- лекарственная (НПВС, ИПП, нефротоксины), миелома, аутоиммунное;
- ⚠️ **отличить острое (ОПП — обратимо!) от хронического:** динамика креатинина, размеры почек
  (УЗИ), анемия/гипокальциемия как признаки хроничности.

## 4. Вектор: лечение (доказательная схема KDIGO 2024)
Цель — замедлить прогрессирование + снизить ССС-риск (ХБП = часть кардио-ренально-
метаболического кластера).
- **SGLT-2 ингибитор — краеугольный:** при протеинурической ХБП ± диабет (в т. ч. eGFR 20–45 с
  ACR <200) — замедляет прогрессирование, защищает сердце;
- **РААС-блокада (иАПФ ИЛИ БРА)** — при альбуминурии/гипертонии, до максимально переносимой;
- **Финеренон** (нестероидный МРА) — при СД2 + eGFR >25 + нормальный калий + альбуминурия;
- **GLP-1 RA** — кардио-ренальная польза (особенно диабет/ожирение);
- **АД <130/80**; статин для ССС-риска;
- комбинация SGLT-2 + финеренон + РААС — дополняющее снижение альбуминурии (следить калий/
  eGFR);
- ⚠️ **ожидаемый гемодинамический спад eGFR (≤30%)** при старте РААС/SGLT-2/МРА — не повод
  отменять (это не ОПП);
- **нефротоксин-стюардшип + sick-day:** избегать НПВС (Triple Whammy!), при острой болезни
  приостановить РААС/диуретик/метформин/SGLT-2;
- **лечить осложнения ХБП:** анемия (железо, ЭПО-стимуляторы), минерально-костные нарушения
  (фосфат, ПТГ, витамин D — связь с «Кальций»), ацидоз (бикарбонат), гиперкалиемия, дозы по eGFR;
- подготовка к замещению (диализ/трансплантация) на поздних стадиях.

**На языке мембраны (рамка):** ХБП — движение почки к M-S (фиброз); вектор = остановить драйвер
(диабет/АД/альбуминурия) и притормозить рубцевание (SGLT-2/РААС/финеренон бьют по гемодинамике
и фиброзно-воспалительному пути).

## 5. Граница (НЕОТЛОЖНОЕ)
- **Острое-на-хроническое** (резкий рост креатинина) → искать ОПП-причину;
- **Уремия/тяжёлая гиперкалиемия/перегрузка объёмом/тяжёлый ацидоз** → неотложно (показания к
  диализу — Т2.5, Т2.6);
- **Гиперкалиемия** (K↑ на РААС+финеренон/НПВС) — ЭКГ, неотложная коррекция при тяжёлой.

## 6. Перекрёстки
- **Кардио-ренально-метаболический кластер:** один кластер, общие 4 столпа, опасные комбинации
  (Triple Whammy, двойная РААС, гиперкалиемия).
- **Гипертония** (причина и следствие; вторичные — реноваскулярная).
- **Кальций/кость:** минерально-костные нарушения ХБП.
- **Электролиты/КЩР** (Т2.5, Т2.6).
- **ОПП:** эпизоды ОПП ускоряют ХБП.

## 7. Карманная версия
1. ХБП = тихая утрата фильтра (eGFR<60 или маркёр повреждения ≥3 мес); **стадировать по двум
   осям:** eGFR (G1–G5) + альбуминурия (A1–A3).
2. Снять маску: обструкция (УЗИ!), реноваскулярная, гломерулярная, лекарственная, миелома;
   отличить ОПП (обратимо).
3. **Вектор (KDIGO 2024):** SGLT-2 при протеинурической ХБП ±диабет (вкл. eGFR 20–45); РААС при
   альбуминурии; финеренон при СД2+eGFR>25+норм.калий+альбуминурия; GLP-1; АД<130/80; статин;
   ожидаемый спад eGFR ≤30% — не отменять.
4. Безопасность: нефротоксин-стюардшип, sick-day, избегать НПВС, контроль калия с финереноном.
5. Осложнения: анемия, кость/фосфат/ПТГ, ацидоз, калий, дозы по eGFR; подготовка к замещению.
6. Граница: острое-на-хроническое, уремия, тяжёлая гиперкалиемия/ацидоз/перегрузка → неотложно.
   Мембрана/энергия: путь к M-S; вектор = остановить драйвер + притормозить фиброз. Решение,
   препарат, доза — лечащий врач.

> Двумерное стадирование (eGFR G1–G5 + альбуминурия A1–A3), SGLT-2/РААС/финеренон/GLP-1,
> ожидаемый спад eGFR ≤30%, нефротоксин-стюардшип — доказательная медицина (KDIGO 2024, ADA
> 2025–2026, сверено июнь 2026; сверять локально). Двигатели Влажность-обмен/Атеросклероз/Фиброз,
> мембрана M-S, энергии — рамка-навигатор METACOD, не основание для назначения. Вектор =
> направление + класс; препарат, доза и решение — за лечащим врачом.
