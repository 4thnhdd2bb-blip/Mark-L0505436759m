# МОНОГРАФИЯ METACOD · Углублённый разбор

## САХАРНЫЙ ДИАБЕТ — по схеме METACOD и через мембрану

**Как читать.** Стержень главы — доказательное ведение диабета (диагноз, цели, препараты с
доказанной пользой): здесь реальная помощь. Поверх — схема METACOD (двигатель → маска → маркёр
→ вектор → граница) и мембранный язык (M-A2→A3, ось анаболизм↔катаболизм) как навигатор, чётко
помеченный как рамка. Пороги сверены (ADA 2025–2026, июнь 2026; сверять локально). Препарат,
доза и решение — за лечащим врачом.

## 1. Место в системе: какой это двигатель и какая мембрана
**Двигатель (Т1.7 — Влажность-обмен).** Диабет 2 типа — образцовый двигатель складирования:
организм получает больше субстрата, чем тратит, и анаболически накапливает (жир, гликирование,
печёночный жир). На языке ПОТОК × ГРАНИЦА: поток субстрата избыточен, клетки теряют
чувствительность к команде «впусти глюкозу» (инсулинорезистентность).

**Мембрана (рамка).** Диабет 2 типа = **анаболическая мембрана M-A2, углубляющаяся в M-A3:**
стерольное насыщение, ригидность бислоя, инсулинорезистентность рецептора в изменённом
липидном окружении. Энергетика — Влажность (+ Тепло): построение, накопление, низкоуровневое
воспаление. Рамочная раскладка; реальная мишень — инсулинорезистентность и β-клетка.

**Диабет 1 типа — иной двигатель.** Это не Влажность-обмен, а **Сухость-иммунитет (Т1.8):**
аутоиммунная деструкция β-клеток → абсолютный дефицит инсулина. Мембранно — скорее
катаболический **M-D**. Лечение — **инсулин**, не «по анаболическому типу». Это первая и
важнейшая развилка: **не лечить два диабета как один.**

## 2. Патофизиология и биохимия
**Диабет 2 типа (≈90%).** Два мотора: инсулинорезистентность (мышца, печень, жир не слышат
инсулин) + дисфункция β-клетки (со временем не успевает компенсировать). Печень гонит лишнюю
глюкозу, жир липотоксичен, низкоуровневое воспаление (связь с Теплом, Т1.10). На уровне мембраны
(рамка): изменённый липидный состав → хуже работает рецептор инсулина.

**Диабет 1 типа.** Аутоиммунная атака (антитела GAD, IA-2, ZnT8) → гибель β-клеток → абсолютный
дефицит инсулина → склонность к кетоацидозу (ДКА, Т2.6).

**LADA / MODY / вторичный** — промежуточные и особые формы; у худого «диабетика 2 типа» без
метаболического синдрома — думать о LADA (антитела) или раке поджелудочной (Том 3, гл. 5).

## 3. Шаг 1 схемы: имя → механизм (сними маску)
«Диабет» — не диагноз-финал, а имя. Механизмы разные:
- инсулинорезистентность + достаточная β-клетка (ранний 2 тип, M-A) — обратимо образом жизни;
- истощение β-клетки (поздний 2 тип) — нужна фарма/инсулин;
- аутоиммунный дефицит (1 тип / LADA, M-D) — инсулин;
- вторичный (стероиды, панкреатит, рак поджелудочной, гемохроматоз).

**Маски, которые надо снять прежде ярлыка «2 тип»:**
- рак поджелудочной у худого пожилого с новым диабетом и потерей веса (Том 3, гл. 5);
- гемохроматоз («бронзовый диабет» + печень + суставы);
- стероид-индуцированный, акромегалия, Кушинг;
- LADA у худого без метаболического синдрома.

## 4. Шаг 2: маркёр (диагноз и цели — пороги)
**Диагноз (любой из, подтвердить повторно):**
- HbA1c ≥ 6,5%;
- глюкоза натощак ≥ 7,0 ммоль/л;
- глюкоза через 2 ч ОГТТ ≥ 11,1 ммоль/л;
- случайная ≥ 11,1 + симптомы.
- Преддиабет: HbA1c 5,7–6,4%; глюкоза натощак 5,6–6,9.

**Цели (индивидуализировать):**
- HbA1c обычно < 7% для большинства; жёстче (<6,5%) — у молодых без осложнений/риска
  гипогликемии; мягче (<8%) — у хрупких пожилых, с гипогликемией, малой ожидаемой
  продолжительностью жизни.
- АД < 130/80; липиды по риску (статин — большинству с диабетом, ЛПНП-цели по Т1.12).
- При ХБП с альбуминурией ≥300 мг/г — снизить альбумин ≥30%.

**Сопутствующие маркёры (мониторинг двигателя):** глюкоза/HbA1c, вес/талия, липиды, почки
(eGFR, альбумин/креатинин мочи), печень (стеатоз), АД; маркёры мембраны в рамке (фазовый угол,
окислительные) — опционально.

## 5. Шаг 3: вектор лечения — ДОКАЗАТЕЛЬНАЯ СХЕМА (стержень)
Современная схема (ADA 2025–2026) сместилась от «снижать сахар» к **снижать сахар + защищать
сердце, почки, вес.**

**Линия 0 — образ жизни (всегда, на всех этапах):** питание, движение (в т. ч. нагрузка
сопротивления — бережёт мышцу, Т1.9), сон, вес. При раннем 2 типе может дать ремиссию.

**Старт фармы — по HbA1c и сопутствующему:**
- HbA1c 6,5–7,5% без АССЗ/ХБП/СН: **метформин (первая линия)** + образ жизни.
- HbA1c на 1,5–2% выше цели: рассмотреть **начальную комбинацию** (не ждать неудачи
  монотерапии).
- Есть АССЗ / высокий риск / ХБП / сердечная недостаточность: включить **SGLT-2 ингибитор
  и/или GLP-1 RA** с доказанной пользой — **НЕЗАВИСИМО от исходного HbA1c** (снижают
  сердечно-сосудистые события и прогрессирование ХБП сами по себе).

**Классы (двигатель → класс → маркёр, Т2.10):**
| Класс | Что делает | Когда особенно |
|---|---|---|
| Метформин | ↓печёночную продукцию глюкозы (AMPK); вес-нейтрален | первая линия 2 типа; продолжать при добавлении других |
| SGLT-2 ингибитор | выводит глюкозу с мочой; ↓вес, ↓АД; защита сердца/почек | ХБП, сердечная недостаточность, АССЗ |
| GLP-1 RA / GIP-GLP-1 | ↓аппетит, ↓вес, ↓сахар; защита сердца | ожирение, АССЗ; узел Т2.12 (мышца!) |
| Инсулин | замещение | 1 тип всегда; 2 тип при истощении β-клетки/высоком HbA1c/катаболизме |
| Сульфонилмочевина/глиниды | стимулируют β-клетку | дёшево, но гипогликемия/вес; ADA: отменять при старте инсулина |
| ДПП-4 ингибитор | мягко ↑инкретины | нейтрален, без сердечно-почечной защиты; отменять при старте GLP-1 |

**Важные правила схемы (ADA):**
- при старте инсулина **продолжать** метформин/SGLT-2/GLP-1; **отменять** сульфонилмочевину,
  глиниды, ДПП-4 (нет пользы для сердца/почек/веса, дают гипогликемию/прибавку).
- **лечить все четыре:** гликемию, АД, липиды, и агенты с сердечно-почечной пользой.

## 6. Тот же вектор на языке мембраны (рамка, рядом со схемой)
- Диабет 2 типа = анаболический перекос **M-A2→A3** → вектор коррекции **катаболический/
  разгружающий.** Заметьте: доказательные SGLT-2 (выводит глюкозу) и GLP-1 (снижает
  складирование) — это и есть «катаболический вектор» рамки. **Рамка и доказательная медицина
  совпадают по направлению** — что делает рамку удобным языком, но не источником назначения.
- Образ жизни (дефицит калорий, движение) — главный катаболический сдвиг M-A→M-0.
- Рамочные мембранные средства (поддержка состава — омега-3; антиоксиданты против перекисного
  окисления; альфа-липоевая кислота, магний при нейропатии) — частично доказательны как
  поддержка, **не вместо** базовой схемы.
- ⚠️ **Конфликт векторов (узел GLP-1, Т2.12):** GLP-1 — катаболический вектор (нужен при M-A
  диабете), но у пожилого с саркопенией (M-D, Т1.9) он углубит потерю мышцы. Решение: не отказ,
  а GLP-1 с белком 1,2–1,6 г/кг и нагрузкой сопротивления, мониторить силу, не только вес.

## 7. Шаг 4: осложнения — двигатель ветвится
Диабет редко один; запускает цепочки (Т2.2). Вести параллельно:
- **Сосуды (Атеросклероз, Т1.12):** статин большинству, АД <130/80, антиагрегант по показаниям;
  SGLT-2/GLP-1 для сердца.
- **Почки (ХБП):** eGFR + альбумин/креатинин мочи; SGLT-2 (защита, продолжать до eGFR<20 по
  показаниям), иАПФ/БРА при альбуминурии; нестероидный антагонист минералокортикоидных
  рецепторов по показаниям.
- **Нейропатия (Т2.9 — проводник):** скрининг стоп; боль — модуляторы, не опиоиды (Т2.7).
- **Ретинопатия:** скрининг глазного дна; быстрая нормализация гликемии может временно ухудшить
  — наблюдение.
- **Стеатоз/МАСХ печени (Т1.2):** часть того же двигателя обмена.

## 8. Шаг 5: граница — где прерывать, не вести
- **Диабетический кетоацидоз (ДКА)** (Т2.6; чаще 1 тип, но и 2 тип): дыхание Куссмауля, кетоны,
  высокопровальный ацидоз → неотложно (инсулин + жидкость + калий).
- **Гиперосмолярное гипергликемическое состояние:** очень высокая глюкоза + дегидратация +
  спутанность у пожилого → неотложно.
- **Тяжёлая гипогликемия** (ятрогенная — инсулин/сульфонилмочевина): спутанность/судорога →
  глюкоза немедленно (Том 3, гл. 3).
- **Новый диабет у худого пожилого + потеря веса** → исключить рак поджелудочной (Т1.1; Том 3,
  гл. 5).
- **Эугликемический ДКА на SGLT-2** (редко, но коварно — глюкоза не очень высокая): при
  недомогании/ацидозе на SGLT-2 проверять кетоны.
- ⚠️ **SGLT-2 — пауза при острой болезни/голодании/периоперационно** (риск эугликемического
  ДКА); **GLP-1 — учитывать гастропарез перед анестезией** (Т2.12).

## 9. Карманная версия (схема одним взглядом)
1. **Сними маску:** 2 тип (M-A, инсулинорезистентность) vs 1 тип/LADA (M-D, аутоиммунный) vs
   вторичный (рак поджелудочной у худого + потеря веса!).
2. **Диагноз:** HbA1c ≥6,5 / глюкоза натощак ≥7,0 / ОГТТ ≥11,1 (подтвердить). Цель HbA1c обычно
   <7%, индивидуально.
3. **Вектор (доказательно):** образ жизни всегда; метформин первой линией; SGLT-2/GLP-1 при
   АССЗ/ХБП/СН независимо от HbA1c; начальная комбинация при HbA1c +1,5–2% к цели; при инсулине
   продолжать метформин/SGLT-2/GLP-1, убрать сульфонилмочевину/ДПП-4.
4. **Лечить все четыре:** сахар, АД (<130/80), липиды (статин), сердечно-почечная защита.
5. **Мембрана (рамка):** M-A2→A3, катаболический вектор — совпадает с SGLT-2/GLP-1/образом
   жизни; поддержка состава (омега-3, антиоксиданты) — добавка, не замена.
6. **Граница:** ДКА/ГГС/тяжёлая гипогликемия → неотложно; SGLT-2 пауза при острой болезни
   (эугликемический ДКА); GLP-1 + саркопения → белок+нагрузка (Т2.12).
7. **Решение, препарат, доза — лечащий врач.**

> Диагностические пороги, цели и классы с доказанной пользой — доказательная медицина (ADA
> 2025–2026, сверено июнь 2026; сверять локально). Двигатель Влажность-обмен, мембрана M-A2→A3,
> энергии — рамка-навигатор METACOD, не основание для назначения. Вектор = направление + класс;
> препарат, доза и решение по конкретному человеку — за лечащим врачом.
