## 1. Что это в системе: камень в протоке потока
Желчная система — дренаж потока желчи из печени и желчного пузыря в кишку. Камни (чаще
холестериновые) образуются при дисбалансе состава желчи (связь с обменом, Т1.7; стерол —
монография «Мембрана») и нарушении опорожнения. **Болезнь определяется тем, где камень застрял и
есть ли инфекция** — это и есть разводящая логика. Двигатель — застой/обструкция дренажа (близко
к Ветер-клиренс/застой) + **Тепло/инфекция (Т1.10/Т2.8)** при воспалении. Мембранно —
холестериновый камень как стерольный осадок (рамка).

**Спектр по локализации (ключ к тяжести):**
- камень в пузыре без симптомов → бессимптомный холелитиаз;
- камень перекрывает проток пузыря → желчная колика / острый холецистит;
- камень в общем желчном протоке (холедохе) → желтуха (холедохолитиаз), панкреатит, холангит.

## 2. Состояния и их разведение
### 2.1. Бессимптомные камни
Находка по УЗИ без симптомов → обычно наблюдение; профилактическая холецистэктомия — лишь в
отдельных группах риска.

### 2.2. Желчная колика
Приступообразная боль в правом подреберье/эпигастрии после жирной еды, проходит (камень временно
перекрыл шейку и сместился); без лихорадки/воспаления. → плановая холецистэктомия при рецидивах.

### 2.3. Острый холецистит
Стойкая боль в правом подреберье + лихорадка + **положительный симптом Мёрфи**; УЗИ (утолщённая
стенка, перипузырная жидкость, камень в шейке). → антибиотики + холецистэктомия (раннюю
предпочтительно); при высоком риске — холецистостома.

### 2.4. Холедохолитиаз (камень холедоха)
Желтуха, расширенный холедох, ↑билирубин/ЩФ/ГГТ. → удаление камня (**ЭРХПГ**) ± холецистэктомия;
при подозрении без холангита — сначала МРХПГ/эндоУЗИ (не диагностическая ЭРХПГ).

### 2.5. Острый холангит (НЕОТЛОЖНОЕ — инфекция в обструированном протоке)
⚠️ **Триада Шарко: лихорадка + желтуха + боль в правом подреберье** (± пентада Рейнолдса: +
гипотензия + спутанность = тяжёлый). Это инфекция в закупоренном протоке → быстрый сепсис. →
неотложно: **антибиотики + срочная декомпрессия/дренирование (ЭРХПГ ≤24 ч)** (Т2.8; Том 3, гл. 11).

## 3. Маркёр
- **УЗИ — первый тест** (камни, стенка пузыря, ширина холедоха);
- **печёночные пробы:** билирубин, ЩФ, ГГТ (холестаз/обструкция), АЛТ/АСТ; липаза (панкреатит);
- воспаление: лейкоциты, СРБ (Тепло);
- **МРХПГ / эндоУЗИ** — для холедоха без явного холангита; **ЭРХПГ — лечебная** (камень холедоха/
  холангит), не для рутинной диагностики.

## 4. Вектор (по состоянию)
- бессимптомные → наблюдение;
- колика/симптомные камни → плановая лапароскопическая холецистэктомия;
- острый холецистит → антибиотики + холецистэктомия (ранняя);
- холедохолитиаз → ЭРХПГ (извлечение) + холецистэктомия;
- **холангит → неотложная декомпрессия (ЭРХПГ ≤24 ч) + антибиотики** (граница!);
- билиарный панкреатит лёгкий → холецистэктомия в ту же госпитализацию.

**На языке мембраны (рамка):** камень = стерольный осадок при дисбалансе желчи (связь с обменом
Т1.7); проблема — застой дренажа + Тепло/инфекция при осложнении. Вектор — убрать обструкцию
(камень/проток) и погасить инфекцию при холангите/холецистите.

## 5. Граница (НЕОТЛОЖНОЕ)
- **Острый холангит** (триада Шарко/пентада Рейнолдса) → антибиотики + срочная декомпрессия — это
  сепсис в протоке (Т2.8);
- **Острый холецистит с осложнениями** (гангрена/перфорация/эмпиема) → срочная хирургия;
- **Билиарный панкреатит** (разбор «Панкреатит»);
- Снять маску правоподреберной боли: гепатит, печёночный абсцесс, правосторонняя пневмония, ОКС,
  язва (Том 3, гл. 8, 11).

## 6. Перекрёстки
- **Желтуха (Том 3, гл. 11):** обструктивная (постпечёночная) развилка — камень/опухоль.
- **Панкреатит:** билиарный — ведущая причина острого.
- **Инфекция/сепсис (Т2.8):** холангит, эмпиема.
- **Обмен (Т1.7):** ожирение/быстрая потеря веса (в т. ч. на GLP-1) ↑ камнеобразование.
- **Онкология (Т1.1):** опухоль желчных путей/головки поджелудочной как причина обструкции
  (**безболевая желтуха — насторожиться**).

## 7. Карманная версия
1. Болезнь определяется **локализацией камня и наличием инфекции:** пузырь (колика/холецистит) vs
   холедох (желтуха/панкреатит/холангит).
2. Маркёр: УЗИ + печёночные пробы (билирубин/ЩФ/ГГТ); МРХПГ/эндоУЗИ при подозрении на холедох без
   холангита; ЭРХПГ — лечебная.
3. Вектор: бессимптомные → наблюдение; симптомные/холецистит → холецистэктомия (при холецистите +
   антибиотики); холедохолитиаз → ЭРХПГ + холецистэктомия.
4. ⚠️ **Холангит (триада Шарко) = неотложность: антибиотики + декомпрессия (ЭРХПГ ≤24 ч).**
5. Граница: холангит, осложнённый холецистит, билиарный панкреатит → неотложно; **безболевая
   желтуха → исключить опухоль.**
6. Мембрана/энергия: стерольный камень + застой дренажа + Тепло при инфекции; вектор = убрать
   обструкцию + погасить инфекцию. Решение, сроки, объём — лечащий врач.

> Разведение по локализации, триада Шарко = холангит (неотложная декомпрессия ≤24 ч), МРХПГ/
> эндоУЗИ до ЭРХПГ, ранняя холецистэктомия — доказательная медицина (Tokyo Guidelines и
> рекомендации, сверено июнь 2026; сверять локально). Двигатели застой-дренажа/Тепло-инфекция,
> стерольный камень, энергии — рамка-навигатор METACOD, не основание для назначения. Вектор =
> направление + класс; решение, сроки и объём вмешательства — за лечащим врачом.
