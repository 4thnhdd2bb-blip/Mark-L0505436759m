# МОНОГРАФИЯ METACOD · Углублённый разбор · Инфекционные болезни

## ИНФЕКЦИОННЫЙ ЭНДОКАРДИТ И МЕНИНГИТ — глубокие очаговые инфекции через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение двух глубоких очаговых инфекций-
неотложностей: инфекционного эндокардита и бактериального менингита. Поверх — фильтры METACOD
(двигатель, маска, маркёр, граница). Связь с узлом «Инфекция» (Том 2, гл. 8). Данные сверены
(Duke-ISCVID 2023, рекомендации по менингиту, июнь 2026; сверять локально). Препарат, доза, решение
— врач/специалист.

> Прикладной разбор болезни для направления 1 (инфекционные). Связан с: `metacod-tom1.md` (Т1.10),
> `metacod-tom2.md` (гл. 8 инфекция, гл. 9 неврология), `metacod-valvular-disease.md`,

## 1. Что их объединяет в системе
Это инфекции в «защищённых» глубоких зонах — на **клапанах сердца (эндокардит)** и в **оболочках
мозга (менингит)**. Обе: трудны для иммунитета и антибиотиков (биоплёнка/гематоэнцефалический
барьер), быстро дают тяжёлые осложнения, требуют высоких доз, длительных курсов и часто срочных
действий. Двигатель — **Инфекция (Том 2, гл. 8) + Тепло**; обе — **граница**.

## 2. ИНФЕКЦИОННЫЙ ЭНДОКАРДИТ
### 2.1. Суть и маска
Инфекция эндокарда/клапанов → **вегетации** (микробы + тромб) → разрушение клапана (СН —
`metacod-valvular-disease.md`), эмболии (инсульт — `metacod-stroke.md`, органные), иммунные
феномены. ⚠️ **Великий имитатор:** лихорадка неясного генеза + новый шум + системное; подумать об
эндокардите при бактериемии (особенно S. aureus), лихорадке у пациента с клапанным протезом/
пороком/в/в наркопотреблении. Эндокардит — частая маска, скрытая за «васкулитом»/«сепсисом неясного
очага» (`metacod-vasculitis.md`, `metacod-sepsis.md`).

### 2.2. Маркёр (критерии Дьюка-ISCVID 2023)
- **посевы крови** (несколько наборов, до антибиотиков) — типичные возбудители;
- **ЭхоКГ** (трансторакальная → чреспищеводная) — вегетации/абсцесс/несостоятельность протеза;
  визуализация (ПЭТ-КТ при протезе) — расширенные критерии;
- **критерии Duke-ISCVID** (большие: микробиология + поражение эндокарда/визуализация; малые:
  предрасполагающие, лихорадка, сосудистые/иммунные феномены) → определённый/возможный/отвергнутый.

### 2.3. Вектор
- **антибиотик после посевов, длительно (недели)**, по возбудителю/чувствительности (бактерицидный,
  высокие дозы; особый режим для протезов);
- ⚠️ **хирургия по показаниям** (тяжёлая клапанная недостаточность/СН, неконтролируемая инфекция/
  абсцесс, крупные вегетации/рецидив эмболий, протезный эндокардит) — мультидисциплинарная
  «эндокардит-команда»;
- лечить осложнения (эмболии, СН), искать входные ворота (зубы, катетер, кожа), профилактика у
  групп риска.

## 3. БАКТЕРИАЛЬНЫЙ МЕНИНГИТ
### 3.1. Суть и маска
Инфекция мягких мозговых оболочек → **классическая триада: лихорадка + ригидность затылка +
нарушение сознания** (не всегда полная); головная боль, светобоязнь, рвота, ± сыпь (менингококк),
судороги, очаговость. ⚠️ Снять маску/распознать срочно: вирусный менингит/энцефалит,
субарахноидальное кровоизлияние (Том 2, гл. 9; `metacod-headache.md`), сепсис.

### 3.2. Маркёр и ⚠️ принцип «не задерживать лечение»
- **люмбальная пункция** (анализ ликвора: цитоз/белок/глюкоза/окраска/посев/ПЦР) — подтверждает и
  типирует; посевы крови;
- ⚠️ **КТ перед ЛП только при показаниях** (очаговость, отёк диска, иммунодефицит, судороги,
  сниженное сознание) — но **НЕ задерживать антибиотик** ради визуализации/ЛП: при подозрении —
  **антибиотик немедленно** (после посевов крови, если быстро).

### 3.3. Вектор
- **эмпирический антибиотик НЕМЕДЛЕННО** (широкий спектр по возрасту/риску — покрытие пневмококка/
  менингококка ± листерии у пожилых/иммунодефицита), затем по ликвору/посеву;
- ⚠️ **дексаметазон** (со/перед первой дозой антибиотика при подозрении на пневмококковый
  бактериальный менингит — снижает осложнения);
- лечить осложнения (отёк мозга, судороги, шок — `metacod-sepsis.md`); изоляция и постконтактная
  профилактика контактам (менингококк); искать очаг (отит/синусит/ликворея).

**На языке мембраны (рамка):** обе — инфекция в защищённой глубокой зоне (Инфекция + Тепло):
антибиотик плохо проникает, осложнения быстрые. Вектор — **быстрый адекватный антибиотик** (высокие
дозы/длительно) + контроль очага/хирургия (эндокардит) или дексаметазон/неотложность (менингит).
Рамка вторична — это граница, протоколы и время.

## 4. Граница (НЕОТЛОЖНОЕ)
- **Менингит — неотложность:** антибиотик немедленно (± дексаметазон), не ждать ЛП/КТ;
  менингококцемия/сепсис → реанимация; контактам — профилактика;
- **Эндокардит с острой тяжёлой клапанной недостаточностью/СН** (`metacod-valvular-disease.md`),
  эмболиями (инсульт — `metacod-stroke.md`), неконтролируемой инфекцией → срочная хирургия/ОРИТ;
- любая из них с сепсисом/шоком → протокол сепсиса (`metacod-sepsis.md`).

## 5. Перекрёстки
- **Сепсис:** обе — источники; немедленные антибиотики.
- **Клапаны/Инсульт:** осложнения эндокардита (разрушение клапана, эмболии).
- **Васкулиты:** эндокардит — имитатор; исключить до иммуносупрессии.
- **Головные боли / Том 2 гл. 9:** менингит — red flag головной боли.
- **Антибиотикотерапия:** длительные высокодозные курсы, проникновение, деэскалация.

## 6. Карманная версия
1. Две глубокие очаговые инфекции-неотложности: **эндокардит** (клапаны) и **менингит** (оболочки
   мозга) — трудны для иммунитета/антибиотиков, быстрые осложнения.
2. **Эндокардит:** лихорадка + новый шум/бактериемия (S. aureus); посевы + ЭхоКГ → критерии
   Duke-ISCVID 2023; длительный антибиотик по возбудителю + хирургия по показаниям; великий
   имитатор (исключить при «васкулите»/неясном сепсисе).
3. **Менингит:** триада лихорадка + ригидность затылка + нарушение сознания; ЛП + посевы; ⚠️
   **антибиотик немедленно, не ждать ЛП/КТ**; дексаметазон при пневмококковом подозрении;
   профилактика контактам (менингококк).
4. Граница: менингит = немедленный антибиотик; эндокардит с СН/эмболиями/неконтролем → срочная
   хирургия; обе с шоком → сепсис-протокол.
5. Мембрана/энергия: инфекция в защищённой зоне; вектор = быстрый адекватный антибиотик + контроль
   очага/хирургия или дексаметазон. Решение, препарат, доза — врач/специалист.

> Эндокардит (Duke-ISCVID 2023, посевы+ЭхоКГ, длительный антибиотик, хирургия по показаниям),
> менингит (ЛП, антибиотик немедленно не задерживая, дексаметазон при пневмококке, профилактика
> контактам) — доказательная медицина (рекомендации, сверено июнь 2026; сверять локально). Двигатели
> Инфекция/Тепло, энергии — рамка-навигатор METACOD; обе ведутся по неотложным протоколам. Вектор =
> направление + класс; препарат, доза и решение — за врачом/специалистом.
