# МОНОГРАФИЯ METACOD · Углублённый разбор · Гематология

## ЛИМФОМЫ И МНОЖЕСТВЕННАЯ МИЕЛОМА — через фильтры METACOD

**Как читать.** Стержень — доказательная логика диагностики лимфом и миеломы: здесь реальная
помощь в распознавании. Поверх — фильтры METACOD (двигатель, мембрана, маркёр, граница). Это
онкогематология — разбор аналитический, не схема назначений. Данные сверены (WHO/рекомендации,
миелома 2024, июнь 2026; сверять локально). Лечение — только гематолог-онколог.

> Прикладной разбор болезни для направления 1 (гематология). Связан с: `metacod-tom1.md` (Т1.1–1.3
> деление), `metacod-tom2.md` (гл. 9 неврология), `metacod-calcium.md`, `metacod-aki.md`,
> `metacod-osteoporosis.md`, `metacod-anemia.md`, `metacod-leukemia.md`, `metacod-thrombophilia-vte.md`.

## 1. Что это в системе: клон лимфоидной/плазматической клетки
Это злокачественные клоны зрелых лимфоидных клеток: **лимфомы** (клон в лимфоузлах/лимфоидной
ткани) и **множественная миелома** (клон плазматических клеток в костном мозге, производящий
патологический белок). Двигатель — **деление/Рак (Т1.1–1.3)** в лимфоидной линии; проявления — от
объёмного образования (лимфоузел) до системного поражения костей/почек/крови (миелома). Мембранно/
энергетически — пролиферация клона + (в миеломе) продукция парапротеина.

## 2. ЛИМФОМЫ
### 2.1. Два больших класса
- **Лимфома Ходжкина** — характерные клетки Рид-Штернберга; часто молодые; обычно локализованное
  распространение по смежным узлам; высокая излечимость;
- **Неходжкинские лимфомы (НХЛ)** — большая разнородная группа: **агрессивные** (напр. диффузная
  B-крупноклеточная — быстро растёт, но потенциально излечима) vs **индолентные** (напр.
  фолликулярная — медленные, часто неизлечимы, но управляемы годами).

### 2.2. Маркёр и клиника
- клиника: **безболезненная лимфаденопатия**, **B-симптомы** (лихорадка, ночные поты, потеря веса),
  утомляемость; объёмные эффекты; экстранодальные поражения;
- ⚠️ снять маску лимфаденопатии: инфекции (часто!), реактивная, другие опухоли, аутоиммунное — но
  стойкий/растущий/безболезненный узел + B-симптомы → биопсия;
- диагноз — **эксцизионная биопсия узла** (не только пункция) + иммуногистохимия/молекулярика
  (тип); стадирование — ПЭТ-КТ, костный мозг по показаниям; ЛДГ (прогноз).

### 2.3. Вектор (гематолог-онколог)
- по типу/стадии: химиоиммунотерапия (напр. с анти-CD20-антителом при B-клеточных), лучевая при
  локализованных, таргетные/CAR-T/биспецифики при рецидиве;
- индолентные — иногда наблюдение (watch-and-wait) при бессимптомных;
- поддержка, профилактика лизиса, инфекций.

## 3. МНОЖЕСТВЕННАЯ МИЕЛОМА
### 3.1. Суть
Клон плазматических клеток в костном мозге → **патологический моноклональный белок** (парапротеин/
M-белок, лёгкие цепи) + поражение органов. Спектр: **MGUS** (моноклональная гаммапатия неясного
значения — предшественник, наблюдение) → **тлеющая** миелома → **активная** миелома.

### 3.2. Маркёр и диагноз (CRAB)
- диагноз активной миеломы: **≥10% клональных плазмоцитов** в костном мозге (или плазмоцитома) +
  признак поражения — **CRAB:** **C**alcium (гиперкальциемия — `metacod-calcium.md`), **R**enal
  (почечная недостаточность — лёгкие цепи/каст-нефропатия, `metacod-aki.md`), **A**nemia (анемия —
  `metacod-anemia.md`), **B**one (литические поражения костей/переломы) — или биомаркёры высокого
  риска;
- маркёры: **электрофорез белков** сыворотки/мочи + иммунофиксация, свободные лёгкие цепи, костный
  мозг, визуализация костей (низкодозовая КТ/МРТ/ПЭТ — не обычная рентгенография предпочтительно),
  кальций/креатинин/анемия;
- ⚠️ **боли в спине/костях у пожилого + анемия + почечная недостаточность + гиперкальциемия → думать
  о миеломе** (частая пропущенная маска — `metacod-osteoporosis.md`, `metacod-calcium.md`,
  `metacod-aki.md`).

### 3.3. Вектор (гематолог-онколог)
- многокомпонентная терапия (протеасомные ингибиторы + иммуномодуляторы + анти-CD38-антитела ±
  стероид), аутологичная трансплантация у подходящих, поддерживающая терапия; при рецидиве — CAR-T/
  биспецифики и др.;
- **поддержка органов:** гиперкальциемия (`metacod-calcium.md`), почка (`metacod-aki.md` —
  каст-нефропатия, плазмаобмен при тяжёлой), кость (бисфосфонаты/деносумаб, `metacod-osteoporosis.md`),
  анемия, инфекции/профилактика, **тромбопрофилактика** (иммуномодуляторы ↑ риск ВТЭ —
  `metacod-thrombophilia-vte.md`).

**На языке мембраны (рамка):** лимфома/миелома = деление лимфоидного/плазматического клона
(Т1.1–1.3); миелома вдобавок — продукция парапротеина, бьющего по почке/кости/кальцию. Вектор
(онкологический) — подавить клон (по типу) + защитить органы-мишени (кальций/почка/кость). METACOD
здесь — навигатор распознавания (особенно «снять маску» лимфаденопатии и CRAB-картины).

## 4. Граница (НЕОТЛОЖНОЕ)
- **компрессия спинного мозга** (миеломное/лимфомное поражение позвонка + неврология) → неотложно
  (Том 2, гл. 9);
- **гиперкальциемический криз** (`metacod-calcium.md`), **острая почечная недостаточность**
  (каст-нефропатия — `metacod-aki.md`), **синдром лизиса** (агрессивные лимфомы), **синдром верхней
  полой вены** (объёмная лимфома), фебрильная нейтропения на терапии (Том 2, гл. 8) → неотложно;
- **стойкий растущий узел + B-симптомы** → срочная биопсия (не откладывать).

## 5. Перекрёстки
- **Кальций:** гиперкальциемия с низким ПТГ → миелома/рак.
- **ОПП:** каст-нефропатия лёгких цепей; снять маску при необъяснённой почечной недостаточности.
- **Остеопороз/кость:** литические поражения vs остеопороз — биопсия/обследование.
- **Анемии:** нормоцитарная анемия + высокая СОЭ + белок → миелома.
- **Лейкозы, Онкология (Т1.1):** соседние клоны, общий двигатель деления.
- **Тромбофилии:** иммуномодуляторы при миеломе → тромбопрофилактика.

## 6. Карманная версия
1. Клон лимфоидной/плазматической клетки (деление Т1.1–1.3): **лимфомы** (узлы) vs **миелома**
   (плазмоциты + парапротеин, кости/почка/кальций).
2. **Лимфома:** безболезненная лимфаденопатия + B-симптомы; снять маску (инфекции!); диагноз —
   **эксцизионная биопсия узла**; Ходжкина vs НХЛ (агрессивные/индолентные).
3. **Миелома (CRAB):** ≥10% плазмоцитов + **C**альций↑ / **R**енальная недостаточность / **A**немия
   / **B**one (литические); маркёры — электрофорез + лёгкие цепи + костный мозг; спектр MGUS →
   тлеющая → активная.
4. ⚠️ **Думать о миеломе:** пожилой + боли в костях/спине + анемия + почечная недостаточность +
   гиперкальциемия.
5. **Вектор (гематолог-онколог):** подавить клон по типу (± трансплантация) + защитить органы
   (кальций/почка/кость/тромбопрофилактика).
6. Граница: компрессия спинного мозга, гиперкальциемический криз, ОПП, лизис, СВПВ, фебрильная
   нейтропения → неотложно. Мембрана/энергия: деление клона; вектор = подавить + защитить органы.
   Решение, режим — гематолог-онколог.

> Классы лимфом (Ходжкина/НХЛ, агрессивные/индолентные), биопсия узла, миелома CRAB-критерии (≥10%
> плазмоцитов + поражение), электрофорез/лёгкие цепи, защита органов-мишеней, неотложности
> (компрессия спинного мозга, гиперкальциемия, каст-нефропатия) — доказательная медицина (WHO/
> рекомендации, миелома 2024, сверено июнь 2026; сверять локально). Двигатель деления/Рак (Т1.1–1.3),
> энергии — рамка-навигатор METACOD для распознавания, не основание для режима терапии. Диагностика
> и лечение — за гематологом-онкологом.
