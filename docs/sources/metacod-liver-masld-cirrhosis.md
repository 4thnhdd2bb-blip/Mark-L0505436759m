## 1. Что это в системе: от метаболического жира к рубцу
Болезни печени образуют траекторию по двигателям: **метаболический жир (стеатоз) → воспаление
(стеатогепатит) → фиброз → цирроз (рубец).** Два двигателя в связке: **Влажность-обмен (Т1.7)**
даёт жир, **Фиброз (Т1.2)** превращает воспаление в рубец. Мембранно (рамка) — анаболическое
накопление (**M-A**) переходит в склеротический исход (**M-S**, цирроз). **Ключ прогноза — степень
фиброза, а не сам жир.**

**Переименование (2024):** НАЖБП → **MASLD** (метаболически-ассоциированная стеатозная болезнь
печени), НАСГ → **MASH**. MASLD = стеатоз + ≥1 кардиометаболический фактор без вредного алкоголя.

**Главный фильтр (маска):** «жирная печень» и «повышенные трансаминазы» — снять маску других
причин: алкоголь, вирусные гепатиты (B/C), лекарственное/токсическое, аутоиммунный гепатит,
гемохроматоз, болезнь Вильсона, дефицит α1-антитрипсина, целиакия, щитовидка.

## 2. MASLD / MASH (стеатоз → стеатогепатит)
### 2.1. Суть и прогноз
Стеатоз сам по себе мало повышает риск; опасность — прогрессирование в MASH с фиброзом. ~10–40%
стеатоза → MASH, ~10% MASLD → цирроз за ~20 лет. **Прогноз определяет фиброз** — единственный
показатель, коррелирующий со смертностью и потребностью в трансплантации.

### 2.2. Маркёр (неинвазивно, без биопсии у большинства)
- **Стратификация фиброза: FIB-4** (возраст, АЛТ/АСТ, тромбоциты) как первый фильтр → при
  повышенном — **эластография** (фиброскан) / ELF; биопсия — в неясных случаях;
- активно искать у групп риска: диабет 2 типа, ожирение + метаболические факторы, стойко
  повышенные трансаминазы, стеатоз на УЗИ.
- Снять маску: алкоголь (анамнез), серология гепатитов, железо/ферритин (гемохроматоз),
  аутоантитела, ТТГ.

### 2.3. Вектор
- **Основа — образ жизни:** снижение веса (заметная доля массы даёт регресс стеатоза/MASH),
  питание, движение, кофе (есть данные о пользе), снижение алкоголя;
- **Лечить кардиометаболические факторы** (это один кластер): диабет, гипертония, липиды;
- **GLP-1 RA** — по их показаниям (диабет/ожирение) с пользой для печени; **резметиром** (агонист
  THR-β) — одобрен (2024) при умеренно-тяжёлом фиброзе **без цирроза**; пиоглитазон не рекомендован
  рутинно (по обновлённым рекомендациям);
- ⚠️ при **MASH-циррозе** специфической одобренной фарма-терапии нет — вести как цирроз (раздел 3).

## 3. ЦИРРОЗ (склеротический исход)
### 3.1. Суть
Диффузный фиброз + узлы регенерации → нарушение функции и портальная гипертензия. Различать
**компенсированный** (бессимптомный) и **декомпенсированный** (осложнения). Причины: MASH,
алкоголь, вирусные гепатиты, аутоиммунные/холестатические, гемохроматоз и др.

### 3.2. Маркёр функции (не путать с «ферментами»)
⚠️ **Функцию печени отражают INR, альбумин, билирубин** (синтез и выведение), а **не АЛТ/АСТ**
(это маркёры повреждения). Шкалы: Child–Pugh, MELD (прогноз/очередь на трансплантацию). УЗИ/
эластография, тромбоциты (косвенно портальная гипертензия), скрининг варикоза (ЭГДС) и ГЦК (УЗИ ±
АФП каждые 6 мес).

### 3.3. Осложнения декомпенсации (вектор по каждому)
- **Асцит** (Том 3, гл. 7): ограничение натрия + диуретики (спиронолактон ± петлевой);
  напряжённый — парацентез; ⚠️ **спонтанный бактериальный перитонит** (лихорадка/боль/ухудшение) →
  парацентез + антибиотики (Т2.8) — неотложно;
- **Варикозное кровотечение** (Т2.4): неселективный β-блокатор для профилактики/эндоскопическое
  лигирование; острое — эндоскопия + вазоактивные + антибиотики — неотложно;
- **Печёночная энцефалопатия** (Том 3, гл. 3): лактулоза ± рифаксимин; искать провокатор
  (кровотечение, инфекция, электролиты, запор);
- **Гепаторенальный синдром, гипонатриемия** (Т2.5) — вести специализированно;
- **ГЦК** (гепатоцеллюлярный рак, Т1.1) — скрининг и лечение.
- **Трансплантация** — при декомпенсации/высоком MELD.

### 3.4. На языке мембраны (рамка)
Печень проходит **M-A** (жир, накопление) → **M-S** (цирроз, рубец). Вектор на стадии стеатоза —
катаболически-метаболический (снизить накопление, образ жизни/GLP-1), на стадии фиброза —
остановить драйвер (резметиром при MASH-фиброзе без цирроза; убрать алкоголь/вирус), на стадии
цирроза — вести осложнения и трансплантация.

## 4. Граница (НЕОТЛОЖНОЕ)
- **Острая печёночная недостаточность** (желтуха + энцефалопатия + ↑INR без хронической болезни) —
  Том 3, гл. 11 — неотложно (трансплантационный центр);
- **Варикозное кровотечение** (Т2.4), **спонтанный бактериальный перитонит**, **печёночная
  энцефалопатия** с провокатором — неотложные осложнения цирроза;
- **Острый холангит** (триада Шарко, Том 3, гл. 11) — отдельная неотложность.

## 5. Перекрёстки
- **Кардиометаболический кластер:** MASLD — печёночное проявление того же обмена.
- **Свёртывание (Т2.4):** цирроз = сложный гемостаз (и кровотечение, и тромбозы).
- **Инфекция (Т2.8):** СБП, сепсис у цирротика.
- **Желтуха (Том 3, гл. 11):** печёночная/обструктивная развилка.
- **Онкология (Т1.1):** ГЦК на фоне цирроза → скрининг.

## 6. Карманная версия
1. Траектория: жир (Влажность-обмен Т1.7) → воспаление → фиброз/цирроз (Фиброз Т1.2, M-S);
   **прогноз — по фиброзу.**
2. MASLD/MASH: снять маску (алкоголь, вирусы, гемохроматоз, щитовидка); стратификация — **FIB-4 →
   эластография**; вектор — образ жизни + кардиометаболические факторы + GLP-1 по показаниям;
   резметиром при MASH-фиброзе без цирроза.
3. Цирроз: **функцию отражают INR/альбумин/билирубин** (не АЛТ/АСТ); шкалы Child–Pugh/MELD;
   скрининг варикоза и ГЦК.
4. Осложнения: асцит/СБП, варикозное кровотечение, энцефалопатия — каждое со своим вектором;
   трансплантация при декомпенсации.
5. Граница: острая печёночная недостаточность, кровотечение, СБП, энцефалопатия → неотложно.
6. Мембрана/энергия: M-A (жир) → M-S (рубец); вектор по стадии. Решение, препарат, доза — лечащий
   врач.

> Переименование MASLD/MASH, прогноз по фиброзу (FIB-4/эластография), резметиром при MASH-фиброзе
> без цирроза, функция печени = INR/альбумин/билирубин, осложнения цирроза — доказательная
> медицина (EASL-EASD-EASO 2024, AASLD 2024, сверено июнь 2026; сверять локально). Двигатели
> Влажность-обмен/Фиброз, мембрана M-A/M-S, энергии — рамка-навигатор METACOD, не основание для
> назначения. Вектор = направление + класс; препарат, доза и решение — за лечащим врачом.
