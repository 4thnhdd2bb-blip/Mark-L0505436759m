# МОНОГРАФИЯ METACOD — Сквозной указатель трилогии

## Навигатор · от жалобы и двигателя — к нужной главе

Единый справочник по трём томам: указатель двигателей, указатель предъявлений, быстрая
таблица «жалоба → двигатели → глава», сводка красных флагов и сводка проверенных порогов.

*Dr. Mark Litvak совместно с Claude · Июнь 2026*

-----

## Как пользоваться навигатором

Трилогия устроена так:
- **Том 1 — двигатели (что бывает):** двенадцать процессов-механизмов.
- **Том 2 — метод и лечение (как пользоваться):** применение у постели, новые двигатели,
  векторы лечения.
- **Том 3 — предъявления (с чем приходит пациент):** обратный поиск от жалобы к диагнозу,
  красные флаги первыми.

Навигатор даёт пять входов:
1. **Указатель двигателей** — нашёл механизм → нашёл главу (раздел A).
2. **Указатель предъявлений** — пациент с жалобой → глава Тома 3 + задействованные двигатели
   (раздел B).
3. **Быстрая таблица «жалоба → двигатели → глава»** — обратный поиск одним взглядом (раздел C).
4. **Сводка красных флагов** — что прерывать немедленно, по предъявлениям (раздел D).
5. **Сводка порогов и маркёров** — проверенные цифры в одном месте (раздел E).

Обозначения: **Т1/Т2/Т3** — том; число после точки — глава. Например, Т1.7 = Том 1, глава 7
(Влажность-обмен); Т3.4 = Том 3, глава 4 (Обморок).

> Пороги и красные флаги — доказательная медицина (сверено, июнь 2026; сверять локально).
> «Двигатели»/«энергии» — рамка-навигатор. Вектор = направление + класс; препарат и решение —
> за лечащим врачом.

## D. Сводка красных флагов (что прерывать немедленно)
Единый стоп-лист трилогии — «прерывать, не сопровождать» (Т2.1 шаг 5; Т2.10 пределы).

**Сосудистые катастрофы**
- ОКС: боль в груди в покое >20 мин + пот/иррадиация → ЭКГ/тропонин, реперфузия (Т3.1, Т1.12)
- Расслоение аорты: разрывающая боль + асимметрия пульса → КТ-ангио, НЕ тромболизис (Т3.1)
- ТЭЛА: внезапная одышка + тахикардия → Wells/D-димер/КТ (Т3.2, Т2.4)
- Инсульт: внезапный очаговый дефицит → КТ, окно реперфузии (Т3.3/Т3.9, Т2.9)
- Острая ишемия конечности; разрыв АБА (пульсирующая масса) (Т3.8, Т2.4)

**Дыхание/кислород**
- Гипоксемия, напряжённый пневмоторакс, анафилаксия (адреналин), тяжёлый бронхоспазм (Т3.2)

**Инфекция/воспаление**
- Сепсис/септический шок (SOFA≥2; вазопрессоры+лактат>2) (Т2.8, Т3.10)
- Менингит (лихорадка+ригидность+спутанность); фебрильная нейтропения (Т3.3, Т2.8)
- Гигантоклеточный артериит (>50, головная боль, зрение) → стероиды срочно (Т3.10)

**Живот/хирургия**
- Перитонит, перфорация, мезентериальная ишемия (боль ≫ находки), странгуляция, разрыв
  внематочной (Т3.8)
- Острый холангит (триада Шарко) (Т3.11)

**Метаболическое/неотложное**
- Гипогликемия (глюкоза каждому со спутанностью) (Т3.3, Т2.9)
- Гиперкалиемия с ЭКГ-изменениями (кальций) (Т2.5)
- Тяжёлая гипонатриемия / слишком быстрая коррекция (Т2.5)
- ДКА/тяжёлый ацидоз; эпистатус (>5 мин) (Т2.6, Т2.9)
- Острая печёночная недостаточность (желтуха+энцефалопатия+↑INR) (Т3.11)

**Онко/гематология**
- Растущая масса/подозрение на рак → биопсия (Т1.1)
- Анемия+потеря веса у пожилого → ЖКТ-рак (Т3.5, Т2.3)
- Кровотечение; ДВС (Т2.4)

**Травма/гериатрия**
- Травма головы на антикоагулянтах → КТ (Т3.12)
- Перелом шейки бедра (Т3.12)

## E. Сводка порогов и маркёров (проверено, июнь 2026)
> Пороги — ориентиры, сверять с локальной лабораторией и обновлениями.

**Сердце / сосуды**
- hs-тропонин: серийно 0 и 1–2 ч; диагноз ИМ — динамика со значением >99-го перцентиля (Т3.1)
- HEART score: 0–3 низкий риск (Т3.1)
- BNP <100 / NT-proBNP <300 — острая СН маловероятна; >500 — вероятна; 100–500 серо (Т3.2)
- ЛПНП-цели: <3,0 / <2,6 / <1,8 / <1,4 ммоль/л по росту риска; ApoB точнее (Т1.12)
- Canadian Syncope Risk Score <1 — низкий риск (~1% за 30 дней) (Т3.4)
- Ортостаз: падение САД ≥20 мм рт. ст. (Т3.12, Т3.4)

**Свёртывание**
- D-димер <500 нг/мл; чувствителен, неспецифичен; ценен отрицательный при низкой
  претестовой вероятности (Wells) (Т2.4, Т3.1/3.2)
- INR 2–3 — цель варфарина (Т2.4)

**Электролиты / КЩР**
- Na <135 / >145; коррекция гипонатриемии ≤8 ммоль/л/24ч (осмотическая демиелинизация) (Т2.5)
- K >5,2; ЭКГ-изменения с ≥6,0 (заострённые T→QRS→синусоида); кальций стабилизирует (Т2.5)
- pH 7,35–7,45; анионный провал 12±2 (поправка +2,5/−1 г/дл альбумина); Винтер 1,5×HCO₃+8±2
  (Т2.6)

**Инфекция**
- Сепсис (Sepsis-3): органная дисфункция, SOFA≥2; шок: вазопрессоры для САД≥65 + лактат>2 (Т2.8)
- CRP >100 склоняет к бактериальному; прокальцитонин/IL-6 выше при бактериальном (Т2.8)
- Surviving Sepsis 2021: против qSOFA как единственного скрининга (NEWS2) (Т2.8)
- FUO: t >38,3 °C, >3 недель, без диагноза после адекватного старта (Т3.10)

**Неврология**
- Тромболизис ≤4,5 ч (альтеплаза/тенектеплаза); тромбэктомия ≤24 ч (по перфузии); АД <185/110
  (Т2.9, Т3.3)
- Эпистатус: судорога >5 мин или серия без восстановления (Т2.9)
- HINTS при ОВС: нормальный head impulse — тревожен (за центральное) (Т3.9)

**Обмен / вес / печень**
- Потеря веса значима: >5% (или ~5 кг) за 6–12 мес (Т3.5)
- Усталость: депрессия ~18,5% (частая), рак ~0,6%, анемия ~2,8% (Т3.6)
- Желтуха при билирубине >2–3 мг/дл; прямой >2 или >20% общего → конъюгированная (Т3.11)
- Функция печени = INR + альбумин (не АЛТ/АСТ/ЩФ) (Т3.11)
- GLP-1: ~8 кг жира / ~5 кг тощей массы; сохранять мышцу — белок 1,2–1,6 г/кг + нагрузка (Т2.12)

**Аутоиммунитет**
- анти-dsDNA чувствителен лишь на ~40–80%; CRP низок при волчанке (высокий → инфекция)
  (Т1.8, Т2.8)

## Четыре правила честности (общие для всей трилогии)
1. **Имя — не диагноз, ищи механизм.** Жалоба и «энергия» — как выглядит, не что есть.
2. **У каждого решения — измеримый маркёр.** Нет теста, подтверждающего И опровергающего — это
   догадка.
3. **Сними маску, прежде чем лечить.** Один признак рождается разными двигателями.
4. **Знай границу.** Где нужен скальпель, реанимация или коллега — рамка замолкает.

> Биохимия, пороги, окна и красные флаги — доказательная медицина. «Энергии» Пак —
> рамка-сортировщик, не основание для лечения. Вектор = направление + класс; препарат, доза и
> решение по живому человеку — за лечащим врачом.
