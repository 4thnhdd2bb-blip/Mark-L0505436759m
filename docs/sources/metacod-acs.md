## ОСТРЫЙ КОРОНАРНЫЙ СИНДРОМ (ОКС) — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и неотложное лечение ОКС: здесь реальная
помощь, и здесь цена ошибки — часы. Поверх — фильтры METACOD (двигатель, мембрана, маркёр,
граница). Данные сверены (2025 ACC/AHA по ОКС, 2023 ESC, июнь 2026; сверять локально). Препарат,
доза, решение — лечащий врач/неотложная бригада.

> Прикладной разбор болезни для направления 1 (кардиология). **ОКС — красный флаг главы «Боль в

## 1. Что это в системе: бляшка прорвалась, тромб перекрыл поток
ОКС — **острая катастрофа атеросклероза:** нестабильная бляшка разрывается или эрозируется, на
ней образуется тромб (Свёртывание, Т2.4), и коронарный поток резко падает → ишемия/некроз
миокарда. Два двигателя сходятся остро: **Атеросклероз (Т1.12)** дал бляшку, **Свёртывание
(Т2.4)** дало тромб. Мембранно (рамка) — разрыв «склеротической» поверхности (M-S) с острым
тромбозом; это уже не хронический вектор, а **граница — неотложность.**

ОКС — континуум одной природы по тяжести закупорки:
- **Нестабильная стенокардия** — ишемия без некроза (тропонин не повышен);
- **NSTEMI** — инфаркт без подъёма ST (тропонин повышен, ST не поднят);
- **STEMI** — полная окклюзия, подъём ST, наибольшая срочность.

## 2. Маркёр: диагноз ставится тремя вещами сразу
Диагноз и сортировка ОКС — по **клиника + ЭКГ + тропонин:**
- **Клиника:** загрудинная боль/давление, часто в покое >20 мин, иррадиация (рука/челюсть), пот,
  тошнота, одышка; атипично у женщин/диабетиков/пожилых (эквиваленты — одышка, слабость). Спектр
  — от боли до кардиогенного шока и остановки.
- **ЭКГ срочно (и повторно):** подъём ST → STEMI-путь; депрессия ST/инверсия T/норма →
  NSTE-ACS-путь.
- **Высокочувствительный тропонин серийно (0/1–2 ч)** — динамика подтверждает инфаркт; единичное
  значение не исключает.
- (MINOCA — инфаркт без обструктивных коронарных артерий — отдельная категория; искать причину.)

## 3. Вектор: неотложное лечение
### 3.1. STEMI — время = миокард
- **Немедленная реперфузия:** первичное ЧКВ (PPCI) — предпочтительно, как можно быстрее; если ЧКВ
  недоступно в срок — **тромболизис** с последующим переводом;
- параллельно: антиагреганты, антикоагулянт, кислород при гипоксии, обезболивание; контроль
  аритмий.

### 3.2. NSTE-ACS — стратификация и инвазивная стратегия
- Риск-стратификация → инвазивная коронарография/реваскуляризация (сроки по риску; при очень
  высоком риске — немедленно);
- антитромботическая терапия (ниже); НФГ — класс 1 для антикоагуляции.

### 3.3. Антитромботическая терапия (ядро ОКС)
- **Двойная антиагрегантная терапия (DAPT):** аспирин + ингибитор P2Y12 (тикагрелор или прасугрел
  предпочтительны; ⚠️ **прасугрел нельзя при инсульте/ТИА в анамнезе**; клопидогрел при
  необходимости/высоком риске кровотечения);
- длительность DAPT по умолчанию — **1 год** без высокого риска кровотечения; при высоком риске
  кровотечения — короче (индивидуально);
- если нужна постоянная антикоагуляция (например, ФП): короткая DAPT (1–4 нед) → затем
  антикоагулянт + один антиагрегант (предпочтительно клопидогрел);
- антикоагулянт в острую фазу (НФГ и др.).

### 3.4. После стабилизации — вторичная профилактика (та же модификация атеросклероза)
- **Статин высокой интенсивности до ЛПНП <55** (±эзетимиб/PCSK9);
- β-блокатор, иАПФ/БРА (особенно при сниженной ФВ/диабете/гипертонии), МРА при ФВ↓ + СН/диабете;
  SGLT-2 при показаниях;
- контроль факторов (АД, диабет, курение, вес, реабилитация); колхицин — у отдельных.

### 3.5. На языке мембраны (рамка)
Острый вектор = **открыть сосуд + остановить тромб** (реперфузия + антитромботики, Т2.4); после —
вернуться к хроническому вектору модификации бляшки (M-A→M-S). Рамка тут вторична: это граница,
действуют протоколы и время.

## 4. Граница: это и ЕСТЬ неотложность
ОКС — сам по себе красный флаг главы «Боль в груди» (Том 3, гл. 1). Любая подозрительная
загрудинная боль в покое → **ЭКГ + тропонин немедленно, не амбулаторно.** Осложнения (аритмии,
кардиогенный шок, механические разрывы, остановка) — реанимационные протоколы. Дифференцировать
угрожающие имитаторы (**расслоение аорты — НЕ тромболизировать!**, ТЭЛА) — Том 3, гл. 1.

## 5. Перекрёстки
- **ИБС/стабильная стенокардия** — хроническая форма; ОКС — её срыв.
- **Свёртывание (Т2.4)** — тромботическое ядро; баланс с риском кровотечения.
- **Сердечная недостаточность** — частый исход инфаркта.
- **ФП** — если сопутствует, особая схема «антикоагулянт + антиагрегант».
- **Дислипидемия/кластер** — вторичная профилактика.

## 6. Карманная версия
1. ОКС = разрыв бляшки + тромб (Атеросклероз Т1.12 + Свёртывание Т2.4); континуум: нестабильная
   стенокардия → NSTEMI → STEMI.
2. Диагноз — **клиника + ЭКГ + тропонин;** ЭКГ срочно и повторно; тропонин серийно.
3. **STEMI → немедленная реперфузия** (PPCI; тромболизис если ЧКВ недоступно).
4. **NSTE-ACS → риск-стратификация + инвазивная стратегия.**
5. **Антитромботика:** DAPT (аспирин + тикагрелор/прасугрел; **прасугрел не при инсульте**), по
   умолчанию 1 год; при потребности в антикоагуляции — особая схема; НФГ остро.
6. После: вторичная профилактика — статин до ЛПНП <55, β-блок, иАПФ/БРА, контроль факторов,
   реабилитация.
7. Граница: это неотложность — боль в покое → ЭКГ+тропонин немедленно; **исключить расслоение
   (не тромболизировать!).** Решение и действия — неотложная бригада/врач.

> Континуум ОКС, диагностика (клиника+ЭКГ+тропонин), реперфузия STEMI, DAPT 1 год,
> прасугрел-противопоказание — доказательная медицина (2025 ACC/AHA по ОКС, 2023 ESC, сверено
> июнь 2026; сверять локально). Двигатели Атеросклероз/Свёртывание, мембрана M-S, энергии —
> рамка-навигатор METACOD, не основание для назначения; ОКС ведётся по неотложным протоколам.
> Вектор = направление + класс; препарат, доза и решение — за лечащим врачом/бригадой.
