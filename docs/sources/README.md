# Источники (sources)

Сюда складываем первоисточники, которые Claude должен изучить:
**монографию по мембранам** и любые материалы, перенесённые из других проектов.

## Как добавить файлы
- Через сайт GitHub: открыть эту папку → **Add file → Upload files** →
  перетащить файлы → **Commit changes**.
- Поддерживаются: PDF, Word (.docx), текст (.txt), Markdown (.md) и др.
  Claude умеет читать PDF и текст.

## Приоритет изучения
1. **Монография по мембранам** — изучается ПЕРВОЙ и целиком.
2. Остальные материалы — анализируются уже через призму мембран.

## Загруженные источники
- **`metacod.md`** — METACOD: Алгоритм клинического мышления (Dr. Mark Litvak + Claude,
  июнь 2026). Краткий фундамент: «Поток × Граница», биохимия мембран, метод рассуждения
  (видимость → маркёр → двигатель → вектор), 8 шагов приёма, 12 ветвей, биохимический
  справочник. **Изучать первым.**
- **`metacod-tom1.md`** — МОНОГРАФИЯ METACOD, Том первый: «Двенадцать процессов-двигателей».
  Полный детальный разбор всех 12 ветвей (по схеме: место в системе → патофизиология/
  биохимия → симптоматика пациент→врач → опросник Пак → осмотр → маркёры с порогами →
  дифдиагноз → маски → тактика без анализов → фон → вектор → иллюстрации → красные флаги).
  Это основной клинический справочник системы.
- **`metacod-tom2.md`** — МОНОГРАФИЯ METACOD, Том второй: «От двигателей к постели больного».
  Применение (метод 5 шагов; несколько двигателей: цепочки/перекрёстки/конфликт векторов;
  разбор случаев) + 6 НОВЫХ двигателей (свёртывание, электролиты, КЩР, боль, инфекция,
  неврология) + карта «двигатель→класс→маркёр ответа», граница METACOD↔EBM и **глава GLP-1
  вглубь** (hard-stop, красные линии, конфликт векторов — напрямую закрывает направление 2).

### 12 процессов-двигателей (карта монографии)
1. Рак (Ветер-деление: не дозрел + не выключился) — прерывать
2. Фиброз (дозрел, не выключился) — убрать драйвер
3. Гиперплазия (много + зрелых) — сдержать по драйверу
4. Ветер-нервы (вегетативная гипервозбудимость) — снять маски, по окраске
5. Ветер-клиренс (дренаж/лимфа) — поддержать отток
6. Влажность-вода (острая жидкость/отёк) — лечить по причине
7. Влажность-обмен (метаб. синдром, диабет) — снизить запас; **GLP-1 hard-stop**
8. Сухость-иммунитет (аутоиммунная атака) — приглушить иммунитет
9. Сухость-атрофия (саркопения, кахексия) — нарастить; **GLP-1 hard-stop**
10. Тепло (ось: воспаление/разгон) — острое не трогать, хроническое гасить
11. Холод (ось: затухание; маска гипотиреоза) — ТТГ первым
12. Атеросклероз-каскад (Тепло + липид + деление) — бить по трём ветвям
