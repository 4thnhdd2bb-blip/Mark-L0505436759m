# Источники (sources)

Сюда складываем первоисточники, которые Claude должен изучить:
**монографию по мембранам** и любые материалы, перенесённые из других проектов.

## Как добавить файлы
- Через сайт GitHub: открыть эту папку → **Add file → Upload files** →
  перетащить файлы → **Commit changes**.
- Поддерживаются: PDF, Word (.docx), текст (.txt), Markdown (.md) и др.
  Claude умеет читать PDF и текст.

## Приоритет изучения
1. **Монография по мембранам** — изучается ПЕРВОЙ и целиком.
2. Остальные материалы — анализируются уже через призму мембран.

> Пока папка пустая. После загрузки файлов перечислим их здесь.
