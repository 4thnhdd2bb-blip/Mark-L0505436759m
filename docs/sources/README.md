# Источники (sources)

Сюда складываем первоисточники, которые Claude должен изучить:
**монографию по мембранам** и любые материалы, перенесённые из других проектов.

## Как добавить файлы
- Через сайт GitHub: открыть эту папку → **Add file → Upload files** →
  перетащить файлы → **Commit changes**.
- Поддерживаются: PDF, Word (.docx), текст (.txt), Markdown (.md) и др.
  Claude умеет читать PDF и текст.

## Приоритет изучения
1. **Монография по мембранам** — изучается ПЕРВОЙ и целиком.
2. Остальные материалы — анализируются уже через призму мембран.

## Загруженные источники
- **`metacod.md`** — METACOD: Алгоритм клинического мышления (Dr. Mark Litvak + Claude,
  июнь 2026). Краткий фундамент: «Поток × Граница», биохимия мембран, метод рассуждения
  (видимость → маркёр → двигатель → вектор), 8 шагов приёма, 12 ветвей, биохимический
  справочник. **Изучать первым.**
- **`metacod-tom1.md`** — МОНОГРАФИЯ METACOD, Том первый: «Двенадцать процессов-двигателей».
  Полный детальный разбор всех 12 ветвей (по схеме: место в системе → патофизиология/
  биохимия → симптоматика пациент→врач → опросник Пак → осмотр → маркёры с порогами →
  дифдиагноз → маски → тактика без анализов → фон → вектор → иллюстрации → красные флаги).
  Это основной клинический справочник системы.
- **`metacod-tom2.md`** — МОНОГРАФИЯ METACOD, Том второй: «От двигателей к постели больного».
  Применение (метод 5 шагов; несколько двигателей: цепочки/перекрёстки/конфликт векторов;
  разбор случаев) + 6 НОВЫХ двигателей (свёртывание, электролиты, КЩР, боль, инфекция,
  неврология) + карта «двигатель→класс→маркёр ответа», граница METACOD↔EBM и **глава GLP-1
  вглубь** (hard-stop, красные линии, конфликт векторов — напрямую закрывает направление 2).
- **`metacod-tom3.md`** — МОНОГРАФИЯ METACOD, Том третий: «От жалобы к диагнозу».
  ОБРАТНЫЙ поиск: от недифференцированной жалобы назад к механизму, **красные флаги первыми**.
  12 предъявлений (боль в груди, одышка, спутанность/делирий, обморок, потеря веса, усталость,
  отёк, острый живот, головокружение, ЛНГ, желтуха, падения у пожилого) — с шкалами (HEART,
  Wells, ADD-RS, CSRS, HINTS, TiTrATE), порогами и алгоритмами. Это вход в систему через то,
  что пациент реально произносит.
- **`metacod-index.md`** — СКВОЗНОЙ УКАЗАТЕЛЬ трилогии (навигатор). Пять входов: указатель
  двигателей (А), указатель предъявлений (B), быстрая таблица «жалоба→двигатели→глава» (C),
  единый стоп-лист красных флагов (D), сводка всех порогов и маркёров в одном месте (E).
  Лучшая точка старта для навигации по базе знаний и для маршрутизации в программе.
- **`metacod-membrane.md`** — СПУТНИК ТРИЛОГИИ: «Мембрана». Закрывает ядро системы.
  Часть I — НАУКА (липидный бислой, состав/текучесть/потенциал, перекисное окисление, ферроптоз,
  маркёры MDA/4-HNE/GSH/фазовый угол — доказательно). Часть II — РАМКА: **6 типов мембран**
  (M-0 норма · M-A1/M-A2 анаболические-щелочные · M-D1/M-D2 катаболические-кислые · M-S
  склеротическая), раскладка болезней/энергий/12 ветвей по мембранам, виды коррекции.
  Часть III — границы (что наука, что рамка). ⚠️ pH крови 7,35–7,45 — инвариант, не «тип».
  Связь «двигатель→мембрана→pH→вектор» сведена в `docs/membranes.md`.
- **`metacod-glp1-program.md`** — ПРИКЛАДНОЙ разбор для направления 2: полная программа снижения
  веса на GLP-1 (семаглутид/тирзепатид/лираглутид) — отбор, титрация, 5 контуров сопровождения
  (белок + силовая обязательны), ВСЕ побочные эффекты с ведением через фильтры METACOD
  (двигатель/мембрана/граница), противопоказания и стоп-сигналы. Сводка — в `docs/drugs.md`.
- **`metacod-diabetes.md`** — ПРИКЛАДНОЙ разбор болезни (первый worked example): сахарный диабет
  по полной схеме (имя→механизм→маска→маркёр→вектор→граница). Доказательная схема ADA 2025–26
  (метформин/SGLT-2/GLP-1/инсулин, «лечить все четыре»), развилка 1 vs 2 тип (M-A vs M-D),
  осложнения-цепочки, границы (ДКА/ГГС/гипогликемия). **Образец-шаблон для направления 1.**
- **`metacod-hypertension.md`** — ПРИКЛАДНОЙ разбор болезни: гипертония ВСЕХ видов (первичная,
  вторичные — полный список со скринингом, резистентная, белого халата/маскированная,
  изолированная систолическая, кризы). Пороги 2025 AHA/ACC, диагноз 130/80 вне офиса, первая
  линия (тиазид/БКК/иАПФ/БРА), обновление термина (urgency упразднён), опасные сочетания
  (Triple Whammy, иАПФ+БРА). Мембрана M-A→M-S.
- **`metacod-thyroid.md`** — ПРИКЛАДНОЙ разбор болезни: щитовидная железа (гипо- и гипертиреоз)
  как ось Холод↔Тепло (M-D↔M-A). Каскад ТТГ→свТ4/Т3, антитела (анти-ТПО/TRAb), субклинические
  состояния (пороги лечения), особые ситуации (беременность, пожилые, амиодарон), границы
  (микседематозная кома, тиреотоксический криз). **Ключевой узел «снять маску»** (щитовидка —
  великий имитатор усталости/депрессии/дислипидемии/тревоги/аритмии/похудания).

- **`metacod-cardiorenal-cluster.md`** — кардио-ренально-метаболический кластер (диабет+почки+
  гипертония+сердце): 4 столпа органозащиты, полезные синергии и **ОПАСНЫЕ комбинации лекарств**
  (Triple Whammy, иАПФ+БРА, гиперкалиемия, sick-day). Прямой материал для упреждения взаимодействий.
- **`metacod-adrenal.md`** — надпочечники: первичный альдостеронизм, Кушинг, Аддисон (адреналовый
  криз!), феохромоцитома (α-блок до β). Площадка «снять маску».
- **`metacod-calcium.md`** — кальций/паращитовидные: гипер- (ПТГ-зависимая vs рак) и
  гипокальциемия (магний обязателен), кризы.
- **`metacod-pituitary.md`** — гипофиз: пролактинома (агонист дофамина), акромегалия,
  гипопитуитаризм (кортизол раньше Т4!), дефицит вазопрессина (бывший несахарный диабет).
- **`metacod-osteoporosis.md`** — остеопороз (Сухость-атрофия, M-D кости): FRAX, бисфосфонаты/
  деносумаб/анаболики, последовательность, связь с падениями.
- **`metacod-dyslipidemia.md`** — дислипидемия (топливо атеросклероза, M-A→M-S): ApoB/Lp(a),
  цели ЛПНП по риску 2026, лестница статин→эзетимиб/бемпедоевая→PCSK9.
- **`metacod-heart-failure.md`** — сердечная недостаточность (финал других двигателей, M-A→M-S):
  классы ФВ (HFrEF/HFmrEF/HFpEF), **четыре столпа** (ARNI+β-блок+МРА+SGLT-2), BNP, отёк лёгких.
- **`metacod-chronic-coronary-disease.md`** — ИБС/стабильная стенокардия: две цели (прогноз vs
  симптомы), КТ-коронарография, статин до ЛПНП<55, место реваскуляризации.
- **`metacod-acs.md`** — ОКС (разрыв бляшки + тромб; Т1.12+Т2.4): континуум НС→NSTEMI→STEMI,
  клиника+ЭКГ+тропонин, реперфузия STEMI, DAPT, **расслоение не тромболизировать!** Неотложность.
- **`metacod-atrial-fibrillation.md`** — фибрилляция предсердий (Ветер Т1.4 + ремоделирование M-S):
  **AF-CARE**, CHA₂DS₂-VA(Sc), DOAC (кроме мех.клапана/митрального стеноза), аблация.
- **`metacod-valvular-disease.md`** — клапанные пороки (граница потока, M-S): стеноз vs
  регургитация, решение по симптомы+ФВ+тяжесть, TAVR/SAVR, варфарин при митральном стенозе.
- **`metacod-gerd-peptic-ulcer.md`** — ГЭРБ и язвенная болезнь (агрессия↔защита барьера): ИПП/
  вонопразан, H. pylori (висмут-четверная), НПВС, тревожные симптомы → эндоскопия.
- **`metacod-ibd.md`** — ВЗК (Крон/ЯК; Сухость-иммунитет + Тепло, фиброз M-S): кальпротектин,
  заживление слизистой, биологики/малые молекулы, C. difficile перед иммуносупрессией.
- **`metacod-liver-masld-cirrhosis.md`** — печень: MASLD/MASH→фиброз→цирроз (M-A→M-S). Прогноз по
  фиброзу (FIB-4/эластография), резметиром, функция = INR/альбумин/билирубин, осложнения цирроза.
- **`metacod-pancreatitis.md`** — панкреатит острый/хронический (Тепло→фиброз M-S): диагноз 2 из 3,
  умеренная инфузия, без проф. антибиотиков, ЭРХПГ только при холангите; диабет 3c.
- **`metacod-gallstones.md`** — желчнокаменная болезнь (стерольный камень + застой + Тепло):
  локализация камня + инфекция; триада Шарко = холангит (декомпрессия ≤24 ч).

- **`metacod-ckd.md`** — ХБП (путь к M-S, фиброз фильтра): двумерное стадирование (eGFR G1–G5 +
  альбуминурия A1–A3), вектор KDIGO 2024 (SGLT-2/РААС/финеренон/GLP-1), ожидаемый спад eGFR ≤30%,
  нефротоксин-стюардшип/sick-day, осложнения.
- **`metacod-aki.md`** — ОПП (обратимо!): KDIGO-стадирование (креатинин/диурез), триада пре/рено/
  постренального, осадок мочи + УЗИ как ключ, этиотропный вектор, диализ **A-E-I-O-U**.
- **`metacod-glomerular.md`** — гломерулярные болезни (повреждён фильтр-клубочек): развилка
  нефротический↔нефритический, осадок+серология+биопсия, две линии (нефропротекция + иммуносупрессия
  по типу), **БПГН = неотложно**, тромбориск при нефротическом.
- **`metacod-nephrolithiasis.md`** — нефролитиаз (кристаллический осадок + застой): низкодозная
  безконтрастная КТ, изгоняющая терапия α-блокатором, профилактика по типу камня;
  **обструктивный пиелонефрит = неотложная декомпрессия** (структурный аналог холангита).
- **`metacod-electrolytes-acidbase-renal.md`** — электролиты и КЩР (почечный узел, разворот Т2.5/
  Т2.6): калий (гипер- порядок кальций→инсулин/β2→диализ), натрий=вода (медленная коррекция), КЩР
  (анионный провал), кальций/фосфат/магний. ⚠️ **pH крови 7,35–7,45 — инвариант, не «тип мембраны».**

- **`metacod-copd.md`** — ХОБЛ (Тепло→ремоделирование M-S + эмфизема, фиксированная обструкция):
  спирометрия ОФВ₁/ФЖЕЛ<0,70, группы GOLD ABE, LABA+LAMA/тройная, ICS по эозинофилам; отказ от
  курения — единственное, меняющее течение; тактика обострения.
- **`metacod-asthma.md`** — бронхиальная астма (Ветер Т1.4 + воспаление, обратимый спазм): GINA
  2025 — **SABA-монотерапия отменена**, реливер всегда с ICS; Трек 1 (ICS-формотерол AIR/MART);
  биологики по фенотипу; нормализация CO₂ при приступе — тревога.
- **`metacod-pneumonia.md`** — пневмония (Инфекция + Тепло на газообменной мембране): где приобретена
  + тяжесть (CURB-65), эмпирический антибиотик по месту с деэскалацией, стероид при тяжёлой ВП;
  снять маску (ТЭЛА, отёк лёгких, рак).
- **`metacod-pulmonary-embolism.md`** — ТЭЛА (Свёртывание Т2.4, тромб в лёгочном русле): диагностика
  по вероятности (Wells/PERC/D-димер/КТ-ангиопульмонография), антикоагуляция (DOAC) ≥3 мес;
  **массивная (шок) → тромболизис/эмболэктомия**.
- **`metacod-ild.md`** — интерстициальные болезни лёгких/лёгочный фиброз (Фиброз Т1.2 → M-S,
  рестрикция): КТВР (UIP→ИЛФ) + DLCO, мультидисциплинарный диагноз; развилка воспаление↔фиброз;
  антифибротики при ИЛФ, ⚠️ иммуносупрессия при ИЛФ вредна.
- **`metacod-rheumatoid-arthritis.md`** — ревматоидный артрит (Сухость-иммунитет + Тепло, эрозивный
  синовит): РФ/анти-CCP, treat-to-target, метотрексат-якорь + стероид коротко, биологики/JAK;
  ускоренный атеросклероз; септический артрит — исключить пункцией.
- **`metacod-sle.md`** — СКВ (системная аутоиммунная многоорганная атака): ANA/анти-dsDNA/анти-Sm/
  комплемент, **гидроксихлорохин всем**, терапия по органу; люпус-нефрит/нейро-СКВ/АФС — границы.
- **`metacod-gout.md`** — подагра (кристаллы мочевой кислоты, метаболический корень Т1.7 → Тепло):
  пункция с кристаллами + исключить инфекцию; приступ (НПВС/колхицин/стероид); аллопуринол до урата
  <6 мг/дл с профилактикой; не лечить бессимптомную гиперурикемию.
- **`metacod-spondyloarthritis.md`** — спондилоартриты (осевой скелет/энтезит, HLA-B27, анкилоз):
  воспалительная боль в спине, МРТ сакроилеита; НПВС + упражнения, биологики по фенотипу
  (метотрексат не работает на осевой); увеит/перелом ригидного позвоночника — границы.
- **`metacod-vasculitis.md`** — васкулиты (иммунная атака на стенку сосуда, по калибру): ANC,
  биопсия; индукция (стероид ± ритуксимаб/циклофосфамид); ⚠️ **гигантоклеточный артериит = немедленно
  стероиды до биопсии** (слепота); лёгочно-почечный синдром.
- **`metacod-anemia.md`** — анемии (признак, не диагноз; чаще Сухость-атрофия эритропоэза): два
  ключа **MCV + ретикулоциты**, ферритин; лечение по причине (железодефицит → искать источник/рак);
  TTP/острая кровопотеря — границы.
- **`metacod-thrombocytopenia-hemostasis.md`** — тромбоцитопении и гемостаз (сторона кровоточивости
  Свёртывания Т2.4): мазок-ключ (шистоциты→TTP, бласты→лейкоз); ⚠️ **TTP = плазмаобмен, не
  тромбоциты**; HIT-парадокс; гемофилия/болезнь Виллебранда.
- **`metacod-thrombophilia-vte.md`** — тромбофилии и ВТЭ (сторона тромбоза Свёртывания, триада
  Вирхова): Wells/D-димер/УЗИ; избирательное тестирование тромбофилии; антикоагуляция (DOAC; варфарин
  при антифосфолипидном); длительность по провокации.
- **`metacod-leukemia.md`** — лейкозы (деление клона костного мозга Т1.1–1.3): острый/хронический ×
  миелоидный/лимфоидный; бласты ≥20% = острый; BCR-ABL/ТКИ при ХМЛ; **фебрильная нейтропения/лизис/
  ОПЛ-DIC** — неотложности (онкогематология — навигатор, не режим терапии).
- **`metacod-lymphoma-myeloma.md`** — лимфомы и миелома (деление лимфоидного/плазматического клона):
  лимфома (биопсия узла, Ходжкина/НХЛ) vs миелома (**CRAB** — кальций/почка/анемия/кость, электрофорез);
  компрессия спинного мозга/гиперкальциемия — границы.

- **`metacod-stroke.md`** — инсульт (острое прерывание мозгового потока): ишемический vs
  геморрагический — **КТ разделяет, лечение противоположно**; тромболизис до 4,5 ч/тромбэктомия до
  24 ч; вторичная профилактика по причине (ФП→антикоагулянт). Время = мозг.
- **`metacod-epilepsy.md`** — эпилепсия/судороги (Ветер-нервы Т1.4, гиперсинхронный разряд): развилка
  спровоцированный↔неспровоцированный; обследование первого приступа; **эпистатус ≥5 мин →
  бензодиазепин с эскалацией**.
- **`metacod-headache.md`** — головные боли (первичные↔вторичные): **red flags первыми** (громоподобная→
  САК, менингизм→менингит, новая >50+↑СОЭ→ГКА); мигрень (триптаны/анти-CGRP), кластерная (кислород).
- **`metacod-neurodegenerative.md`** — нейродегенерация (Сухость-атрофия Т1.9): деменции (Альцгеймер/
  сосудистая/Леви/лобно-височная) и паркинсонизм (леводопа); ⚠️ снять маску обратимого (B12/ТТГ/
  лекарства/делирий).
- **`metacod-demyelinating-neuropathy.md`** — демиелинизирующие/нейропатии (Ветер-проводимость +
  Сухость-иммунитет): РС (МРТ/олигоклональные полосы, DMT; ⚠️ «склероз ЦНС» ≠ фиброзный M-S);
  нейропатии по паттерну; **Гийен-Барре → следить за дыханием**.
- **`metacod-sepsis.md`** — сепсис/септический шок (Инфекция + Тепло → падение потока, Sepsis-3):
  **hour-1 bundle** (лактат, посевы до антибиотика, антибиотик ≤1 ч, кристаллоид ≥30 мл/кг,
  вазопрессоры до САД≥65), контроль очага, деэскалация. Неотложность.
- **`metacod-uti.md`** — ИМП (цистит↔пиелонефрит, неосложнённые↔осложнённые): анализ/посев мочи;
  ⚠️ не лечить бессимптомную бактериурию (кроме беременности); **обструктивный пиелонефрит =
  неотложная декомпрессия**.
- **`metacod-skin-soft-tissue.md`** — инфекции кожи/мягких тканей (глубина+скорость; гнойная↔негнойная):
  абсцесс→дренаж, целлюлит→антибиотик; ⚠️ **некротизирующий фасциит** (боль непропорциональна осмотру)
  → немедленная хирургия.
- **`metacod-endocarditis-meningitis.md`** — эндокардит и менингит (глубокие очаговые инфекции):
  эндокардит (Duke-ISCVID 2023, посевы+ЭхоКГ, великий имитатор) и менингит (триада, ⚠️ **антибиотик
  немедленно не задерживая**, дексаметазон при пневмококке).
- **`metacod-antibiotics-stewardship.md`** — принципы антибиотикотерапии/резистентность (сквозной узел
  Инфекция): 5 правил стюардшипа (показание/спектр/доза/деэскалация+короткие курсы/мониторинг вреда);
  не лечить вирусное/колонизацию; не медлить при сепсисе.

## Прикладные разборы болезней (worked examples)
Растущая библиотека для направления 1: каждая болезнь — по единой схеме METACOD
(имя→механизм→маска→маркёр→вектор→граница), доказательный стержень + рамка-навигатор.
**Эндокринология:** диабет · щитовидка · надпочечники · кальций/паращитовидные · гипофиз ·
остеопороз · дислипидемия. **Кардиология:** гипертония · кардио-ренальный кластер · сердечная
недостаточность · ИБС/стенокардия · ОКС · фибрилляция предсердий · клапанные пороки.
**Гастроэнтерология/гепатология:** ГЭРБ/язва · ВЗК · печень (MASLD/цирроз) · панкреатит · желчные.
**Нефрология:** ХБП · ОПП · гломерулярные болезни · нефролитиаз · электролиты/КЩР (почечный узел).
**Пульмонология:** ХОБЛ · астма · пневмония · ТЭЛА · ИЗЛ/лёгочный фиброз.
**Ревматология:** ревматоидный артрит · СКВ · подагра · спондилоартриты · васкулиты.
**Гематология:** анемии · тромбоцитопении/гемостаз · тромбофилии/ВТЭ · лейкозы · лимфомы/миелома.
**Неврология:** инсульт · эпилепсия · головные боли · нейродегенерация · демиелинизирующие/нейропатии.
**Инфекционные:** сепсис · ИМП · кожа/мягкие ткани · эндокардит/менингит · антибиотикотерапия (сквозной узел).
**Направление 2:** программа GLP-1.

### 12 процессов-двигателей (карта монографии)
1. Рак (Ветер-деление: не дозрел + не выключился) — прерывать
2. Фиброз (дозрел, не выключился) — убрать драйвер
3. Гиперплазия (много + зрелых) — сдержать по драйверу
4. Ветер-нервы (вегетативная гипервозбудимость) — снять маски, по окраске
5. Ветер-клиренс (дренаж/лимфа) — поддержать отток
6. Влажность-вода (острая жидкость/отёк) — лечить по причине
7. Влажность-обмен (метаб. синдром, диабет) — снизить запас; **GLP-1 hard-stop**
8. Сухость-иммунитет (аутоиммунная атака) — приглушить иммунитет
9. Сухость-атрофия (саркопения, кахексия) — нарастить; **GLP-1 hard-stop**
10. Тепло (ось: воспаление/разгон) — острое не трогать, хроническое гасить
11. Холод (ось: затухание; маска гипотиреоза) — ТТГ первым
12. Атеросклероз-каскад (Тепло + липид + деление) — бить по трём ветвям

> Сюда же добавить авторскую монографию по самим мембранам (4 категории / 6 видов:
> нормальная, 2 анаболические-щелочные, 2 катаболические-кислые, MS-высохшая), когда
> будет готова — она уточнит ядро.
