# МОНОГРАФИЯ METACOD · Углублённый разбор · Ревматология

## СИСТЕМНАЯ КРАСНАЯ ВОЛЧАНКА (СКВ) — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение СКВ: здесь реальная помощь. Поверх
— фильтры METACOD (двигатель, мембрана, маска, маркёр, вектор, граница). Данные сверены (ACR 2025,
EULAR, июнь 2026; сверять локально). Препарат, доза, решение — ревматолог.

> Прикладной разбор болезни для направления 1 (ревматология). Связан с: `metacod-tom1.md` (Т1.8,
> Т1.10, Т1.12), `metacod-tom2.md` (гл. 4 свёртывание, гл. 8), `metacod-glomerular.md`,
> `metacod-thrombophilia-vte.md`, `metacod-rheumatoid-arthritis.md`, `metacod-osteoporosis.md`.

## 1. Что это в системе: иммунитет атакует много органов сразу
СКВ — системное аутоиммунное заболевание, при котором иммунная система (через аутоантитела и
иммунные комплексы) атакует **множество органов**: кожу, суставы, почки (люпус-нефрит), кровь,
серозные оболочки, ЦНС, сосуды. Двигатель — **Сухость-иммунитет (Т1.8)** в системной,
многоорганной форме + **Тепло (Т1.10)** воспаления; течение — волнообразное (обострения и
ремиссии). Это «великий имитатор» ревматологии — отсюда центральность фильтра «снять маску» и
наоборот, помнить о СКВ при необъяснённой многосистемности.

**Главный фильтр (маска):** многоликость → снять маску инфекций (могут имитировать И осложнять
СКВ), лекарственной волчанки, других системных болезней, гематологических и онкологических. И
наоборот: необъяснённая комбинация (сыпь + артрит + цитопения + почки) → думать о СКВ.

## 2. Маркёр: диагноз и активность
- **Клиника (многосистемная):** «бабочка» на лице/фотосенситивность, артрит (неэрозивный),
  серозит, нефрит, цитопении, неврологическое, язвы рта, алопеция, феномен Рейно;
- **Серология: ANA** (чувствителен, скрининг — почти всегда положителен), специфичные — **анти-
  dsDNA** (связь с активностью/нефритом), **анти-Sm** (специфичен); **комплемент C3/C4 снижен**
  при активности; **антифосфолипидные антитела** (риск тромбозов/потерь беременности — Т2.4);
- **органная оценка:** моча (протеинурия/осадок — люпус-нефрит, `metacod-glomerular.md`), кровь,
  функция органов;
- классификационные критерии ACR/EULAR; активность (по органам/индексам) — ведёт лечение.

## 3. Вектор: лечение (ACR 2025 — по органам)
- **Гидроксихлорохин — основа практически ВСЕМ с СКВ** (снижает обострения, защищает органы,
  улучшает выживаемость; ⚠️ офтальмологический скрининг — ретинотоксичность);
- **Глюкокортикоиды** — для контроля обострений, стремиться к минимальной дозе/отмене
  (кумулятивный вред);
- **Иммуносупрессия/таргетная — по органу и тяжести:**
  - артрит как ведущее → метотрексат;
  - более широкое органное вовлечение → микофенолат;
  - планирующим беременность → азатиоприн (совместим);
  - **тяжёлый люпус-нефрит / системный васкулит** → пульс-терапия глюкокортикоидами + индукция
    (микофенолат или циклофосфамид) ± биологики (белимумаб, анифролумаб);
- **сопутствующее:** фотозащита, вакцинация (до иммуносупрессии), сердечно-сосудистый риск (СКВ
  ускоряет атеросклероз — Т1.12), кость, контрацепция/планирование беременности,
  **антифосфолипидный синдром — антикоагуляция при тромбозах (Т2.4)**.

**На языке мембраны (рамка):** СКВ = системная аутоиммунная атака (Сухость-иммунитет + Тепло) на
многие органы. Вектор — базис гидроксихлорохином всем + погасить активность по органу (стероид
минимально + иммуносупрессия по тяжести/мишени) + защитить органы и сосуды.

## 4. Граница (НЕОТЛОЖНОЕ)
- **Тяжёлый люпус-нефрит / быстропрогрессирующий ГН** (`metacod-glomerular.md`) → срочная индукция;
- **нейропсихиатрическая СКВ** (судороги, психоз, инсульт), **тяжёлые цитопении** (гемолиз,
  тромбоцитопения), серозит с тампонадой, **катастрофический антифосфолипидный синдром**
  (множественные тромбозы — Т2.4) → неотложно;
- ⚠️ **инфекция на иммуносупрессии** — может имитировать обострение; различать (лихорадка → не
  рефлекторно усиливать стероид) — Том 2, гл. 8.

## 5. Перекрёстки
- **Гломерулярные болезни:** люпус-нефрит — ключевая мишень и прогноз.
- **Свёртывание (Т2.4):** антифосфолипидный синдром — тромбозы, потери беременности.
- **Сердечно-сосудистое (Т1.12):** ускоренный атеросклероз.
- **Инфекция (Том 2, гл. 8):** имитатор/осложнитель; скрининг перед иммуносупрессией.
- **Остеопороз/надпочечники:** стероид-индуцированные.

## 6. Карманная версия
1. СКВ = **системная аутоиммунная многоорганная атака** (Сухость-иммунитет Т1.8 + Тепло),
   волнообразная; «великий имитатор» — думать при необъяснённой многосистемности.
2. Маркёр: **ANA** (скрининг), **анти-dsDNA/анти-Sm**, низкий комплемент при активности; органная
   оценка (моча — нефрит); антифосфолипидные антитела.
3. **Вектор (ACR 2025): гидроксихлорохин всем** (+ офтальмоскрининг); стероид минимально;
   иммуносупрессия по органу (метотрексат — артрит; микофенолат — шире; азатиоприн — беременность;
   тяжёлый нефрит/васкулит → пульс + индукция ± биологики).
4. Сопутствующее: фотозащита, вакцинация до иммуносупрессии, сердечно-сосудистый риск, кость,
   антифосфолипидный синдром (антикоагуляция при тромбозах).
5. Граница: тяжёлый люпус-нефрит, нейро-СКВ, тяжёлые цитопении, катастрофический АФС, инфекция на
   терапии → неотложно/срочно.
6. Мембрана/энергия: системный аутоиммунный катаболизм; вектор = базис ГХХ + погасить по органу +
   защитить. Решение, препарат, доза — ревматолог.

> ANA/анти-dsDNA/анти-Sm/комплемент, гидроксихлорохин как базис всем, терапия по органу (ACR 2025),
> антифосфолипидный синдром, сердечно-сосудистый риск — доказательная медицина (ACR 2025, EULAR,
> сверено июнь 2026; сверять локально). Двигатели Сухость-иммунитет/Тепло, энергии — рамка-
> навигатор METACOD, не основание для назначения. Вектор = направление + класс; препарат, доза и
> решение — за ревматологом.
