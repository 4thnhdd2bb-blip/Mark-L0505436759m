## 1. Что такое СН в системе: насос не справляется с потоком
Сердечная недостаточность (СН) — неспособность насоса обеспечить поток при нормальном давлении
наполнения: либо сердце слабо качает (систолическая), либо плохо расслабляется/наполняется
(диастолическая). Итог — застой (назад: лёгкие → одышка, системно → отёки, печень) и/или
низкий выброс (вперёд: усталость, гипоперфузия). Узел ПОТОК × ГРАНИЦА: поток падает, давление
наполнения растёт, жидкость уходит за границу сосуда (Влажность-вода, Т1.6).

**Через фильтр двигателей:** СН — почти всегда **финал другого двигателя** (перекрёсток, Т2.2):
атеросклероз/инфаркт (Т1.12 — ишемическая кардиомиопатия), гипертония (Т1.12 → гипертрофия →
диастолическая СН), клапаны, аритмия (Т1.4), токсины/инфильтрация, обмен (Т1.7). Мембранно
(рамка) — миокард движется к фиброзу/ремоделированию (**M-S**) на фоне объёмной перегрузки
(M-A); вектор современной терапии — **затормозить ремоделирование, а не просто «выгнать воду».**

## 2. Классификация по фракции выброса (каркас лечения)
ФВ левого желудочка делит СН и определяет, что доказательно помогает:
- **HFrEF** — со сниженной ФВ (≤40%): есть «четыре столпа», меняющие прогноз;
- **HFmrEF** — с умеренно сниженной (41–49%): SGLT-2 (и слабее — остальные столпы);
- **HFpEF** — с сохранённой (≥50%): SGLT-2 доказательно; лечить застой и причины (гипертония,
  ожирение, ФП, апноэ).
Плюс стадии A→D (от риска до терминальной) — профилактика на стадии риска (лечить гипертонию,
диабет SGLT-2, Т1.7/Т1.12).

## 3. Маска: что снять прежде «просто СН»
СН — синдром, не диагноз. Найти причину и провокатор:
- **причина:** ишемия/инфаркт (коронарография по показаниям), гипертония, клапанный порок,
  аритмия (тахи-индуцированная), кардиомиопатии, инфильтрация (амилоидоз — не пропустить,
  меняет лечение), миокардит, токсины (алкоголь, химиотерапия), тиреотоксикоз/гипотиреоз
  (Т1.10/11), анемия, шунты;
- **провокатор декомпенсации:** несоблюдение терапии/соли, аритмия (ФП), ишемия, инфекция,
  **НПВС (задержка натрия!)**, почечная дисфункция, неконтролируемое АД.

## 4. Маркёр: диагноз и оценка
- **Натрийуретические пептиды:** BNP <100 / NT-proBNP <300 делают острую СН маловероятной;
  высокие — подтверждают (Том 3, гл. 2);
- **ЭхоКГ — ключ:** ФВ, структура, клапаны, диастолика, давления;
- ЭКГ, рентген, тропонин (ишемия), функция почек/электролиты (Т2.5), ТТГ, железо/ферритин
  (дефицит железа — лечить), при подозрении — поиск амилоидоза;
- оценка застоя клинически (вены шеи, хрипы, отёки, ортопноэ) и объёма.

## 5. Вектор: лечение
### 5.1. HFrEF — ЧЕТЫРЕ СТОЛПА (меняют прогноз)
Начать все четыре класса рано (по возможности ещё в стационаре), затем титровать до
максимально переносимых доз:
1. **ARNI** (сакубитрил/валсартан) — предпочтительно; при недоступности — иАПФ или БРА;
2. **β-блокатор** (доказательный — бисопролол/карведилол/метопролола сукцинат);
3. **МРА** (спиронолактон/эплеренон) — следить калий/почки;
4. **SGLT-2 ингибитор** (дапаглифлозин/эмпаглифлозин).
- **Диуретик** (петлевой) — для застоя/симптомов, но **не улучшает прогноз** (титровать по объёму).
- По показаниям: дефицит железа → в/в железо; ивабрадин, верицигуат, гидралазин/нитрат;
  устройства (ИКД/СРТ) по ФВ/QRS; трансплантация/поддержка — терминальная стадия.

### 5.2. HFmrEF и HFpEF
- **SGLT-2 — обоим** (доказательно через весь спектр ФВ);
- HFpEF: лечить причины и застой — гипертония (<130/80), ожирение (в т. ч. GLP-1 по профилю),
  ФП, апноэ; диуретик по застою; МРА/ARNI — отдельным подгруппам.

### 5.3. На языке мембраны (рамка)
Четыре столпа — это **антиремоделирующий вектор:** они тормозят фиброз/гипертрофию (движение к
M-S) и разгружают объём (M-A), а не просто «гонят воду» (это делает диуретик, не меняя прогноз).
Рамка совпадает с EBM по направлению; дозы и контроль калия/почек — строго EBM.

## 6. Граница (НЕОТЛОЖНОЕ)
- **Острый отёк лёгких / острая декомпенсация:** тяжёлая одышка, ортопноэ, гипоксемия → кислород/
  вентиляция, в/в петлевой диуретик, вазодилататоры по АД (Том 3, гл. 2);
- **Кардиогенный шок:** гипоперфузия + гипотензия → ОРИТ, инотропы/механическая поддержка;
- **Провокатор-катастрофа:** инфаркт (Том 3, гл. 1), тяжёлая аритмия, тампонада, ТЭЛА — свои
  протоколы;
- ⚠️ **НПВС противопоказаны** (задержка натрия, ухудшение СН и почек — Triple Whammy).

## 7. Перекрёстки
- **Кардио-ренально-метаболический кластер:** СН неотделима от почек и диабета (SGLT-2, МРА/
  финеренон); следить калий/eGFR.
- **ФП и СН** усиливают друг друга (контроль ритма/частоты + антикоагуляция).
- **Ишемия/клапаны как причина** — лечить причину (разборы «ИБС», «ОКС», «Клапаны»).
- **Дефицит железа, апноэ, щитовидка, амилоидоз** — снять маску, вести параллельно.

## 8. Карманная версия
1. СН — синдром: найти ФВ (HFrEF≤40 / HFmrEF 41–49 / HFpEF≥50), причину и провокатор.
2. Маркёр: BNP/NT-proBNP (низкий исключает острую СН) + ЭхоКГ; железо, ТТГ, амилоидоз.
3. **HFrEF → четыре столпа рано:** ARNI(/иАПФ-БРА) + β-блокатор + МРА + SGLT-2, титровать;
   диуретик для застоя (прогноз не меняет).
4. **HFmrEF/HFpEF → SGLT-2;** HFpEF — лечить причины и застой.
5. Граница: отёк лёгких/кардиогенный шок → неотложно; **НПВС нельзя.**
6. Мембрана/энергия: финал других двигателей; вектор = антиремоделирование + разгрузка объёма.
   Решение, препарат, доза — лечащий врач.

> Классы ФВ, четыре столпа, BNP-пороги, SGLT-2 через спектр ФВ — доказательная медицина
> (ACC/AHA/HFSA + ESC + NICE 2022–2025, сверено июнь 2026; сверять локально). Двигатели
> Атеросклероз/Влажность/Ветер, мембрана M-A/M-S, энергии — рамка-навигатор METACOD, не
> основание для назначения. Вектор = направление + класс; препарат, доза и решение — за лечащим
> врачом.
