## 1. Что такое дислипидемия в системе: топливо атеросклероза
Дислипидемия — избыток атерогенных липопротеинов, несущих холестерин в стенку сосуда. Это не
«болезнь цифры», а главное **модифицируемое топливо двигателя Атеросклероз (Т1.12):** атерогенные
частицы (ЛПНП и другие аполипопротеин-B-содержащие — ремнанты, Lp(a)) проникают в интиму,
окисляются, поглощаются макрофагами → бляшка. Мембранно (рамка) — **стерольный/анаболический
сдвиг сосудистой стенки (M-A) с исходом в склероз бляшки (M-S);** пересечение с обменом (Т1.7) и
воспалением (Тепло, Т1.10).
**Ключевая идея 2026:** риск несёт не только ЛПНП, а **вся масса атерогенных B-содержащих
частиц** — поэтому в оценку входят **ApoB** (число частиц) и **Lp(a)** (генетический фактор).

**Главный фильтр (маска):** прежде «первичной» дислипидемии — снять вторичные причины (раздел 3)
и помнить про **семейную гиперхолестеринемию** (очень высокий ЛПНП смолоду, семейный анамнез
ранних инфарктов).

## 2. Маркёр: липиды, ApoB, Lp(a), и оценка риска
**Липидная панель:** общий холестерин, ЛПНП (предпочтительно метод Мартина–Хопкинс), ЛПВП,
триглицериды, не-ЛПВП.
**Новое (2026):**
- **Lp(a)** — измерить хотя бы раз в жизни (генетический риск; при высоком — обследовать
  родственников);
- **ApoB** — выборочно для уточнения остаточного риска, особенно при триглицеридах >200, диабете,
  метаболическом синдроме, и при достигнутом ЛПНП <70 (ApoB точнее ЛПНП у этих групп).
**Оценка риска — каркас «CPR» (2026):** **Calculate** (риск калькулятором PREVENT-ASCVD, возраст
30–79, учитывает почку, без расовых коэффициентов, есть 30-летний риск) → **Personalize**
(обсудить с пациентом) → **Reclassify** (при неопределённости — кальциевый индекс коронарных
артерий, CAC).

## 3. Маска: вторичные причины и семейная форма
Снять прежде лечения «первичной»:
- **гипотиреоз** (классическая маска дислипидемии — ТТГ!), диабет/метаболический синдром, ХБП/
  нефротический синдром, холестаз, ожирение;
- лекарства (стероиды, некоторые диуретики/β-блокаторы, антиретровирусные), алкоголь;
- **семейная гиперхолестеринемия** — очень высокий ЛПНП с молодости + семейный анамнез ранних
  ССЗ; требует ранней агрессивной терапии и каскадного скрининга родни.

## 4. Вектор: цели и лечение (доказательная схема 2026)
**Образ жизни — всем:** питание (снижение насыщенных/транс-жиров), вес, движение, отказ от
курения, лечение диабета/гипертонии (это один кластер — разбор кардио-ренального кластера).

**Цели ЛПНП по уровню риска (2026 вернул конкретные цели):**
| Категория | Цель ЛПНП | Не-ЛПВП |
|---|---|---|
| Очень высокий риск (многократные крупные события АССЗ или 1 событие + множество факторов) | < 40 мг/дл (~1,0 ммоль/л) опционально, агрессивно — как минимум <55 | — |
| Вторичная профилактика / высокий риск | < 55 мг/дл (1,4 ммоль/л) | < 85 мг/дл |
| Промежуточный/повышенный первичный ориентир | < 70 мг/дл (1,8 ммоль/л) или ≥50% снижения | — |
| Базовый первичный | ≥30–50% снижения ЛПНП | — |

*(В ммоль/л: <1,4 / <1,8 / <2,6 по нарастанию благополучия риска.)*

**Когда начинать в первичной профилактике (PREVENT):** рассмотреть при 10-летнем риске 3–<5%
(пограничный), рекомендовать при 5–10% (промежуточный) и выше; статин молодым ≤30 при ЛПНП ≥160
или сильном семейном анамнезе.

**Лестница терапии:**
1. **Статин** (умеренной/высокой интенсивности по риску) — основа; первая линия снижения ЛПНП.
2. Не достигли цели → добавить **эзетимиб** и/или **бемпедоевую кислоту** (последняя — при
   непереносимости статинов, действует выше по пути синтеза, не даёт мышечных симптомов).
3. Высокий остаточный риск/цель не достигнута → **ингибитор PCSK9** (моноклональное антитело);
   инклисиран — изучается на исходы.
4. **Триглицериды:** очень высокие (≥1000 мг/дл / ≥11,3 ммоль/л) → риск панкреатита → снижать
   (фибрат, образ жизни); при стойко высоких на фоне риска АССЗ — статин остаётся основой.

**Особые группы:** диабет (статин практически всем взрослым с диабетом + риск); семейная
гиперхолестеринемия (рано и агрессивно, PCSK9 при необходимости); высокий Lp(a) (специфической
одобренной терапии пока нет — снижать общий B-зависимый риск; новые препараты в исследованиях).

## 5. Тот же вектор на языке мембраны (рамка)
- Дислипидемия = топливо **M-A→M-S** сосуда → вектор «убрать стерольный перегруз» (снизить
  атерогенные B-частицы) совпадает с доказательным (статин/эзетимиб/PCSK9).
- ⚠️ Но **холестерин не «враг по принципу чем меньше тем лучше»** (наука мембраны): он нужен
  мембране и стероидогенезу; цель — снизить атерогенную нагрузку по риску, а не обнулить. Рамочные
  добавки (омега-3 при высоких ТГ — есть и доказательные показания) — рядом, не вместо статина.
- **Беременность:** статины традиционно избегали (пересматривается) — решение врача.

## 6. Граница
- **Очень высокие триглицериды (≥1000 мг/дл)** → риск острого панкреатита (Том 3, гл. 8; Т2.7) →
  активно снижать.
- **ОКС/инсульт** — своя неотложность (Том 3, гл. 1, 3); липиды — вторичная профилактика после.
- **Семейная гиперхолестеринемия** — не «обычная дислипидемия»: ранний высокий риск, каскадный
  скрининг.
- **Мышечные симптомы на статине** — оценить (истинная миопатия редка; бемпедоевая кислота —
  опция), не отменять рефлекторно без оценки.

## 7. Карманная версия
1. **Маркёр:** липидная панель + Lp(a) однократно + ApoB выборочно (диабет, ТГ>200, достигнутый
   ЛПНП<70); оценка риска PREVENT (CPR: Calculate–Personalize–Reclassify через CAC).
2. **Снять маску:** гипотиреоз (ТТГ!), диабет, ХБП/нефротический, холестаз, лекарства; семейная
   гиперхолестеринемия (рано+агрессивно).
3. **Цели ЛПНП по риску:** вторичная профилактика/высокий — <55 мг/дл (1,4 ммоль/л); очень
   высокий — ещё ниже; первичный — ≥30–50% снижения.
4. **Лестница:** образ жизни → статин → +эзетимиб/бемпедоевая → PCSK9; очень высокие ТГ (≥1000) →
   профилактика панкреатита.
5. **Мембрана:** топливо M-A→M-S; снизить атерогенные B-частицы по риску — но холестерин не
   обнулять.
6. Решение, препарат, доза — лечащий врач.

> Цели ЛПНП по риску, ApoB/Lp(a), PREVENT-ASCVD, лестница нестатинов, порог ТГ для панкреатита —

> Двигатель Атеросклероз, мембрана M-A/M-S, энергии — рамка-навигатор METACOD, не основание для
> назначения. Вектор = направление + класс; препарат, доза и решение — за лечащим врачом.
