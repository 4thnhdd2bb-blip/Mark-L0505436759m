**Как читать.** Стержень — доказательная диагностика и лечение клапанных пороков: здесь реальная
помощь. Поверх — фильтры METACOD (двигатель, мембрана, маркёр, вектор, граница). Данные сверены
(ACC/AHA 2020/2021 + ESC/EACTS 2021 и обновления, июнь 2026; сверять локально). Препарат, доза,

## 1. Что это в системе: испорченная граница потока
Клапаны — **направляющие границы потока в сердце.** Поломка бывает двух типов:
- **Стеноз** — клапан не открывается (преграда потоку → перегрузка давлением выше клапана);
- **Регургитация (недостаточность)** — клапан не закрывается (обратный поток → перегрузка
  объёмом).
Двигатели: склероз/кальциноз (Атеросклероз-подобный, Т1.12 + фиброз Т1.2 → **M-S**) —
дегенеративный аортальный стеноз; ревматический/инфекционный (эндокардит), ишемический/
функциональный (дилатация). Мембранно — кальцинированный аортальный клапан = образцовая **M-S**
(склероз). Итог любого тяжёлого порока без лечения — сердечная недостаточность и аритмии (ФП).

**Главный принцип ведения:** решение об операции/вмешательстве определяют **симптомы + ФВ +
тяжесть по ЭхоКГ**, а не «само по себе» наличие порока.

## 2. Маркёр: как оценивают
- **ЭхоКГ — основной инструмент:** тяжесть стеноза/регургитации, градиенты/площадь, размеры и
  функция желудочка (ФВ), давление в лёгочной артерии; повторять в динамике;
- аускультация (характер шума) направляет; ЭКГ/рентген — вспомогательно; стресс-тест/стресс-ЭхоКГ
  — для «бессимптомных»/неоднозначных; КТ (кальций аортального клапана, планирование TAVR); при
  эндокардите — посевы крови + ЭхоКГ (Т2.8).

## 3. Основные пороки
### 3.1. Аортальный стеноз (самый частый, дегенеративный, M-S)
- **Суть:** кальциноз/склероз створок → препятствие выбросу; классическая триада симптомов —
  **стенокардия, обмороки (Том 3, гл. 4), сердечная недостаточность;**
- **Решение о вмешательстве:** при тяжёлом стенозе + симптомах, или бессимптомном с ФВ <50%/по
  критериям; вмешательство — протезирование: **TAVR** (транскатетерное) vs **хирургическое
  (SAVR)** — выбор по возрасту/риску/анатомии решает кардиокоманда;
- лекарств, меняющих течение, нет — лечить факторы, не откладывать вмешательство при показаниях;
  ⚠️ осторожно с вазодилататорами при тяжёлом стенозе.

### 3.2. Митральная регургитация
- **Первичная** (поражение клапана — пролапс, разрыв хорд) vs **вторичная/функциональная**
  (дилатация желудочка/кольца при СН/ишемии — лечить основную болезнь);
- **Решение:** тяжёлая + симптомы или дисфункция ЛЖ → хирургия (предпочтительно пластика) или
  транскатетерное восстановление (edge-to-edge) у неоперабельных/функциональной на фоне
  оптимальной терапии СН;
- вторичная — основа лечение СН (четыре столпа).

### 3.3. Митральный стеноз (чаще ревматический)
- Перегрузка левого предсердия → ФП и тромбоэмболия; ⚠️ **при ФП — варфарин, не DOAC**;
  вмешательство — баллонная вальвулопластика/хирургия по тяжести.

### 3.4. Аортальная регургитация
- **Острая** (расслоение/эндокардит) — неотложная хирургия; **хроническая** — наблюдение, операция
  по симптомам/размерам/ФВ.

## 4. Вектор: общая логика
- **Время вмешательства — по симптомам + ФВ + тяжести** (не «профилактически» при лёгком);
- **тип вмешательства** (TAVR vs хирургия; пластика vs протез) — кардиокоманда по риску/анатомии/
  возрасту;
- медикаменты в основном — лечение последствий (СН, ФП, эндокардит-профилактика у отдельных), а
  не самого порока (кроме функциональной регургитации — лечить причину);
- **антикоагуляция протезов:** механический → варфарин пожизненно; биопротез → по ситуации.

**На языке мембраны (рамка):** дегенеративный аортальный стеноз = M-S (кальциноз/склероз) на
створке; вектор — не «растворить» (лекарств нет), а **заменить границу (протез) вовремя.** Рамка
описательна; решение и сроки — строго по ЭхоКГ-критериям и кардиокоманде.

## 5. Граница (НЕОТЛОЖНОЕ)
- **Острая тяжёлая регургитация** (эндокардит, разрыв хорды, расслоение) → острый отёк лёгких/шок
  → неотложная хирургия;
- **Обморок/стенокардия/СН при тяжёлом аортальном стенозе** → срочная оценка (плохой прогноз без
  вмешательства; Том 3, гл. 4);
- **Эндокардит** (лихорадка + шум + вегетации) → Т2.8 (неотложно).

## 6. Перекрёстки
- **Сердечная недостаточность** — общий исход; функциональная регургитация лечится как СН.
- **ФП** — частый спутник; митральный стеноз/механический клапан → варфарин.
- **Эндокардит/инфекция** — Т2.8.
- **Обморок/боль в груди** — аортальный стеноз как причина (Том 3, гл. 1, 4).

## 7. Карманная версия
1. Два типа поломки границы: **стеноз** (не открывается, перегрузка давлением) vs **регургитация**
   (не закрывается, перегрузка объёмом); итог — СН/аритмии.
2. **ЭхоКГ — основной маркёр;** решение о вмешательстве — **симптомы + ФВ + тяжесть**, не сам факт
   порока.
3. **Аортальный стеноз (M-S):** триада стенокардия/обморок/СН; тяжёлый + симптомы или ФВ<50% →
   TAVR/SAVR (кардиокоманда); лекарств, меняющих течение, нет.
4. **Митральная регургитация:** первичная → пластика/протез; вторичная → лечить СН.
5. **Митральный стеноз + ФП → варфарин** (не DOAC).
6. Граница: острая тяжёлая регургитация, симптомный аортальный стеноз, эндокардит → неотложно.
7. Мембрана/энергия: кальциноз = M-S; вектор — заменить границу вовремя. Решение, сроки, тип —
   кардиокоманда/врач.

> Принцип «симптомы + ФВ + тяжесть», показания к TAVR/SAVR, варфарин при митральном стенозе/
> механическом клапане — доказательная медицина (ACC/AHA + ESC/EACTS и обновления, сверено июнь
> 2026; сверять локально). Двигатели Атеросклероз/фиброз, мембрана M-S, энергии — рамка-навигатор
> METACOD, не основание для назначения. Вектор = направление + класс; решение, сроки и тип
> вмешательства — за лечащим врачом/кардиокомандой.
