**Как читать.** Стержень — доказательная диагностика и лечение спондилоартритов: здесь реальная
помощь. Поверх — фильтры METACOD (двигатель, мембрана, маска, маркёр, вектор, граница). Данные

## 1. Что это в системе: воспаление осевого скелета и мест прикрепления
Спондилоартриты (СпА) — группа воспалительных болезней с поражением **осевого скелета**
(позвоночник, крестцово-подвздошные сочленения) и/или периферических суставов, и характерным
**энтезитом** (воспаление мест прикрепления сухожилий к кости). Двигатель — **Сухость-иммунитет
(Т1.8) + Тепло (Т1.10)**, с генетической связью (**HLA-B27**); особенность — не только разрушение,
но и **патологическое костеобразование** (анкилоз, сращение позвонков → «бамбуковый позвоночник»).
Мембранно (рамка) — воспаление с фиброзно-оссифицирующим исходом.

**Семейство СпА:**
- **аксиальный СпА / анкилозирующий спондилит** (осевой — позвоночник/крестцово-подвздошные);
- **псориатический артрит** (с псориазом — кожа/ногти);
- **реактивный артрит** (после кишечной/урогенитальной инфекции);
- **СпА при ВЗК** (связь с `metacod-ibd.md`).

**Главный фильтр (маска):** **воспалительная боль в спине** (≤40 лет, постепенная, утренняя
скованность >30 мин, улучшение при движении и ухудшение в покое/ночью, ответ на НПВС) — надо
отличить от **механической боли в спине** (улучшение в покое, нет воспалительных черт). Снять
маску: РА, остеоартроз, подагра, инфекция, опухоль.

## 2. Маркёр: диагноз
- **Клиника:** воспалительная боль в спине, энтезит (ахиллово/подошвенный), **дактилит**
  («сосискообразный» палец), периферический артрит (часто асимметричный, нижние конечности),
  внесуставное — **увеит, псориаз, ВЗК**;
- **HLA-B27** (часто положителен, особенно при осевом — поддерживает, не доказывает);
- СРБ/СОЭ (Тепло);
- **визуализация:** рентген крестцово-подвздошных (сакроилеит — поздно), **МРТ** (ранний активный
  сакроилеит/воспаление); рентген позвоночника (синдесмофиты);
- классификационные критерии ASAS.

## 3. Вектор: лечение
- **НПВС — первая линия при осевом СпА** (симптомы + возможно замедление; регулярно при
  активности; ⚠️ осторожно при ХБП/ЖКТ/ССЗ);
- **Лечебная физкультура/упражнения — обязательны** (поддержание подвижности, осанки) — не опция;
- **При недостаточном ответе / по форме:**
  - **осевой → биологики:** ингибиторы ФНО или ИЛ-17 (⚠️ csDMARD типа метотрексата при осевом
    малоэффективны!);
  - **периферический/псориатический** → метотрексат и другие csDMARD + биологики (анти-ФНО,
    анти-ИЛ-17, анти-ИЛ-23, JAK), с учётом кожи/ногтей/ВЗК/увеита при выборе;
- ⚠️ скрининг перед биологиками (туберкулёз, гепатиты), вакцинация;
- вести сопутствующее: увеит (офтальмолог), ВЗК, **остеопороз** (парадокс — и анкилоз, и хрупкость
  позвонков → риск переломов), сердечно-сосудистый риск.

**На языке мембраны (рамка):** СпА = иммунное воспаление осевого скелета/энтезисов (Сухость-
иммунитет + Тепло) с фиброзно-оссифицирующим исходом (анкилоз). Вектор — погасить воспаление (НПВС
→ биологик по форме) и сохранить подвижность (упражнения). Выбор биологика — по фенотипу (кожа/
кишка/глаз).

## 4. Граница (срочное)
- **Острый передний увеит** (боль/покраснение/светобоязнь глаза) → срочно офтальмолог;
- **острый перелом ригидного («бамбукового») позвоночника** — даже при малой травме, высокий риск
  (в т. ч. спинной мозг) — осторожность, визуализация;
- сопутствующее тяжёлое ВЗК (`metacod-ibd.md`); инфекция на биологиках.

## 5. Перекрёстки
- **ВЗК:** СпА и ВЗК часто вместе; выбор биологика с учётом кишки (анти-ФНО/анти-ИЛ-23 работают на
  оба; ⚠️ анти-ИЛ-17 может ухудшать ВЗК).
- **Псориаз/кожа:** псориатический артрит — выбор по коже/ногтям.
- **Увеит:** частое внесуставное; анти-ФНО предпочтительны при рецидивирующем.
- **Остеопороз:** парадокс анкилоза и хрупкости → переломы позвонков.
- **Реактивный артрит:** связь с инфекцией (Том 2, гл. 8).

## 6. Карманная версия
1. СпА = **воспаление осевого скелета/энтезисов** (Сухость-иммунитет + Тепло, HLA-B27), с
   анкилозом; семейство — аксиальный/анкилозирующий, псориатический, реактивный, при ВЗК.
2. Снять маску: **воспалительная боль в спине** (улучшение при движении, ночная, утренняя
   скованность) vs механическая; РА, артроз, инфекция, опухоль.
3. Маркёр: клиника (энтезит, дактилит, увеит, псориаз), HLA-B27, СРБ, **МРТ крестцово-подвздошных**
   (ранний сакроилеит).
4. **Вектор:** НПВС первой линией + **упражнения обязательны**; осевой → биологик (анти-ФНО/
   анти-ИЛ-17), метотрексат на осевой не работает; периферический/псориатический → csDMARD +
   биологики по фенотипу (кожа/кишка/глаз); скрининг перед биологиками.
5. Граница: острый увеит → офтальмолог; перелом ригидного позвоночника при малой травме.
6. Мембрана/энергия: иммунное воспаление с оссификацией; вектор = погасить + сохранить
   подвижность. Решение, препарат, доза — ревматолог.

> Воспалительная боль в спине, HLA-B27, МРТ сакроилеита, НПВС + упражнения первой линией, биологики
> по фенотипу (метотрексат не работает на осевой; анти-ИЛ-17 осторожно при ВЗК), риск перелома
> ригидного позвоночника — доказательная медицина (ASAS-EULAR, ACR/GRAPPA, сверено июнь 2026;
> сверять локально). Двигатели Сухость-иммунитет/Тепло, энергии — рамка-навигатор METACOD, не
> основание для назначения. Вектор = направление + класс; препарат, доза и решение — за
> ревматологом.
