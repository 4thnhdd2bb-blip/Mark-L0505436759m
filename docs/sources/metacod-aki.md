# МОНОГРАФИЯ METACOD · Углублённый разбор · Нефрология

## ОСТРОЕ ПОЧЕЧНОЕ ПОВРЕЖДЕНИЕ (ОПП) — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение острого почечного повреждения:
здесь реальная помощь, и цена ошибки — часы. Поверх — фильтры METACOD (двигатель, мембрана, маска,
маркёр, вектор, граница). Данные сверены (KDIGO ОПП, июнь 2026; сверять локально). Препарат, доза,
решение — лечащий врач/нефролог.

> Прикладной разбор болезни для направления 1 (нефрология). Связан с: `metacod-tom1.md` (Т1.6,
> Т1.10), `metacod-tom2.md` (гл. 5, 6, 8), `metacod-tom3.md` (гл. 8), `metacod-cardiorenal-cluster.md`,
> `metacod-ckd.md`, `metacod-glomerular.md`, `metacod-electrolytes-acidbase-renal.md`.

## 1. Что такое ОПП в системе: фильтр встал — но обратимо
ОПП — **быстрое (часы–дни) падение фильтрующей функции почки**: рост креатинина, падение диуреза.
В отличие от ХБП (медленный фиброз к **M-S**) — ОПП чаще **обратимо**, если вовремя снять причину.
Двигатель зависит от уровня поломки: упал поток к почке (Влажность-вода Т1.6 / шок), повредилась
сама ткань (Тепло/токсин Т1.10), или забит отток (обструкция). Мембранно (рамка) — острый удар по
канальцам/клубочку, не обязательно склероз; задача — **не дать ОПП превратиться в ХБП** (каждый
эпизод ОПП ускоряет путь к M-S).

**Ключ — ОПП тоже тихое:** часто бессимптомно, ловится по анализу/диурезу. Активный поиск у
больного в зоне риска (сепсис, гиповолемия, контраст, нефротоксины, операция).

## 2. Маркёр: диагноз и стадирование (KDIGO)
ОПП ставится по **любому** из критериев:
- ↑креатинина ≥26,5 мкмоль/л (0,3 мг/дл) за 48 ч; **или**
- ↑креатинина ≥1,5× от исходного за ≤7 дней; **или**
- **диурез <0,5 мл/кг/ч ≥6 ч**.

**Стадии (по креатинину и диурезу):**
- 1 ст. — креатинин 1,5–1,9× / диурез <0,5 мл/кг/ч за 6–12 ч;
- 2 ст. — креатинин 2,0–2,9× / диурез <0,5 мл/кг/ч ≥12 ч;
- 3 ст. — креатинин ≥3× (или ≥353,6 мкмоль/л, или начало диализа) / анурия ≥12 ч.

## 3. Маска: триада уровней (определяет всё лечение)
Главная разводящая логика ОПП — **где поломка** (преренальное / ренальное / постренальное):
- **Преренальное (поток не доходит):** гиповолемия, кровопотеря, шок, сердечная/печёночная
  недостаточность, иАПФ/БРА+НПВС+диуретик (**Triple Whammy**). Почка цела — обратимо при
  восстановлении перфузии.
- **Ренальное (повреждена ткань):** острый канальцевый некроз (ишемия/токсины — контраст,
  аминогликозиды, миоглобин при рабдомиолизе), острый интерстициальный нефрит (лекарства — НПВС,
  ИПП, антибиотики), гломерулонефрит/васкулит (см. `metacod-glomerular.md`).
- **Постренальное (забит отток):** камень, простата, опухоль, нейрогенный пузырь — **УЗИ!**
  устранимо (катетер/стент/нефростома).

**Ключ диагностики — осадок мочи + УЗИ:**
- чистый осадок, FENa низкая → преренальное;
- зернистые/«грязно-бурые» цилиндры → канальцевый некроз;
- эозинофилы/лейкоциты, сыпь, эозинофилия → интерстициальный нефрит;
- эритроцитарные цилиндры/дисморфные эритроциты + протеинурия → гломерулярное (срочно!);
- расширение чашечно-лоханочной системы на УЗИ → обструкция.

## 4. Вектор: лечение (по причине — этиотропно)
ОПП **не лечится одной таблеткой** — лечится причина:
- **Преренальное:** восстановить перфузию — инфузия при гиповолемии, лечить шок/сепсис/СН;
  отменить виновные (НПВС, иАПФ/БРА на острый период);
- **Постренальное:** срочно снять обструкцию (катетер/стент/нефростома);
- **Ренальное:** убрать токсин/лекарство, лечить интерстициальный нефрит (отмена виновного ±
  стероид), гломерулонефрит — специфически (биопсия, иммуносупрессия);
- **поддержка всегда:** оптимизировать объём (не залить и не пересушить), **отменить нефротоксины,
  дозировать лекарства по текущей функции**, лечить гиперкалиемию/ацидоз/перегрузку;
- ⚠️ **нет препарата, ускоряющего восстановление ОПП** — диуретики только для контроля объёма (не
  «для почки»); дофамин в «почечной дозе» — НЕ показан.

**На языке мембраны (рамка):** ОПП — острый удар по фильтру, чаще обратимый; вектор = быстро снять
причину (поток/токсин/обструкция) и поддержать, **не дав уйти в фиброз (M-S)/ХБП**.

## 5. Граница (НЕОТЛОЖНОЕ) — показания к диализу: **A-E-I-O-U**
- **A**cidosis — тяжёлый метаболический ацидоз, рефрактерный;
- **E**lectrolytes — тяжёлая/рефрактерная **гиперкалиемия** (ЭКГ!);
- **I**ntoxication — диализируемые яды/лекарства;
- **O**verload — перегрузка объёмом / отёк лёгких, рефрактерный к диуретикам;
- **U**remia — уремические симптомы (перикардит, энцефалопатия, кровоточивость).
+ **постренальная обструкция** = неотложная декомпрессия; **обструктивный пиелонефрит**
  (камень+лихорадка) — срочное дренирование (см. `metacod-nephrolithiasis.md`).

## 6. Перекрёстки
- **ХБП:** острое-на-хроническое; каждый эпизод ОПП ускоряет ХБП.
- **Кардио-ренальный кластер:** Triple Whammy, sick-day rules (приостановить РААС/диуретик/
  метформин/SGLT-2 при острой болезни).
- **Электролиты/КЩР (Т2.5, Т2.6):** гиперкалиемия, ацидоз — неотложные спутники ОПП.
- **Гломерулярные болезни:** быстропрогрессирующий ГН как причина ренального ОПП (срочно).
- **Инфекция/сепсис (Т2.8):** ведущая причина ОПП у тяжёлого больного.
- **Рабдомиолиз:** миоглобин → канальцевый некроз (КФК, моча на кровь без эритроцитов).

## 7. Карманная версия
1. ОПП = быстрое (часы–дни) падение фильтра (KDIGO: ↑креатинина ≥0,3 мг/дл/48ч или ≥1,5× / диурез
   <0,5 мл/кг/ч); **в отличие от ХБП — обратимо**, если снять причину.
2. **Триада уровней (решает всё):** преренальное (поток — гиповолемия/шок/Triple Whammy) /
   ренальное (ткань — некроз/интерстициальный нефрит/ГН) / постренальное (отток — обструкция, УЗИ!).
3. **Ключ — осадок мочи + УЗИ:** зернистые цилиндры → некроз; эозинофилы → интерстициальный;
   эритроцитарные цилиндры → гломерулярное (срочно); расширение ЧЛС → обструкция.
4. **Вектор — этиотропный:** восстановить перфузию / снять обструкцию / убрать токсин; всегда —
   отменить нефротоксины, дозы по функции, лечить калий/ацидоз/объём; **препарата «для почки» нет**.
5. **Граница — диализ A-E-I-O-U** (ацидоз, калий, интоксикация, перегрузка, уремия) +
   обструктивный пиелонефрит → срочная декомпрессия.
6. Мембрана/энергия: острый удар по фильтру, чаще обратимый; вектор = снять причину + поддержать +
   не дать уйти в M-S/ХБП. Решение, препарат, доза — лечащий врач.

> Стадирование KDIGO (креатинин/диурез), триада пре/рено/постренального, осадок мочи + УЗИ как
> ключ, этиотропный вектор, диализ A-E-I-O-U — доказательная медицина (KDIGO ОПП, сверено июнь
> 2026; сверять локально). Двигатели Влажность-вода/Тепло-токсин/застой-оттока, мембрана (острый
> удар, не обязательно M-S), энергии — рамка-навигатор METACOD, не основание для назначения.
> Вектор = направление + класс; препарат, доза и решение — за лечащим врачом.
