# МОНОГРАФИЯ METACOD · Углублённый разбор · Нефрология

## ЭЛЕКТРОЛИТЫ И КИСЛОТНО-ЩЕЛОЧНОЕ РАВНОВЕСИЕ — почечный узел через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и коррекция электролитных и КЩР-нарушений:
здесь реальная помощь, и при тяжёлых сдвигах цена ошибки — минуты. Поверх — фильтры METACOD
(двигатель, мембрана, маска, маркёр, вектор, граница). Данные сверены (июнь 2026; сверять локально).
Препарат, доза, скорость коррекции — лечащий врач.

## 1. Что это в системе: почка держит постоянство среды
Почка (+ лёгкие, кости, ЖКТ) поддерживает **гомеостаз внутренней среды**: калий, натрий/вода,
КЩР, кальций/фосфат/магний. Это не «болезнь», а **маркёрный узел**: сдвиг электролита/pH — почти
всегда **симптом другого двигателя** (обезвоживание, эндокринное, лекарство, почечная
недостаточность). Принцип METECOD здесь прямой: **никогда не лечить цифру — лечить причину**; но
при жизнеугрожающем сдвиге сначала **стабилизировать**, параллельно искать двигатель.

⚠️ **Жёсткий инвариант:** **pH крови 7,35–7,45**. Это **НЕ «тип мембраны»** и не рамочная «энергия»
— это узкий физиологический коридор; выход = неотложный ацидоз/алкалоз. (Рамочный pH мочи/внутренней
зоны для 6 типов мембран — отдельная ось, см. `metacod-membrane.md`; **не путать с pH крови**.)

## 2. КАЛИЙ (самый «электрический» — сердце)
### 2.1. Гиперкалиемия (K↑) — НЕОТЛОЖНОЕ при ЭКГ-изменениях
- причины: почечная недостаточность (ОПП/ХБП), **РААС-блокада / финеренон / калийсберегающие /
  НПВС** (опасные стэки — кардио-ренальный кластер), ацидоз, гипоальдостеронизм, распад тканей;
- ⚠️ **ЭКГ: высокие Т → расширение QRS → синусоида → остановка**;
- **вектор (порядок):** ① **кальция глюконат** (стабилизировать миокард, не снижает K);
  ② **сдвинуть K в клетку** — инсулин+глюкоза, β2-агонист (сальбутамол), при ацидозе бикарбонат;
  ③ **вывести** — петлевой диуретик, K-связывающие смолы (патиромер/циклосиликат), **диализ** при
  тяжёлой/рефрактерной; ④ убрать причину (отменить виновные лекарства).
### 2.2. Гипокалиемия (K↓)
- причины: потери ЖКТ (рвота/диарея), диуретики, гиперальдостеронизм, гипомагниемия;
- ⚠️ **аритмии** (особенно на дигоксине); **обязательно восполнить магний** — иначе калий не
  держится; восполнять K (per os/в/в — контролируемо).

## 3. НАТРИЙ И ВОДА (это про воду, не про соль)
**Ключ:** натрий крови отражает **баланс воды**, а не запас соли.
### 3.1. Гипонатриемия (Na↓) — частая, опасна скоростью коррекции
- разбор по объёму и осмоляльности: гиповолемическая / эуволемическая (**SIADH**, гипотиреоз,
  надпочечниковая недостаточность) / гиперволемическая (СН, цирроз, ХБП);
- ⚠️ **корректировать медленно** (риск **осмотического демиелинизирующего синдрома** при слишком
  быстром подъёме); острая симптомная (судороги/кома) → гипертонический NaCl осторожно, по протоколу.
### 3.2. Гипернатриемия (Na↑) — это дефицит воды
- почти всегда **потеря/нехватка воды** (нет доступа к воде, AVP-D/несахарный диабет — см.
  `metacod-pituitary.md`); восполнять воду, тоже **не слишком быстро** (риск отёка мозга).

## 4. КИСЛОТНО-ЩЕЛОЧНОЕ (КЩР) — Т2.6
Системный подход: pH (7,35–7,45) → первичный сдвиг (метаболический/респираторный) → компенсация →
**анионный провал** для метаболического ацидоза.
- **Метаболический ацидоз с ↑анионным провалом:** «**KUSMALE/MUDPILES**» — лактат (шок/сепсис,
  Т1.10), кетоны (**ДКА**, см. `metacod-diabetes.md`), уремия (почечная недостаточность),
  токсины (метанол/этиленгликоль, салицилаты);
- **Метаболический ацидоз с нормальным провалом:** потери бикарбоната (диарея), почечный
  канальцевый ацидоз;
- **Метаболический алкалоз:** рвота, диуретики, гиперальдостеронизм;
- **Респираторные:** ацидоз (гиповентиляция — Т1.11/угнетение дыхания), алкалоз (гипервентиляция);
- **вектор:** лечить **причину** (восполнить объём при лактате, инсулин при ДКА, диализ/токсин-
  специфика при отравлениях); бикарбонат — по показаниям, осторожно. Хронический ацидоз ХБП —
  пероральный бикарбонат (см. `metacod-ckd.md`).

## 5. КАЛЬЦИЙ / ФОСФАТ / МАГНИЙ (узел кости-почки)
- **Кальций** (гипер-/гипо-) — полный разбор в `metacod-calcium.md` (ПТГ-развилка; при гипокальциемии
  **сначала магний**); неотложное — тяжёлая гиперкальциемия (инфузия+кальцитонин/бисфосфонат) и
  симптомная гипокальциемия (тетания, ларингоспазм, удлинение QT);
- **Фосфат** — задержка при ХБП (минерально-костные нарушения, фосфат-биндеры); гипофосфатемия при
  рефидинге;
- **Магний** — дефицит «прячет» гипокалиемию и гипокальциемию (восполнять первым); гипермагниемия
  при ХБП.

## 6. Граница (НЕОТЛОЖНОЕ)
- **Тяжёлая гиперкалиемия с ЭКГ** → кальций → инсулин/глюкоза/β2 → вывести/диализ (немедленно);
- **Тяжёлый ацидоз/алкалоз** (pH вне 7,35–7,45 с нестабильностью) → причина + ОРИТ;
- **Острая симптомная гипонатриемия** (судороги/кома) → гипертонический NaCl по протоколу (медленно!);
- **Симптомная гипокальциемия** (тетания/ларингоспазм/QT) → в/в кальций;
- показания к диализу при метаболических кризах — A-E-I-O-U (`metacod-aki.md`).

## 7. Перекрёстки
- **ОПП/ХБП:** главный источник гиперкалиемии, ацидоза, фосфат/кальций-нарушений.
- **Кардио-ренальный кластер:** РААС+финеренон+НПВС = гиперкалиемия (опасный стэк).
- **Эндокринные:** надпочечники (альдостерон → K, Na), гипофиз (AVP-D → Na), щитовидка, кальций/ПТГ.
- **Диабет:** ДКА — ацидоз с провалом + сдвиги калия (тотальный дефицit при норме в крови).
- **Свёртывание/неврология:** магний/кальций/натрий влияют на возбудимость (судороги, аритмии).

## 8. Карманная версия
1. Электролиты/КЩР — **маркёрный узел, не болезнь:** сдвиг = симптом другого двигателя; **лечить
   причину**, но жизнеугрожающее сначала **стабилизировать**.
2. ⚠️ **pH крови 7,35–7,45 — жёсткий инвариант, НЕ тип мембраны** (рамочный pH мочи — отдельная ось).
3. **Калий:** гипер- с ЭКГ → кальций → инсулин/глюкоза/β2 → вывести/диализ; гипо- → восполнить +
   **обязательно магний**.
4. **Натрий = вода:** гипо- корректировать **медленно** (риск демиелинизации); гипер- = дефицит
   воды (восполнять воду, тоже медленно).
5. **КЩР:** анионный провал разводит метаболический ацидоз (лактат/кетоны/уремия/токсины); вектор
   по причине.
6. **Кальций/фосфат/магний** — узел кости-почки (`metacod-calcium.md`); магний восполнять первым.
   Скорость и доза коррекции — лечащий врач.

> Системный подход к КЩР (pH→первичный сдвиг→компенсация→анионный провал), порядок при
> гиперкалиемии (кальций→инсулин/β2→вывод/диализ), медленная коррекция натрия, «лечить причину, не
> цифру» — доказательная медицина (сверено июнь 2026; сверять локально). ⚠️ pH крови 7,35–7,45 —
> физиологический инвариант, не рамочный «тип мембраны». Энергии/типы — рамка-навигатор METACOD, не
> основание для назначения. Вектор = направление + класс; препарат, доза и скорость коррекции — за
> лечащим врачом.
