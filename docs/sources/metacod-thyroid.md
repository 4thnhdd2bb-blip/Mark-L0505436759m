## ЩИТОВИДНАЯ ЖЕЛЕЗА — гипо- и гипертиреоз через фильтры METACOD

здесь реальная помощь. Поверх — фильтры METACOD: двигатель (Холод Т1.11 ↔ Тепло Т1.10),

## 1. Что такое щитовидка в системе: одна ось, два полюса
Щитовидная железа — **термостат обмена.** Образцовая иллюстрация оси METACOD **Холод↔Тепло**
(и мембранной оси катаболизм↔анаболизм), с важной оговоркой о направлении:
- **Гипотиреоз = двигатель Холод (Т1.11):** обмен угасает, всё замедляется. Парадокс мембраны:
  замедление синтеза и накопление (отёчность, прибавка) клинически выглядит
  «анаболически-застойно», но по сути это **гипометаболизм**; в рамке — тяготение к **M-D1**
  (катаболический полюс по сниженному обороту) с микседематозным застоем. Энергетика — Холод/
  Влажность (зябкость, отёчность, замедление).
- **Гипертиреоз = двигатель Тепло (Т1.10):** обмен разогнан, катаболизм (потеря веса при
  аппетите, распад). Мембрана — Тепло, сдвигающее к разрушению (**M-A→M-D жаром**). Энергетика
  — Тепло/Жар (жар, тахикардия, тремор, тревога).

**Главный фильтр (маска):** щитовидка — великий имитатор. Гипотиреоз маскируется под
усталость/депрессию/деменцию/дислипидемию/сердечную недостаточность; гипертиреоз — под
тревогу/аритмию/потерю веса/«нервы» (Т1.4). Поэтому **ТТГ — в широкий скрининг** при этих
масках (Том 3, гл. 5, 6).

## 2. Маркёр: как читать анализы (каскад)
**ТТГ — первый и главный тест** (чувствительнее всего), затем каскад:
- **ТТГ высокий → измерить свободный Т4:** низкий Т4 → явный гипотиреоз; нормальный Т4 →
  субклинический гипотиреоз.
- **ТТГ низкий → измерить свободные Т4 и Т3:** высокие → явный гипертиреоз; нормальные →
  субклинический гипертиреоз.
- **Антитела:** анти-ТПО (Хашимото — гипотиреоз), антитела к рецептору ТТГ/TRAb (Грейвс —
  гипертиреоз).
- **Ловушки:** эутиреоидный синдром больного (тяжёлая болезнь искажает пробы — не лечить «по
  цифре»), первый триместр беременности (низкий ТТГ — норма), лекарства (амиодарон, литий,
  биотин-интерференция; глюкокортикоиды/допамин подавляют ТТГ). При сомнении — пересдать, в т.
  ч. в другой лаборатории.

## 3. ГИПОТИРЕОЗ (двигатель Холод)

### 3.1. Причины (снять маску)
- **Хашимото** (аутоиммунный, анти-ТПО) — самая частая; пересечение с Сухость-иммунитет (Т1.8);
- после лечения щитовидки (тиреоидэктомия, радиойод), йод-дефицит/избыток;
- центральный (гипофиз/гипоталамус) — редкий, ТТГ не повышен;
- лекарственный (амиодарон, литий).

### 3.2. Клиника (Холод/Влажность)
Зябкость, усталость, прибавка веса, запор, сухость кожи, выпадение волос, замедленность,
брадикардия, отёчность (микседема — неямочный отёк, Том 3 гл. 7), депрессия/«туман»,
дислипидемия (вторичная — снять маску в Т1.12).

### 3.3. Лечение (вектор: добавить тепло обмену)
- **Левотироксин (ЛТ4)** — основа; титровать по ТТГ в референс (свой для возраста/беременности).
- **Субклинический гипотиреоз:** лечить при ТТГ >10 независимо от симптомов; при 7–10 —
  индивидуально (симптомы, возраст, антитела, беременность/планирование).
- ⚠️ **У пожилых и при болезни сердца — начинать с малых доз и медленно** (форсаж ЛТ4 → ишемия,
  аритмия; субклинический гипертиреоз от передозировки ↑ риск фибрилляции предсердий и потери
  костной массы).
- Т3 рутинно не рекомендуется; принимать ЛТ4 натощак, разнести с железом/кальцием/ИПП.

### 3.4. Граница (неотложное)
**Микседематозная кома:** тяжёлый гипотиреоз + гипотермия + угнетение сознания + гипонатриемия
→ неотложно (ОРИТ, тиреоидные гормоны + глюкокортикоид, согревание; исключить надпочечниковую
недостаточность прежде/вместе).

## 4. ГИПЕРТИРЕОЗ (двигатель Тепло)

### 4.1. Причины (снять маску)
- **Болезнь Грейвса** (аутоиммунная, TRAb; + офтальмопатия) — самая частая;
- узловой токсический зоб / токсическая аденома (автономные узлы);
- тиреоидит (подострый/послеродовой — преходящий выброс гормона, потом гипо);
- йод/амиодарон-индуцированный, передозировка ЛТ4 (ятрогенный — проверить приём).
- **Различить «гипер-продукцию» от «выброса при тиреоидите»** — захват радиойода/сканирование
  (высокий при Грейвсе/узлах, низкий при тиреоидите) меняет лечение.

### 4.2. Клиника (Тепло/Жар)
Потеря веса при сохранном аппетите, жар/потливость, сердцебиение/тахикардия/фибрилляция
предсердий, тремор, тревога/раздражительность, бессонница, частый стул, проксимальная
слабость; при Грейвсе — глазные симптомы. У пожилых — **«апатичный» тиреотоксикоз** (маска:
только похудание/аритмия/депрессия — снять её, Том 3 гл. 5).

### 4.3. Лечение (вектор: убавить тепло)
- **Тиреостатики:** карбимазол/метимазол (первая линия; пропилтиоурацил — в 1-м триместре
  беременности и при кризе). Контроль печёночных проб и лейкоцитов — ⚠️ **риск
  агранулоцитоза: при лихорадке/ангине немедленно проверить лейкоциты и отменить!**
- **β-блокатор** — симптоматически (тахикардия, тремор) сразу.
- **Радиойод или тиреоидэктомия** — по ситуации/предпочтению (Грейвс, узлы).
- **Тиреоидит** — обычно поддерживающее (β-блокатор, НПВС/стероид при подостром), НЕ
  тиреостатики (нет гиперпродукции).
- ⚠️ **Субклинический гипертиреоз** (ТТГ низкий, гормоны норма): лечить при ТТГ стойко ≤0,1
  (особенно >65 лет, остеопороз, болезнь сердца — риск фибрилляции предсердий ×3 и потери
  кости); при 0,1–0,4 — чаще наблюдение.

### 4.4. Граница (неотложное)
**Тиреотоксический криз (буря):** гипертиреоз + лихорадка + тахиаритмия + возбуждение/делирий +
дисфункция органов → неотложно (β-блокатор, тиреостатик, йод после тиреостатика, глюкокортикоид,
охлаждение, лечить триггер). Высокая летальность.

## 5. Сводная таблица: два полюса через фильтры
| | Гипотиреоз | Гипертиреоз |
|---|---|---|
| Двигатель | Холод (Т1.11) | Тепло (Т1.10) |
| Энергия | Холод/Влажность | Тепло/Жар |
| Мембрана (рамка) | гипометаболизм, застой (M-D/микседема) | катаболизм жаром (M-A→M-D) |
| ТТГ | высокий | низкий |
| Маска | усталость, депрессия, дислипидемия, СН | тревога, аритмия, похудание |
| Вектор | добавить ЛТ4 (по ТТГ) | убавить (тиреостатик/β-блок/радиойод) |
| Граница | микседематозная кома | тиреотоксический криз |

## 6. Особые ситуации
- **Беременность:** цели ТТГ по триместрам (ниже обычных); явный гипо/гипер — лечить (гипотиреоз
  → ↑дозу ЛТ4 ~на 25–30% рано; гипертиреоз → пропилтиоурацил в 1-м триместре); иАПФ/БРА и
  радиойод — нельзя. Связь с «беременность как M-A».
- **Пожилые:** осторожный старт ЛТ4; апатичный тиреотоксикоз; ниже порог тревоги по фибрилляции
  предсердий.
- **Амиодарон:** может дать и гипо-, и гипертиреоз — мониторинг ТТГ.
- **Узел щитовидной железы:** оценить риск рака (УЗИ-стратификация, ТТГ, при показаниях
  пункция) — это уже двигатель деления (Т1.1), отдельная логика.

## 7. Карманная версия
1. **ТТГ первым** (каскад: высокий → свТ4; низкий → свТ4/Т3); антитела (анти-ТПО/TRAb); не
   лечить «по цифре» при тяжёлой болезни/беременности (ловушки).
2. **Гипотиреоз (Холод):** ЛТ4 по ТТГ; субклинический — лечить при ТТГ >10, 7–10 индивидуально;
   у пожилых/сердечных — малые дозы, медленно.
3. **Гипертиреоз (Тепло):** тиреостатик + β-блокатор; различить продукцию от тиреоидита
   (захват); субклинический — лечить при ТТГ ≤0,1 (риск фибрилляции/кости); агранулоцитоз —
   лихорадка/ангина → стоп + лейкоциты.
4. **Снять маску:** ТТГ при усталости/депрессии/дислипидемии/аритмии/похудании.
5. **Граница:** микседематозная кома и тиреотоксический криз → неотложно.
6. **Мембрана/энергия:** Холод (M-D/застой) ↔ Тепло (катаболизм); вектор = добавить/убавить.
   Решение, препарат, доза — лечащий врач.

> Пороги ТТГ, критерии субклинических состояний, схемы лечения — доказательная медицина
> (ATA/ETA 2024–2025, сверено июнь 2026; сверять локально). Двигатели Холод/Тепло, мембраны
> M-D/M-A, энергии — рамка-навигатор METACOD, не основание для назначения. Вектор = направление
> + класс; препарат, доза и решение по конкретному человеку — за лечащим врачом.
