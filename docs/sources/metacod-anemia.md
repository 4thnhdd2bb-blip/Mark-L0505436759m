## 1. Что такое анемия в системе: мало переносчиков кислорода
Анемия — снижение гемоглобина/эритроцитов → меньше кислорода доставляется тканям. Это **не
диагноз, а признак:** всегда есть причина, и задача METACOD — её найти. Симптомы от гипоксии
тканей: утомляемость, одышка при нагрузке, бледность, сердцебиение; тяжёлая/быстрая — опасна.
Анемия — частая **маска** другой болезни (кровотечение, дефицит, хроническое воспаление, костный
мозг, гемолиз) — поэтому «снять маску» здесь центрально.

**Три механизма (двигатель):**
- **снижено производство** (дефицит субстрата — железо/B12/фолат; поражение костного мозга;
  хроническое воспаление/почка) — энергетически ближе к **Сухость-атрофия (Т1.9)** (нехватка
  субстрата/продукции);
- **повышено разрушение (гемолиз)** — эритроциты гибнут быстрее, чем создаются;
- **кровопотеря** (острая/хроническая) — теряются прямо.

## 2. Маркёр: два ключа — размер (MCV) и ретикулоциты
**Двумерный фильтр диагностики:**
1. **MCV** (средний объём эритроцита): микроцитарная / нормоцитарная / макроцитарная;
2. **Ретикулоциты:** низкие (гипопродукция — костный мозг не отвечает) vs высокие (гиперпродукция
   — гемолиз/кровопотеря, мозг отвечает).

**Микроцитарная (MCV↓):** железодефицит (самая частая в мире — **ферритин** — самый надёжный тест,
низкий = дефицит; ⚠️ ферритин — острофазовый, при воспалении ложно высок), талассемия, анемия
хронического заболевания (может быть микро-/нормоцитарной), сидеробластная.

**Макроцитарная (MCV↑):** дефицит B12 (+ **неврология** — Том 2, гл. 9!) и фолата (мегалобластные);
алкоголь, болезни печени, гипотиреоз, миелодисплазия, лекарства.

**Нормоцитарная (MCV норм):** анемия хронического заболевания/воспаления, ХБП (дефицит
эритропоэтина — `metacod-ckd.md`), острая кровопотеря, ранний дефицит, костномозговая
недостаточность, гемолиз.

**Гемолиз (маркёры):** ↑ретикулоциты, ↑ЛДГ, ↑непрямой билирубин, ↓гаптоглобин; мазок (шистоциты →
микроангиопатия — TTP/HUS/DIC, `metacod-thrombocytopenia-hemostasis.md`; сфероциты → аутоиммунный
— проба Кумбса).

**Базовое:** общий анализ + мазок + ретикулоциты → ферритин/железо/ОЖСС, B12/фолат, функция почек,
ТТГ, гемолиз-панель по подозрению; ⚠️ **железодефицит у взрослого = искать источник кровопотери**
(ЖКТ — рак толстой кишки! Т1.1; менструальный; `metacod-gerd-peptic-ulcer.md`).

## 3. Вектор: лечение (по причине — анемия лечится не «железом всем»)
- **Железодефицит:** препараты железа (внутрь; в/в при непереносимости/мальабсорбции/ХБП/быстрой
  потребности) + **устранить источник** (главное!);
- **B12/фолат:** восполнение (B12 — парентерально при мальабсорбции/неврологии; ⚠️ при
  B12-дефиците фолат без B12 может усугубить неврологию — восполнять оба правильно);
- **анемия хронического заболевания:** лечить основную болезнь; железо/эритропоэз — по ситуации;
- **ХБП:** железо + эритропоэз-стимуляторы (`metacod-ckd.md`);
- **гемолитические:** по типу (аутоиммунный — стероиды/иммуносупрессия; наследственные —
  специализированно); апластическая/миелодисплазия/инфильтрация — гематолог;
- **трансфузия** — по тяжести/симптомам/скорости (не по одной цифре), осторожно.

**На языке мембраны (рамка):** анемия — дефицит переносчиков кислорода; чаще это **Сухость-атрофия
(Т1.9)** на уровне эритропоэза (нехватка субстрата/продукции) или потеря/разрушение. Вектор — найти
и убрать причину (восполнить субстрат / остановить потерю / погасить гемолиз / лечить мозг), а не
«железо всем».

## 4. Граница (НЕОТЛОЖНОЕ)
- **Острая кровопотеря / гемодинамическая нестабильность** (Том 2, гл. 4) → реанимация +
  трансфузия + остановка источника;
- **тяжёлая симптомная анемия** (боль в груди/одышка покоя/ишемия) → трансфузия;
- **гемолитический криз / микроангиопатия** (шистоциты + тромбоцитопения = ⚠️ TTP — неотложно,
  `metacod-thrombocytopenia-hemostasis.md`);
- **панцитопения / бласты в мазке** → срочно гематолог (лейкоз — `metacod-leukemia.md`).

## 5. Перекрёстки
- **ЖКТ-кровотечение (Том 2, гл. 4; ГЭРБ/язва):** железодефицит у взрослого → искать источник (рак
  толстой кишки!).
- **ХБП:** дефицит эритропоэтина.
- **B12 и неврология (Том 2, гл. 9):** макроцитарная анемия + неврология.
- **Гемостаз:** микроангиопатия (TTP/HUS/DIC) — шистоциты.
- **Онкология/костный мозг (лейкозы, лимфомы и миелома):** панцитопения, бласты, инфильтрация.

## 6. Карманная версия
1. Анемия — **признак, не диагноз;** всегда искать причину. Механизмы: ↓продукция / гемолиз /
   кровопотеря.
2. Маркёр — **два ключа: MCV** (микро/нормо/макро) **+ ретикулоциты** (гипо/гипер); мазок;
   ферритин — самый надёжный для железодефицита (но острофазовый).
3. Микро → железодефицит (искать источник — рак!), талассемия; макро → B12/фолат (B12 +
   неврология); нормо → хроническое/ХБП/кровопотеря; гемолиз → ↑ЛДГ/билирубин, ↓гаптоглобин,
   шистоциты/сфероциты.
4. Вектор по причине: железо + устранить источник; B12/фолат (оба правильно); лечить основную
   болезнь/ХБП; гемолиз по типу; трансфузия по тяжести.
5. Граница: острая кровопотеря, тяжёлая симптомная, TTP (шистоциты+тромбоцитопения), панцитопения/
   бласты → неотложно.
6. Мембрана/энергия: чаще Сухость-атрофия эритропоэза; вектор = найти и убрать причину. Решение,
   препарат, доза — лечащий врач.

> Двумерная диагностика (MCV + ретикулоциты), ферритин как ключ к железодефициту, поиск источника
> кровопотери, лечение по причине, неотложности (TTP, острая кровопотеря) — доказательная медицина
> (рекомендации по анемии, сверено июнь 2026; сверять локально). Двигатель Сухость-атрофия
> (эритропоэз), энергии — рамка-навигатор METACOD, не основание для назначения. Вектор =
> направление + класс; препарат, доза и решение — за лечащим врачом.
