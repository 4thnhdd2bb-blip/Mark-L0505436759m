## 1. Что это в системе: костный мозг выпускает клон вместо нормальной крови
Лейкоз — **злокачественный клон кроветворных клеток, вытесняющий нормальное кроветворение** в
костном мозге. Двигатель — **деление/Рак (Т1.1–1.3)** в кроветворной ткани; итог — костномозговая
недостаточность (анемия, тромбоцитопения, нейтропения → инфекции) + накопление опухолевых клеток.
Мембранно/энергетически — неконтролируемая пролиферация клона.

**Два деления (фильтр — определяет срочность и подход):**
- **острые vs хронические:** острые — **бласты** (незрелые), бурное течение, неотложность;
  хронические — более зрелые клетки, часто годами;
- **миелоидные vs лимфоидные** (по линии):
  - **ОМЛ** (острый миелоидный) — взрослые, бласты, неотложно;
  - **ОЛЛ** (острый лимфобластный) — чаще дети, но и взрослые;
  - **ХМЛ** (хронический миелоидный) — Ph-хромосома / BCR-ABL;
  - **ХЛЛ** (хронический лимфоцитарный) — пожилые, зрелые лимфоциты, часто бессимптомно.

## 2. Маркёр: диагноз
- **Общий анализ + мазок:** цитопении и/или лейкоцитоз; **бласты в мазке → острый лейкоз
  (срочно!)**; зрелый лимфоцитоз → ХЛЛ; гранулоциты всех стадий → ХМЛ;
- **костный мозг** (аспирация/трепанобиопсия): доля бластов (**≥20% → острый**), морфология;
- **иммунофенотипирование** (проточная цитометрия — линия), **цитогенетика/молекулярика** (BCR-ABL
  для ХМЛ; мутации — прогноз/мишень в ОМЛ; и т.д.) — определяют тип, прогноз и таргетную терапию;
- сопутствующее: ЛДГ, мочевая кислота (риск лизиса), коагулограмма (⚠️ промиелоцитарный ОМЛ → DIC
  — `metacod-thrombocytopenia-hemostasis.md`).

## 3. Вектор: лечение (по типу — гематолог-онколог)
- **ОМЛ:** интенсивная химиотерапия (индукция/консолидация) ± таргетные по мутациям; трансплантация
  по риску; ⚠️ **острый промиелоцитарный лейкоз (ОПЛ)** — особый, лечится ATRA/мышьяком, но даёт
  **DIC** — неотложно;
- **ОЛЛ:** длительная многофазная химиотерапия, при Ph+ — добавить ингибитор тирозинкиназы;
  иммунотерапия (биспецифики, CAR-T) при рецидиве; профилактика ЦНС;
- **ХМЛ:** **ингибиторы тирозинкиназы** (иматиниб и др.) — таргет на BCR-ABL, превратили болезнь в
  управляемую; мониторинг молекулярного ответа;
- **ХЛЛ:** часто наблюдение при бессимптомной ранней; лечение при прогрессии — таргетные
  (ингибиторы BTK/BCL-2) ± антитела; не всем нужна немедленная терапия;
- **поддержка всем:** профилактика/лечение инфекций (нейтропения!), трансфузии, профилактика
  синдрома лизиса опухоли (гидратация, аллопуринол/расбуриказа), психосоциальная.

**На языке мембраны (рамка):** лейкоз = неконтролируемое деление кроветворного клона (Т1.1–1.3) →
костномозговая недостаточность. Вектор (онкологический, специализированный) — подавить/устранить
клон (химио/таргет/трансплантация/иммунотерапия по типу) + поддержать (инфекции, кровь, лизис).
METACOD здесь — навигатор распознавания и срочности, не источник режима терапии.

## 4. Граница (НЕОТЛОЖНОЕ)
- **Бласты в мазке / подозрение на острый лейкоз** → срочно гематолог (часы-дни);
- **фебрильная нейтропения** (лихорадка + нейтропения) → неотложно антибиотики (Том 2, гл. 8) —
  может убить быстро;
- **синдром лизиса опухоли** (гиперкалиемия/гиперурикемия/гиперфосфатемия/гипокальциемия, ОПП —
  Том 2 гл. 5, `metacod-aki.md`) → неотложно;
- **лейкостаз** (очень высокий лейкоцитоз + одышка/неврология), **DIC при ОПЛ**, тяжёлая анемия/
  тромбоцитопения с кровотечением → неотложно.

## 5. Перекрёстки
- **Анемии/Гемостаз:** цитопении, бласты, DIC (промиелоцитарный) — общий мазок.
- **Инфекция (Том 2, гл. 8):** фебрильная нейтропения — неотложность.
- **Электролиты/ОПП (Том 2 гл. 5; ОПП):** синдром лизиса опухоли.
- **Лимфомы и миелома:** соседние онкогематологические клоны.
- **Онкология (Т1.1):** общий двигатель деления (Том 1).

## 6. Карманная версия
1. Лейкоз = **злокачественный клон костного мозга** (деление Т1.1–1.3) → костномозговая
   недостаточность.
2. Два деления: **острые** (бласты, неотложно) vs хронические; **миелоидные** (ОМЛ/ХМЛ) vs
   **лимфоидные** (ОЛЛ/ХЛЛ).
3. Маркёр: мазок (**бласты → срочно**) + костный мозг (**≥20% бластов = острый**) + иммунофенотип/
   цитогенетика (BCR-ABL→ХМЛ; мутации→прогноз/мишень).
4. **Вектор (гематолог-онколог):** ОМЛ — химио±таргет±трансплантация (ОПЛ → ATRA, риск DIC); ОЛЛ —
   многофазная химио (Ph+ → +ТКИ); ХМЛ → ингибиторы тирозинкиназы; ХЛЛ — часто наблюдение, при
   прогрессии таргетные; поддержка (инфекции/лизис/кровь).
5. Граница: бласты/острый лейкоз → срочно; **фебрильная нейтропения → неотложно антибиотики**;
   синдром лизиса, лейкостаз, DIC при ОПЛ.
6. Мембрана/энергия: деление клона; вектор = подавить клон + поддержать. Решение, режим, препарат —
   гематолог-онколог.

> Деления (острый/хронический, миелоидный/лимфоидный), бласты как маркёр срочности, BCR-ABL/ТКИ при
> ХМЛ, наблюдение при ранней ХЛЛ, неотложности (фебрильная нейтропения, лизис, ОПЛ-DIC) —
> доказательная медицина (WHO/ELN/рекомендации, сверено июнь 2026; сверять локально). Двигатель
> деления/Рак (Т1.1–1.3), энергии — рамка-навигатор METACOD для распознавания и срочности, не
> основание для режима терапии. Диагностика и лечение — за гематологом-онкологом.
