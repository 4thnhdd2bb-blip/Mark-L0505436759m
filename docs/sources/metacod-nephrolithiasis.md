## 1. Что это в системе: камень в дренаже мочи
Мочевые пути — дренаж потока мочи из почки наружу. Камень образуется при перенасыщении мочи
солями (кальций, оксалат, мочевая кислота, цистин) + дефиците ингибиторов (цитрат) + застое.
Двигатель — метаболически-обменный (Т1.7; перенасыщение/осадок) + застой дренажа, при осложнении —
**Тепло/инфекция (Т1.10/Т2.8)**. Мембранно (рамка) — кристаллический осадок при дисбалансе среды
мочи. **Болезнь определяется тем, где камень застрял, есть ли обструкция и есть ли инфекция** — это
разводящая логика (структурно повторяет логику желчных камней, см. `metacod-gallstones.md`).

**Спектр (ключ к тяжести):**
- камень в почке без обструкции → может быть бессимптомным;
- камень в мочеточнике → **почечная колика** (обструкция);
- камень + обструкция + лихорадка → **обструктивный пиелонефрit** (неотложное!).

## 2. Состояния и их разведение
### 2.1. Почечная колика
Острейшая схваткообразная боль в боку/пояснице с иррадиацией в пах, беспокойство, тошнота,
**гематурия**. Камень перекрыл мочеточник. → обезболивание (НПВС — первая линия при сохранной
функции почек, иначе опиоид), гидратация по ситуации, оценка размера/локализации.

### 2.2. Изгнание камня
- **мелкие (<5–6 мм)** обычно отходят сами → **медикаментозная изгоняющая терапия (α-блокатор,
  напр. тамсулозин)** + анальгезия + наблюдение;
- крупные / не отходят / стойкая обструкция → урологическое удаление (литотрипсия ESWL,
  уретероскопия, чрескожно).

### 2.3. ⚠️ Обструктивный пиелонефрит (НЕОТЛОЖНОЕ — инфекция за обструкцией)
**Камень-обструкция + лихорадка/признаки инфекции = инфекция в закрытой системе** → быстрый
уросепсис. → неотложно: **антибиотики + срочная декомпрессия (стент/нефростома)** — структурный
аналог холангита в желчных путях (Т2.8).

## 3. Маркёр
- **Низкодозная безконтрастная КТ — золотой стандарт** диагностики (видит почти все камни, размер,
  локализацию); УЗИ — у беременных/детей и как скрининг (гидронефроз);
- **анализ мочи** (гематурия, pH, кристаллы, лейкоциты/нитриты — инфекция);
- **анализ состава камня** (если добыт) — определяет профилактику;
- функция почки (креатинин), кальций/мочевая кислота крови;
- метаболическое обследование (суточная моча) — при рецидивах/высоком риске.

## 4. Вектор (острый + профилактика по типу)
**Острая фаза:**
- обезболивание (НПВС/опиоид), изгоняющая терапия α-блокатором для мелких камней мочеточника;
- удаление при крупных/обструкции;
- ⚠️ **обструкция + инфекция → декомпрессия + антибиотики (граница!)**.

**Профилактика рецидива (определяется типом камня):**
- **общее всем:** **высокий объём жидкости** (диурез >2–2,5 л/сут) — главная мера;
- **кальций-оксалатные** (самые частые): нормальный кальций пищи, **ограничить натрий и животный
  белок**, **тиазид** (снижает кальций мочи), **цитрат калия** (ингибитор);
- **мочекислые:** **подщелачивание мочи цитратом калия** (растворяет!), снизить пурины, лечить
  гиперурикемию;
- **струвитные** (инфекционные, magnesium-ammonium-фосфат) — полное удаление + лечение инфекции;
- **цистиновые** (генетические) — высокий объём, подщелачивание, специфическая терапия.

**На языке мембраны (рамка):** камень = кристаллический осадок при перенасыщении/дефиците
ингибиторов + застой; вектор = убрать обструкцию, погасить инфекцию при осложнении, **изменить
среду мочи** под тип камня (объём + диета + цитрат/тиазид/подщелачивание).

## 5. Граница (НЕОТЛОЖНОЕ)
- **Обструктивный пиелонефрит** (камень + лихорадка) → антибиотики + срочная декомпрессия — это
  уросепсис в закрытой системе (Т2.8);
- **Двусторонняя обструкция / единственная почка** → постренальное ОПП (анурия) → срочная
  декомпрессия (`metacod-aki.md`);
- **Неконтролируемая боль / рвота / беременность** → госпитализация;
- Снять маску боли в боку: расслоение/разрыв аорты, ОКС, аппендицит, внематочная, опоясывающий
  герпес (Том 3, гл. 8).

## 6. Перекрёстки
- **ОПП:** двусторонняя/единственной почки обструкция = постренальное ОПП.
- **Инфекция/сепсис (Т2.8):** обструктивный пиелонефрит — уросепсис.
- **Кальций (Т1.7/«Кальций»):** гиперкальциемия/гиперпаратиреоз → кальциевые камни (снять маску!).
- **Обмен/подагра:** мочекислые камни — связь с гиперурикемией/метаболическим синдромом.
- **Желчные камни:** та же структурная логика «камень + застой + инфекция» (см. `metacod-gallstones.md`).

## 7. Карманная версия
1. Болезнь определяется **локализацией камня + обструкцией + инфекцией:** почка (часто немо) vs
   мочеточник (колика) vs камень+лихорадка (обструктивный пиелонефрит — неотложно).
2. **Маркёр — низкодозная безконтрастная КТ** (золотой стандарт) + анализ мочи; анализ состава
   камня определяет профилактику.
3. **Острый вектор:** обезболивание (НПВС), α-блокатор для мелких камней мочеточника; удаление при
   крупных/обструкции.
4. ⚠️ **Обструкция + инфекция = неотложность:** антибиотики + декомпрессия (стент/нефростома).
5. **Профилактика по типу:** всем — много жидкости (>2–2,5 л); кальций-оксалатные — тиазид/цитрат/
   меньше соли и животного белка; мочекислые — подщелачивание цитратом.
6. Мембрана/энергия: кристаллический осадок + застой + Тепло при инфекции; вектор = убрать
   обструкцию + изменить среду мочи. Решение, метод удаления — лечащий врач/уролог.

> Разведение по локализации/обструкции/инфекции, низкодозная КТ как стандарт, изгоняющая терапия
> α-блокатором, обструктивный пиелонефрит = неотложная декомпрессия, профилактика по типу камня —
> доказательная медицина (рекомендации по нефролитиазу, сверено июнь 2026; сверять локально).
> Двигатели обмен/застой-дренажа/Тепло-инфекция, кристаллический осадок, энергии — рамка-навигатор
> METACOD, не основание для назначения. Вектор = направление + класс; решение, метод и объём
> вмешательства — за лечащим врачом.
