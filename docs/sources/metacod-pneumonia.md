## 1. Что это в системе: инфекция заполняет газообменную поверхность
Пневмония — инфекционное воспаление лёгочной паренхимы: альвеолы заполняются экссудатом,
газообмен страдает. Это двигатель **Инфекция (Том 2, гл. 8) + Тепло/воспаление (Т1.10)** в лёгком;
фундамент ПОТОК × ГРАНИЦА на уровне **альвеолярной мембраны** (кислород не проходит через
заполненную альвеолу). Ключевые вопросы METACOD: **где приобретена** (внебольничная vs
внутрибольничная — определяет спектр возбудителей и антибиотик) и **насколько тяжела**
(амбулаторно vs стационар vs ОРИТ).

**Главный фильтр (маска):** «инфильтрат + лихорадка + кашель» — не всегда типичная бактериальная
пневмония; снять маску: вирусная (грипп/COVID), атипичная, ТЭЛА с инфарктом
(`metacod-pulmonary-embolism.md`), сердечная недостаточность/отёк лёгких (Том 3, гл. 2), рак/
обструкция, аспирация, туберкулёз, организующаяся пневмония (ИЗЛ).

## 2. Маркёр: диагноз и тяжесть
- **Клиника:** лихорадка, кашель (часто продуктивный), одышка, плевритная боль, хрипы/
  бронхиальное дыхание; у пожилых — стёрто (спутанность, падение — Том 3, гл. 3);
- **Рентген грудной клетки** — инфильтрат (подтверждение); насыщение кислородом, при тяжести —
  газы крови;
- **тяжесть — шкалы: CURB-65** (Confusion, Urea >7 ммоль/л, Respiratory rate ≥30, Blood pressure
  низкое, age ≥65; 1 балл за каждый) или PSI — для решения амбулаторно/стационар/ОРИТ; CRB-65 без
  лабораторных — у постели;
- **микробиология по тяжести** (посевы крови/мокроты, антигены мочи — пневмококк/легионелла, ПЦР
  на вирусы) — особенно при стационаре/ОРИТ; биомаркёры (прокальцитонин) — вспомогательно.

## 3. Вектор: лечение (эмпирически по месту/тяжести, затем деэскалация)
- **Амбулаторно (лёгкая, CURB-65 0–1):** пероральный антибиотик по локальным рекомендациям (часто
  аминопенициллин ± макролид / доксициклин; респираторный фторхинолон — альтернатива);
- **Стационар (среднетяжёлая, CURB-65 ≥2):** β-лактам ± макролид (или респираторный фторхинолон);
- **ОРИТ (тяжёлая):** β-лактам широкого спектра + макролид или фторхинолон; при факторах риска —
  покрытие синегнойной/MRSA; легионелла → фторхинолон;
- **деэскалация** по культурам/улучшению, переход на пероральный, разумная длительность (часто
  короткие курсы достаточны);
- **поддержка:** кислород, жидкости, при тяжёлой ВП — рассмотреть **глюкокортикоид** (по
  современным данным улучшает исходы при тяжёлой ВП у отдельных);
- **внутрибольничная/вентилятор-ассоциированная** — другой спектр (антисинегнойные/MRSA по риску);
- профилактика: вакцинация (пневмококк, грипп), отказ от курения; искать причину рецидива
  (обструкция/рак, аспирация).

**На языке мембраны (рамка):** пневмония = инфекция + Тепло, заполняющие газообменную мембрану.
Вектор — подавить инфекцию по спектру места/тяжести (антибиотик) + поддержать газообмен
(кислород). Рамка вторична — это инфекция/граница; спектр и сроки — EBM/локальная резистентность.

## 4. Граница (НЕОТЛОЖНОЕ)
- **Тяжёлая пневмония / сепсис / септический шок** (Том 2, гл. 8) → ранние антибиотики +
  реанимация; **дыхательная недостаточность** (Том 3, гл. 2) → кислород/вентиляция/ОРИТ;
- осложнения: **парапневмонический выпот/эмпиема** (дренирование), абсцесс, ОРДС;
- ⚠️ исключить ТЭЛА (может имитировать) и отёк лёгких (СН); у пожилого — спутанность/падение как
  единственное проявление (Том 3, гл. 3, 12).

## 5. Перекрёстки
- **Инфекция/сепсис (Том 2, гл. 8):** ранние антибиотики, источник, шок.
- **Одышка (Том 3, гл. 2):** пневмония vs СН vs ТЭЛА vs обострение ХОБЛ/астмы.
- **ХОБЛ:** частый провокатор обострения; ICS ↑ риск пневмонии.
- **ТЭЛА:** имитатор/сопутствующее.
- **Онкология (Т1.1):** рецидив в одной зоне → обструкция/рак.

## 6. Карманная версия
1. Пневмония = **инфекция + Тепло в паренхиме** (газообменная мембрана заполнена); ключ — **где
   приобретена и насколько тяжела**.
2. Маркёр: клиника + рентген (инфильтрат); тяжесть — **CURB-65** (амбулаторно/стационар/ОРИТ);
   микробиология по тяжести.
3. Снять маску: вирусная, ТЭЛА, отёк лёгких (СН), рак/обструкция, аспирация, ТБ.
4. Вектор: **эмпирический антибиотик по месту/тяжести** (амбулаторно → β-лактам±макролид → ОРИТ
   β-лактам + макролид/фторхинолон; покрытие синегнойной/MRSA по риску); деэскалация; кислород;
   стероид при тяжёлой ВП у отдельных; вакцинация.
5. Граница: сепсис/шок, дыхательная недостаточность, эмпиема/абсцесс → неотложно.
6. Мембрана/энергия: инфекция + Тепло; вектор = подавить по спектру + поддержать газообмен.
   Решение, препарат, доза — лечащий врач.

> Диагноз (клиника + рентген), CURB-65 для сортировки, эмпирическая терапия по месту/тяжести с
> деэскалацией, стероид при тяжёлой ВП у отдельных, вакцинация — доказательная медицина (IDSA/ATS,
> BTS и рекомендации, сверено июнь 2026; сверять локально). Двигатели Инфекция/Тепло, энергии —
> рамка-навигатор METACOD, не основание для назначения. Вектор = направление + класс; препарат,
> доза и решение — за лечащим врачом.
