# МОНОГРАФИЯ METACOD · Углублённый разбор · Пульмонология

## ТЭЛА (тромбоэмболия лёгочной артерии) — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение ТЭЛА: здесь реальная помощь, и это
потенциально жизнеугрожающее состояние. Поверх — фильтры METACOD (двигатель, мембрана, маркёр,
граница). Данные сверены (ESC 2019/обновления, рекомендации по ВТЭ, июнь 2026; сверять локально).
Препарат, доза, решение — лечащий врач/неотложная бригада.

## 1. Что это в системе: тромб перекрыл лёгочный поток
ТЭЛА — закупорка лёгочной артерии тромбом (чаще приплывшим из глубоких вен ног — это единый
**венозный тромбоэмболизм, ВТЭ**). Двигатель — **Свёртывание (Т2.4)**: где-то образовался тромб
(**триада Вирхова** — застой, повреждение стенки, гиперкоагуляция), оторвался и застрял в лёгочном
русле → нарушение перфузии, перегрузка правого желудочка, гипоксемия. Фундамент ПОТОК × ГРАНИЦА:
лёгочный кровоток внезапно перекрыт. Мембранно/энергетически — острая тромботическая катастрофа
сосуда; это **граница**.

**Главный фильтр (маска и обратная маска):** ТЭЛА — «великий имитатор» и часто пропускается;
проявления неспецифичны (одышка, плевритная боль, тахикардия, синкопе, кровохарканье). Думать о
ТЭЛА при **необъяснённой одышке/тахикардии**, особенно с факторами риска. Снять маску: ОКС,
пневмония, СН, расслоение аорты, пневмоторакс, тревога.

## 2. Маркёр: диагностика по вероятности (порядок критичен)
- **Оценить претестовую вероятность** (шкала Wells или Geneva): низкая/промежуточная/высокая;
- **PERC** — у пациентов с очень низкой вероятностью: если все критерии отрицательны, ТЭЛА
  практически исключена без анализов;
- **D-димер** — при низкой/промежуточной вероятности: нормальный → исключает (с поправкой на
  возраст); повышенный — неспецифичен, нужна визуализация;
- **КТ-ангиопульмонография (CTPA)** — основной подтверждающий тест; при противопоказании (почки/
  контраст/беременность) — вентиляционно-перфузионная сцинтиграфия;
- ⚠️ при **высокой вероятности / нестабильности** — сразу к визуализации/лечению, не тратить
  время на D-димер;
- оценка тяжести/риска: гемодинамика (гипотензия/шок = массивная), маркёры перегрузки ПЖ (ЭхоКГ,
  тропонин, BNP), индексы (sPESI) — для выбора тактики; искать источник (УЗИ вен ног).

## 3. Вектор: лечение
- **Антикоагуляция — основа** (как только вероятность высока, если нет высокого риска
  кровотечения — начинать, не дожидаясь подтверждения при высокой вероятности):
- **DOAC** (апиксабан/ривароксабан и др.) — предпочтительны для большинства стабильных;
- **низкомолекулярный гепарин/НФГ** — в острой фазе/особых ситуациях (беременность — НМГ, тяжёлая
  почечная недостаточность — НФГ);
- длительность — **≥3 мес**; продлённо при сохраняющемся факторе риска/идиопатической (взвешивая
  кровотечение);
- **Массивная ТЭЛА (гипотензия/шок) → реперфузия:** системный тромболизис (если нет
  противопоказаний) или катетерная/хирургическая эмболэктомия — неотложно (Том 3, гл. 2, 4);
- **субмассивная** (перегрузка ПЖ без гипотензии) — мониторинг, антикоагуляция, реперфузия у
  отдельных при ухудшении;
- **кава-фильтр** — при противопоказании к антикоагуляции/рецидиве на терапии;
- **искать причину:** провоцирующий фактор (операция, иммобилизация, рак, эстрогены,
  беременность, тромбофилия) — определяет длительность и обследование (онкопоиск при
  неспровоцированной по показаниям).

**На языке мембраны (рамка):** ТЭЛА = острая тромботическая катастрофа (Свёртывание Т2.4),
перекрывшая лёгочный поток. Вектор — остановить и не дать нарастать тромбу (антикоагуляция), при
шоке — растворить/удалить (реперфузия); затем профилактика рецидива. Рамка вторична — это граница,
баланс тромбоз↔кровотечение.

## 4. Граница (НЕОТЛОЖНОЕ)
- **Массивная ТЭЛА с шоком/остановкой** → реанимация + тромболизис/эмболэктомия — немедленно;
- синкопе/гипотензия/гипоксемия с подозрением → срочная диагностика и лечение (Том 3, гл. 2, 4);
- ⚠️ при высокой вероятности — начать антикоагуляцию до подтверждения (если безопасно);
- беременность — особые алгоритмы (НМГ, осторожная визуализация).

## 5. Перекрёстки
- **Свёртывание (Т2.4):** ядро механизма; баланс с кровотечением (НПВС+антикоагулянт, гемостаз).
- **Одышка/боль в груди/обморок (Том 3, гл. 1, 2, 4):** ТЭЛА в дифференциале каждого.
- **Онкология (Т1.1):** рак — фактор риска ВТЭ; неспровоцированная ТЭЛА → онконастороженность.
- **ХОБЛ/пневмония/СН:** имитаторы и сопутствующее.
- **Нефротический синдром, ФП:** другие протромботические/эмболические состояния.

## 6. Карманная версия
1. ТЭЛА = **тромб перекрыл лёгочный поток** (Свёртывание Т2.4); «великий имитатор», часто
   пропускается — думать при необъяснённой одышке/тахикардии/синкопе.
2. **Диагностика по вероятности:** Wells → PERC (очень низкая) → D-димер (низкая/промежуточная,
   нормальный исключает) → **КТ-ангиопульмонография**; при высокой вероятности/нестабильности —
   сразу визуализация/лечение.
3. Вектор: **антикоагуляция** (DOAC для большинства; НМГ при беременности/раке; НФГ при тяжёлой
   ХБП), ≥3 мес; **массивная (шок) → тромболизис/эмболэктомия** неотложно.
4. Искать причину (провоцирующий фактор/рак/тромбофилия) — определяет длительность.
5. Граница: массивная ТЭЛА с шоком → реперфузия немедленно; при высокой вероятности —
   антикоагуляция до подтверждения.
6. Мембрана/энергия: острый тромбоз сосуда; вектор = остановить тромб + при шоке растворить/
   удалить + профилактика. Решение, препарат, доза — лечащий врач/бригада.

> Диагностика по претестовой вероятности (Wells/PERC/D-димер/КТ-ангиопульмонография),
> антикоагуляция (DOAC предпочтительны) ≥3 мес, тромболизис при массивной, поиск причины —
> доказательная медицина (ESC и рекомендации по ВТЭ, сверено июнь 2026; сверять локально).
> Двигатель Свёртывание (Т2.4), энергии — рамка-навигатор METACOD, не основание для назначения;
> ТЭЛА ведётся по неотложным протоколам. Вектор = направление + класс; препарат, доза и решение —
> за лечащим врачом/бригадой.
