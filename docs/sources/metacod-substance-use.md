# МОНОГРАФИЯ METACOD · Углублённый разбор · Психиатрия в общей медицине

## РАССТРОЙСТВА, СВЯЗАННЫЕ С УПОТРЕБЛЕНИЕМ АЛКОГОЛЯ И ДРУГИХ ВЕЩЕСТВ — через фильтры METACOD

**Как читать.** Стержень — доказательное распознавание и ведение расстройств употребления и
абстинентных синдромов: здесь реальная помощь. Поверх — фильтры METACOD. Подача бережная и без
осуждения: это **хронические медицинские состояния, поддающиеся лечению**. Данные сверены (DSM-5,
рекомендации, июнь 2026; сверять локально). Препарат, доза, решение — врач; сложное — нарколог/
психиатр.

## 1. Что это в системе: захват системы вознаграждения
Расстройство употребления — **хроническое рецидивирующее состояние, при котором система
вознаграждения мозга «захвачена» веществом:** продолжение употребления несмотря на вред, потеря
контроля, тяга, толерантность, абстиненция. Это **медицинская проблема, не моральная слабость** —
важная установка для эффективной помощи. В рамке METACOD: хронический «крючок» влечения +
абстиненция как вегетативная буря (избыточный Ветер) при отмене. Двунаправленная связь с депрессией/
тревогой (`metacod-depression-anxiety.md`) и с соматикой (печень, ЖКТ, сердце, инфекции, травмы).

**Главный фильтр (снять маску в обе стороны):** вещества имитируют и провоцируют множество состояний
(тревога, депрессия, делирий, аритмии, болезни печени); и наоборот — расстройство употребления часто
скрыто за соматическими/психическими жалобами. Спрашивать **тактично и рутинно (скрининг), без
осуждения**.

## 2. Маркёр: распознавание
- **критерии DSM-5** (потеря контроля, тяга, продолжение несмотря на вред, толерантность,
  абстиненция, ущерб ролям/здоровью); степень тяжести по числу критериев;
- **скрининг** (краткие опросники по алкоголю), лабораторные косвенные маркёры (печень, макроцитоз
  — `metacod-anemia.md`), анамнез;
- оценить коморбидность (депрессия/тревога/ПТСР), соматические осложнения, риск абстиненции.

## 3. Абстинентные синдромы (часть — неотложности)
- ⚠️ **Алкогольная абстиненция:** от лёгкой (тремор, тревога, потливость) до тяжёлой — судороги
  (`metacod-epilepsy.md`) и **delirium tremens** (делирий + вегетативная буря — потенциально
  смертелен); тяжесть — по шкале **CIWA**; ⚠️ лечение — **бензодиазепины** (симптом-триггерно по
  CIWA) + поддержка; ⚠️ **тиамин ДО глюкозы** (профилактика энцефалопатии Вернике); электролиты
  (магний, `metacod-electrolytes-acidbase-renal.md`);
- **Опиоидная абстиненция:** тягостна, но обычно не смертельна сама по себе; лечится; ⚠️ главная
  угроза опиоидов — **передозировка** (угнетение дыхания → налоксон) —
  `metacod-psychiatric-emergencies.md`;
- **седативно-снотворная** абстиненция (как алкогольная — опасна), стимуляторная, никотиновая.

## 4. Вектор: лечение (без осуждения, доказательно)
- **Алкоголь:** управление абстиненцией (CIWA + бензодиазепины + тиамин); **поддержка воздержания**
  — психосоциальные вмешательства + фармакотерапия (налтрексон, акампросат и др.); лечить
  коморбидность;
- **Опиоиды:** ⚠️ **медикаментозная терапия — основа и спасает жизни:** бупренорфин, метадон
  (агонисты/частичные — снижают тягу, смертность, передозировки), налтрексон (антагонист) у
  отдельных; **снижение вреда** (доступ к налоксону!), лечение сопутствующего (инфекции —
  `metacod-endocarditis-meningitis.md`, `metacod-skin-soft-tissue.md`, вирусные гепатиты);
- **Табак:** никотинзаместительная терапия и др. + поддержка (важнейшее вмешательство при ХОБЛ/ИБС/
  раке);
- **общее:** уважительный, мотивационный подход; лечение коморбидной депрессии/тревоги; длительное
  сопровождение (**рецидив не «провал», а часть процесса**).

**На языке мембраны (рамка):** захват системы вознаграждения (хронический «крючок») + абстиненция
как вегетативная буря (Ветер). Вектор — управлять абстиненцией безопасно (особенно алкоголь — CIWA/
бензодиазепины/тиамин) + поддержать воздержание/снижение вреда (опиоиды — агонисты/налтрексон +
налоксон) + лечить коморбидность, без осуждения.

## 5. Граница (НЕОТЛОЖНОЕ)
- ⚠️ **Delirium tremens / тяжёлая алкогольная абстиненция** (судороги, вегетативная буря,
  спутанность) → неотложно: бензодиазепины + тиамин + поддержка (`metacod-delirium.md`,
  `metacod-epilepsy.md`);
- ⚠️ **Опиоидная передозировка** (угнетение дыхания/сознания) → налоксон + поддержка дыхания
  (`metacod-psychiatric-emergencies.md`);
- ⚠️ **энцефалопатия Вернике** (спутанность/глазодвигательные/атаксия) → тиамин немедленно;
- тяжёлая интоксикация, суицидальный риск (`metacod-psychiatric-emergencies.md`).

## 6. Перекрёстки
- **Делирий:** алкогольная/седативная абстиненция = delirium tremens.
- **Эпилепсия:** абстинентные судороги.
- **Психиатрические неотложности:** передозировка (налоксон), суицидальный риск.
- **Депрессия/тревога:** двунаправленная коморбидность.
- **Печень / Анемии / Эндокардит / Электролиты:** соматические осложнения; тиамин/магний.
- **Хронические болезни (вся книга):** курение/алкоголь — модифицируемые факторы.

## 7. Карманная версия
1. Расстройство употребления = **хроническое медицинское состояние** (захват вознаграждения), не
   моральная слабость; подход — уважительный, без осуждения.
2. ⚠️ **Снять маску в обе стороны:** вещества имитируют/провоцируют (тревога, делирий, аритмии,
   печень); и наоборот — скрыто за жалобами; скринировать рутинно.
3. Маркёр: критерии DSM-5, скрининг, коморбидность, риск абстиненции.
4. ⚠️ **Абстиненция:** алкоголь — **CIWA + бензодиазепины + тиамин ДО глюкозы** (судороги, delirium
   tremens опасны); опиоиды — лечится, главная угроза — передозировка (налоксон).
5. Вектор: алкоголь (налтрексон/акампросат + психосоциальное); опиоиды — бупренорфин/метадон/
   налтрексон + **налоксон** (спасает жизни); табак (НЗТ); лечить коморбидность; рецидив — часть
   процесса.
6. Граница: delirium tremens, передозировка опиоидов (налоксон), Вернике (тиамин) → неотложно.
   Мембрана/энергия: крючок + буря отмены; вектор = безопасная отмена + поддержка. Решение, препарат
   — врач/нарколог.

> Критерии DSM-5, управление абстиненцией (алкоголь — CIWA/бензодиазепины/тиамин до глюкозы; delirium
> tremens опасен), опиоиды (агонистная терапия бупренорфин/метадон, налтрексон, налоксон при
> передозировке), поддержка воздержания без осуждения — доказательная медицина (рекомендации, сверено
> июнь 2026; сверять локально). «Крючок»/Ветер отмены — рамка-навигатор METACOD, не основание для
> назначения. Вектор = направление + класс; препарат, доза и решение по конкретному человеку — за
> врачом, при сложном — за наркологом/психиатром.
