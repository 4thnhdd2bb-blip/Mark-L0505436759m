## 1. Что это в системе: иммунитет атакует стенку сосуда
Васкулиты — группа болезней с **воспалением стенки кровеносных сосудов** → сужение/окклюзия
(ишемия тканей за сосудом) или ослабление/разрыв (аневризмы, кровоизлияния). Двигатель — **Сухость-
иммунитет (Т1.8) + Тепло (Т1.10)**, атакующие сосуд; итог — нарушение потока к органам (фундамент
ПОТОК × ГРАНИЦА: повреждена сама труба). **Классифицируют по калибру сосуда**, что определяет
картину и подход:
- **крупные сосуды:** гигантоклеточный артериит (височный), артериит Такаясу;
- **средние:** узелковый полиартериит, болезнь Кавасаки;
- **мелкие:** ANCA-ассоциированные (гранулематоз с полиангиитом, микроскопический полиангиит,
  эозинофильный), иммунокомплексные (IgA-васкулит/Шёнлейна-Геноха, криоглобулинемический,
  анти-ГБМ).

**Главный фильтр (маска):** васкулит — «великий имитатор»: системные симптомы (лихорадка, потеря
веса, утомляемость) + органная ишемия в неожиданных местах. Снять маску: инфекции (**эндокардит!**
— Том 2 гл. 8), злокачественность, тромбоэмболии, другие системные болезни, лекарственные. И
наоборот — думать о васкулите при необъяснённой многоорганной ишемии/гломерулонефрите + системных
симптомах.

## 2. Маркёр: диагноз
- **Клиника по калибру:** крупные — головная боль/челюстная хромота/нарушение зрения
  (гигантоклеточный), отсутствие пульса/разница АД (Такаясу); мелкие — лёгочно-почечный синдром
  (кровохарканье + гломерулонефрит), пурпура, мононеврит, ЛОР (седловидный нос, синуситы при
  гранулематозе);
- **Лабораторно:** СРБ/СОЭ (часто очень высокие — Тепло), **ANCA (PR3/MPO** — для
  ANCA-ассоциированных), комплемент/криоглобулины/анти-ГБМ по подозрению, моча (нефрит —
  `metacod-glomerular.md`);
- **Визуализация/биопсия:** биопсия поражённого органа (височная артерия, почка, кожа) — часто
  решающая; визуализация сосудов (УЗИ/КТ/МР/ПЭТ) при крупных.

## 3. Вектор: лечение (индукция → поддержание)
- **Общая логика:** индукция ремиссии (быстро погасить) → поддержание;
- **Глюкокортикоиды** — основа индукции (часто высокие/пульс при тяжёлом);
- **+ иммуносупрессия/таргетная по типу:** ANCA-ассоциированные → **ритуксимаб или циклофосфамид
  + стероид** (тяжёлый — пульс, плазмаобмен у отдельных); поддержание — ритуксимаб/азатиоприн;
- **гигантоклеточный артериит → немедленно высокие дозы глюкокортикоидов** (НЕ ждать биопсии —
  риск необратимой слепоты!); тоцилизумаб как стероид-сберегающий;
- ⚠️ скрининг перед иммуносупрессией (туберкулёз, гепатиты), профилактика инфекций (пневмоцистной
  при интенсивной), вакцинация; вести стероид-осложнения (кость, надпочечники, диабет);
- лечить причину при вторичных (инфекция, лекарство, криоглобулины/гепатит C).

**На языке мембраны (рамка):** васкулит = иммунная атака на стенку сосуда (Сухость-иммунитет +
Тепло) → нарушение потока к органам. Вектор — быстро погасить воспаление (стероид + иммуносупрессия/
биологик по типу, индукция → поддержание) и спасти орган до необратимой ишемии.

## 4. Граница (НЕОТЛОЖНОЕ — спасение органа)
- ⚠️ **Гигантоклеточный артериит с угрозой зрения** (новая головная боль у пожилого + челюстная
  хромота + нарушение зрения + ↑СОЭ) → немедленно высокие глюкокортикоиды, **не дожидаясь биопсии**
  (слепота необратима);
- **лёгочно-почечный синдром** (кровохарканье + быстропрогрессирующий гломерулонефрит, ANCA/
  анти-ГБМ) → неотложная индукция ± плазмаобмен (`metacod-glomerular.md`);
- мезентериальная/коронарная/церебральная ишемия при системном васкулите;
- ⚠️ исключить инфекцию-имитатор (эндокардит — Том 2 гл. 8) прежде интенсивной иммуносупрессии.

## 5. Перекрёстки
- **Гломерулярные болезни:** ANCA-васкулит — быстропрогрессирующий ГН (неотложно).
- **Инфекция (Том 2, гл. 8):** эндокардит и др. имитируют васкулит; скрининг перед
  иммуносупрессией; гепатит C → криоглобулинемический.
- **Зрение/неврология (Том 2, гл. 9; Том 3):** гигантоклеточный артериит — слепота; мононеврит.
- **Остеопороз/надпочечники/диабет:** высокие стероиды длительно.
- **ТЭЛА/тромбоз (Т2.4):** дифференциал органной ишемии.

## 6. Карманная версия
1. Васкулит = **иммунное воспаление стенки сосуда** (Сухость-иммунитет + Тепло) → ишемия/разрыв;
   классифицируют по калибру (крупные/средние/мелкие).
2. Снять маску: инфекция (**эндокардит!**), опухоль, тромбоэмболия; и наоборот — думать при
   необъяснённой многоорганной ишемии + системных симптомах.
3. Маркёр: СРБ/СОЭ (высокие), **ANCA** (мелкие), моча (нефрит), биопсия/визуализация по калибру.
4. Вектор: **индукция** (глюкокортикоиды ± ритуксимаб/циклофосфамид по типу) → поддержание;
   скрининг инфекций перед иммуносупрессией; вести стероид-осложнения.
5. ⚠️ **Граница: гигантоклеточный артериит с угрозой зрения → немедленно стероиды, не ждать
   биопсии** (слепота!); лёгочно-почечный синдром → неотложная индукция ± плазмаобмен; исключить
   эндокардит.
6. Мембрана/энергия: атака на трубу потока; вектор = быстро погасить + спасти орган. Решение,
   препарат, доза — ревматолог.

> Классификация по калибру, ANCA, биопсия, индукция/поддержание, гигантоклеточный артериит =
> немедленные стероиды до биопсии (риск слепоты), лёгочно-почечный синдром, исключение
> инфекции-имитатора — доказательная медицина (ACR/EULAR и рекомендации, сверено июнь 2026; сверять
> локально). Двигатели Сухость-иммунитет/Тепло, энергии — рамка-навигатор METACOD, не основание для
> назначения. Вектор = направление + класс; препарат, доза и решение — за ревматологом.
