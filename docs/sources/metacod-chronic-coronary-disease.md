# МОНОГРАФИЯ METACOD · Углублённый разбор · Кардиология

## ИБС И СТАБИЛЬНАЯ СТЕНОКАРДИЯ (хроническая коронарная болезнь) — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение хронической коронарной болезни:
здесь реальная помощь. Поверх — фильтры METACOD (двигатель, мембрана, маска, маркёр, вектор,
граница). Данные сверены (ACC/AHA Chronic Coronary Disease 2023, ESC 2024, июнь 2026; сверять
локально). Препарат, доза, решение — лечащий врач.

> Прикладной разбор болезни для направления 1 (кардиология). Связан с: `metacod-tom1.md` (Т1.12),
> `metacod-tom3.md` (гл. 1), `metacod-dyslipidemia.md`, `metacod-cardiorenal-cluster.md`,

## 1. Что это в системе: спрос превышает доставку
Стабильная стенокардия — **обратимая ишемия миокарда при нагрузке:** сужение коронарной артерии
бляшкой ограничивает доставку кислорода, и при росте потребности (нагрузка, стресс, холод, еда)
возникает боль/дискомфорт, проходящие в покое/после нитроглицерина. Двигатель — **Атеросклероз
(Т1.12)** в коронарном русле; мембранно (рамка) — стерольно-воспалительная бляшка (M-A) со
склерозом (M-S). Это хроническая, стабильная форма того же процесса, чья острая форма — ОКС
(разрыв бляшки, отдельный разбор).

**Главная задача — две цели сразу:** (1) **улучшить прогноз** (предотвратить инфаркт/смерть —
модификация атеросклероза) и (2) **снять симптомы** (антиангинальные). Их нельзя путать: часть
лечения продлевает жизнь, часть только облегчает боль.

## 2. Маска: типичная стенокардия и её имитаторы
- **Типичная стенокардия = три признака:** загрудинный дискомфорт характерного типа + провокация
  нагрузкой/стрессом + облегчение покоем/нитратами; атипичная — два из трёх.
- **Снять маску (Том 3, гл. 1):** ОКС (боль в покое/нарастающая → не «стабильная»!), расслоение
  аорты, ТЭЛА, перикардит, ГЭРБ, скелетно-мышечная, тревога; микрососудистая/вазоспастическая
  стенокардия (ИНОКА/ANOCA — стенокардия без обструктивных стенозов).
- Учесть атипичные группы (женщины, диабет, пожилые — стёртая/эквиваленты: одышка,
  утомляемость).

## 3. Маркёр: подтверждение и стратификация
- Оценка **предтестовой вероятности** (возраст, пол, характер боли, факторы риска).
- **Анатомия:** КТ-коронарография — предпочтительный неинвазивный тест при низкой-средней
  вероятности; инвазивная коронарография — при высоком риске/рефрактерности.
- **Ишемия (функция):** стресс-тесты с визуализацией (стресс-ЭхоКГ, перфузия); при пограничных —
  FFR/iFR на катетеризации.
- Базово: ЭКГ покоя, липиды (ЛПНП), HbA1c/глюкоза, функция почек, ЭхоКГ (ФВ).

## 4. Вектор: лечение
### 4.1. Улучшающее ПРОГНОЗ (модификация атеросклероза — главное)
- **Статин высокой интенсивности** ± эзетимиб/PCSK9 до цели ЛПНП (вторичная профилактика <55
  мг/дл / 1,4 ммоль/л);
- **Антиагрегант** (аспирин; клопидогрел как альтернатива);
- иАПФ/БРА — при сопутствующих диабете/гипертонии/СН/ХБП;
- контроль факторов (АД <130/80, диабет с SGLT-2/GLP-1, отказ от курения, вес, активность);
- ⚠️ **при стабильной ИБС реваскуляризация (стент/шунт) улучшает симптомы, но у большинства не
  превосходит оптимальную медикаментозную терапию по выживаемости** — кроме анатомии высокого
  риска (ствол, многососудистое с дисфункцией ЛЖ, большая зона ишемии). Решение — кардиокоманда.

### 4.2. Снимающее СИМПТОМЫ (антиангинальные)
- **Первая линия:** β-блокатор и/или блокатор кальциевых каналов (по ЧСС/АД/переносимости);
  короткодействующий нитрат — для купирования приступа;
- **Вторая линия/добавление:** длительные нитраты, ранолазин, ивабрадин, никорандил;
- **Вазоспастическая** → блокаторы кальциевых каналов (± нитраты), избегать неселективных
  β-блокаторов; **микрососудистая** → лечить факторы + антиангинальные.

### 4.3. На языке мембраны (рамка)
Прогноз-вектор = «остановить топливо бляшки» (M-A→M-S): статин/контроль факторов совпадают.
Симптом-вектор = «снизить спрос миокарда» (β-блок/БКК) — облегчение, не модификация болезни.
Рамка помогает **не путать две цели;** дозы — EBM.

## 5. Граница
- Боль в покое / нарастающая / >20 мин / с потом-иррадиацией = **ОКС, не «стабильная»** →
  неотложно (Том 3, гл. 1; разбор «ОКС»).
- Внезапное ухудшение толерантности к нагрузке (нестабильная стенокардия) → срочная оценка.
- Расслоение аорты, ТЭЛА как имитаторы → исключить при тревожной картине.

## 6. Перекрёстки
- **Дислипидемия / гипертония / диабет / ХБП** — общий кластер; модификация атеросклероза едина.
- **Сердечная недостаточность** — ишемия как причина.
- **ОКС** — острая форма того же двигателя.

## 7. Карманная версия
1. Стабильная стенокардия = обратимая ишемия при нагрузке (двигатель Атеросклероз); снять маску
   (**ОКС в покое!** расслоение, ТЭЛА, ГЭРБ, микрососудистая).
2. Маркёр: предтестовая вероятность → КТ-коронарография (низко-средняя) / стресс-тест /
   инвазивно (высокий риск); липиды, ЭхоКГ.
3. **Прогноз (главное):** статин до ЛПНП <55 + антиагрегант + контроль факторов; иАПФ/БРА по
   сопутствующему; реваскуляризация — симптомы/анатомия высокого риска (не рутинно ради
   выживаемости).
4. **Симптомы:** β-блокатор/БКК + нитрат для приступа; вторая линия — ранолазин/ивабрадин.
5. Граница: боль в покое/нарастающая = ОКС → неотложно.
6. Мембрана/энергия: бляшка M-A→M-S; два вектора — модификация болезни vs снятие спроса.
   Решение, препарат, доза — лечащий врач.

> Стратегия двух целей (прогноз vs симптомы), КТ-коронарография, цели ЛПНП, место
> реваскуляризации — доказательная медицина (ACC/AHA 2023 Chronic Coronary Disease, ESC 2024,
> сверено июнь 2026; сверять локально). Двигатель Атеросклероз, мембрана M-A/M-S, энергии —
> рамка-навигатор METACOD, не основание для назначения. Вектор = направление + класс; препарат,
> доза и решение — за лечащим врачом.
