# МОНОГРАФИЯ METACOD · Углублённый разбор · Инфекционные болезни

## ИНФЕКЦИИ КОЖИ И МЯГКИХ ТКАНЕЙ — через фильтры METACOD

**Как читать.** Стержень — доказательная диагностика и лечение инфекций кожи и мягких тканей
(ИКМТ): здесь реальная помощь, и главная задача — **не пропустить некротизирующую (неотложную)**.
Поверх — фильтры METACOD (двигатель, маска, маркёр, вектор, граница). Связь с узлом «Инфекция» (Том
2, гл. 8). Данные сверены (IDSA SSTI и рекомендации, июнь 2026; сверять локально). Препарат, доза,
решение — лечащий врач/хирург.

> Прикладной разбор болезни для направления 1 (инфекционные). Связан с: `metacod-tom1.md` (Т1.10),
> `metacod-tom2.md` (гл. 8 инфекция), `metacod-sepsis.md`, `metacod-diabetes.md`, `metacod-gout.md`,
> `metacod-antibiotics-stewardship.md`.

## 1. Что это в системе: инфекция в коже и под ней
ИКМТ — спектр от поверхностного до жизнеугрожающего, и **главный фильтр METACOD — глубина и
скорость:** банальный целлюлит vs **некротизирующая инфекция (хирургическая неотложность)**.
Двигатель — **Инфекция (Том 2, гл. 8) + Тепло (Т1.10)**; фундамент ПОТОК × ГРАНИЦА — кожа как барьер
прорвана (входные ворота: рана, трещина, укус, отёк, диабетическая стопа).

**Два разводящих фильтра:**
- **гнойная vs негнойная:** гнойная (абсцесс/фурункул — часто стафилококк, в т. ч. MRSA) →
  дренирование в основе; негнойная (рожа/целлюлит — часто стрептококк) → антибиотик;
- ⚠️ **некротизирующая vs ненекротизирующая:** некротизирующий фасциит — глубокая, стремительная,
  угрожающая жизни инфекция → немедленная хирургия + широкий спектр.

## 2. Состояния
- **Рожа (erysipelas):** яркая, чётко отграниченная поверхностная (дерма), стрептококк;
- **Целлюлит:** более глубокая дерма/подкожная, менее очерчён; лихорадка/системность по тяжести;
- **Абсцесс/фурункул/карбункул:** ограниченное гнойное скопление → дренирование;
- **Некротизирующая инфекция (фасциит/мионекроз):** ⚠️ см. граница;
- **особые:** диабетическая стопа (`metacod-diabetes.md` — полимикробная, сосудистая, остеомиелит),
  укусы (анаэробы/особые), пролежни, инфекции после операций.

## 3. Маркёр: диагноз и тревожные признаки
- клинический диагноз (эритема, отёк, боль, тепло, ± гной, ± лихорадка); очертить границу маркером
  для динамики;
- посев — при гное (после дренирования), тяжёлых, иммунодефиците, неответе;
- ⚠️ **красные флаги некротизирующей инфекции:** **боль, непропорциональная осмотру**, быстрое
  распространение, системная токсичность/сепсис, буллы/некроз/изменение цвета кожи, крепитация
  (газ), анестезия кожи; визуализация/лаборатория (напр. шкалы) помогают, но **не должны
  задерживать хирургию** при клиническом подозрении;
- снять маску: тромбоз глубоких вен, подагра (`metacod-gout.md`), застойный дерматит, аллергия,
  рожистоподобные — не всё красное и тёплое инфекция.

## 4. Вектор: лечение
- **Гнойные (абсцесс):** разрез и дренирование — основа; антибиотик (с покрытием MRSA по риску) —
  при больших/множественных/системных/иммунодефиците;
- **Негнойные (целлюлит/рожа):** антибиотик с покрытием стрептококка (± стафилококка по картине);
  поднять/иммобилизовать конечность, лечить входные ворота/отёк; длительность — обычно короткая,
  по ответу;
- **тяжёлые/системные** → госпитализация, в/в, покрытие MRSA/широкий спектр по риску;
- ⚠️ **некротизирующая инфекция → немедленная хирургическая обработка (debridement)** +
  эмпирический широкий спектр (покрытие грам+, грам−, анаэробов, ± токсин-подавление) + реанимация
  (`metacod-sepsis.md`); промедление с хирургией = смерть;
- **диабетическая стопа** — мультидисциплинарно (сосуды, разгрузка, остеомиелит,
  `metacod-diabetes.md`);
- деэскалация по посеву; лечить источник/входные ворота, профилактика рецидива (отёк, кожа,
  гликемия).

**На языке мембраны (рамка):** ИКМТ = инфекция за прорванным кожным барьером (Инфекция + Тепло).
Вектор зависит от глубины/скорости: поверхностное → антибиотик/дренаж; **некротизирующее → срочная
хирургия**. Рамка вторична — при некротизирующем это граница, время и скальпель.

## 5. Граница (НЕОТЛОЖНОЕ)
- ⚠️ **Некротизирующий фасциит/мионекроз:** боль непропорциональна осмотру + быстрое распространение
  + системная токсичность + крепитация/буллы/некроз → **немедленная хирургия + широкий спектр +
  реанимация** (`metacod-sepsis.md`) — счёт на часы;
- сепсис/септический шок из мягкотканного очага (`metacod-sepsis.md`);
- диабетическая стопа с глубокой инфекцией/ишемией/остеомиелитом → срочно;
- особые токсин-опосредованные (синдром токсического шока) → неотложно.

## 6. Перекрёстки
- **Сепсис:** мягкотканный очаг; некротизирующая → анаэробное покрытие.
- **Диабет:** диабетическая стопа, тяжёлые/атипичные инфекции.
- **Антибиотикотерапия:** покрытие MRSA по риску, деэскалация, длительность.
- **Подагра/ТГВ:** имитаторы красной горячей конечности.
- **Кость:** остеомиелит при глубоких/хронических.

## 7. Карманная версия
1. Главный фильтр — **глубина и скорость:** банальный целлюлит vs некротизирующая инфекция
   (неотложность); и **гнойная (дренаж) vs негнойная (антибиотик)**.
2. Маркёр — клинический; посев при гное/тяжёлых; ⚠️ **красные флаги некроза: боль непропорциональна
   осмотру**, быстрое распространение, токсичность, крепитация/буллы/некроз.
3. Вектор: абсцесс → дренирование (± антибиотик с MRSA по риску); целлюлит/рожа → антибиотик
   (стрептококк ± стафилококк); тяжёлое → в/в/госпитализация.
4. ⚠️ **Некротизирующая → немедленная хирургия + широкий спектр + реанимация** (не задерживать ради
   тестов).
5. Граница: некротизирующий фасциит, сепсис из кожи, диабетическая стопа, токсический шок.
6. Мембрана/энергия: инфекция за прорванным барьером; вектор по глубине/скорости. Решение, препарат,
   доза, хирургия — врач/хирург.

> Фильтры (глубина/скорость, гнойная/негнойная), дренирование абсцесса, красные флаги
> некротизирующей инфекции (боль непропорциональна осмотру) → немедленная хирургия + широкий спектр,
> покрытие MRSA по риску, деэскалация — доказательная медицина (IDSA SSTI и рекомендации, сверено
> июнь 2026; сверять локально). Двигатели Инфекция/Тепло, энергии — рамка-навигатор METACOD;
> некротизирующая инфекция ведётся по неотложным/хирургическим протоколам. Вектор = направление +
> класс; препарат, доза и решение — за врачом/хирургом.
