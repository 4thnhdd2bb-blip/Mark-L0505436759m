# Мембраны — ядро системы

Центральная цель системы — **здоровая (нормальная) мембрана M-0**. Все симптомы, анализы и
лекарства интерпретируются через их влияние на состояние мембраны.

> Полный первоисточник: `sources/metacod-membrane.md` (спутник трилогии). ВАЖНО: разделять
> **науку** (липидный бислой, перекисное окисление — доказательно) и **рамку** (6 типов,
> pH-топография — навигатор, в статусе «энергий» Пак, НЕ основание для диагноза/лечения).

## Классификация мембран (6 типов)

Ось: **анаболизм (построение) ↔ катаболизм (разрушение)**, с фиброзом как застывшим исходом.

| Тип | Название | pH (рамка, внутр. зона) | Суть | Реальный двигатель |
|---|---|---|---|---|
| **M-0** | Нормальная (сбалансированная) | нейтрально | обновление без окислительного стресса — **цель** | здоровье |
| **M-A1** | Анаболическая лёгкая | щелочная (моча >7,0) | умеренный перевес синтеза, построение | Гиперплазия (Т1.3) |
| **M-A2** | Анаболическая глубокая | щелочная | выраженный анаболизм, ригидность, избыток стеролов | Влажность-обмен (Т1.7), Атеросклероз (Т1.12) |
| **M-D1** | Катаболическая лёгкая | кислая (моча <6,0) | начало разрушения/потерь | Холод/гипотиреоз (Т1.11), Саркопения (Т1.9) |
| **M-D2** | Катаболическая глубокая | кислая | активное перекисное окисление, распад | Кахексия (Т1.9), Сепсис (Т2.8), ишемия (ферроптоз) |
| **M-S** | Склеротическая («высохшая») | — (исход) | фиброз ЭЦМ; жёсткая, но «протекающая» | Фиброз (Т1.2) |

⚠️ **M-S = склеротическая (фиброз), НЕ рассеянный склероз.**
⚠️ **pH крови 7,35–7,45 — жёсткий инвариант, НЕ «тип мембраны».** Отклонение = неотложный
ацидоз/алкалоз (`sources/metacod-tom2.md`, гл. 6).

## Ось энергий (рамка Пак) → мембрана
- **Тепло** → анаболизм + окисление (M-A с риском M-D)
- **Влажность** → анаболизм, накопление (M-A)
- **Жар** (крайнее Тепло) → переключение M-A → M-D
- **Сухость** → катаболизм, истощение (M-D), исход M-S
- **Холод** → катаболизм, угасание (M-D)
- **Ветер** → нестабильность, переход между типами

## Объективные маркёры мембраны (где рамка опирается на науку — доказательно)
- **Фазовый угол биоимпеданса (PhA50)** — целостность мембран (↓ при катаболизме).
- **Перекисное окисление:** MDA, 4-HNE, GSH/GSSG, GPX4 (активно при M-D, подавлено при M-A).
- ECW/TBW (↑ при анаболическом сдвиге), BCM/FFM% (↓ при катаболизме), α Cole-Cole (узкий при M-S).

## ЕДИНАЯ КАРТА: двигатель → мембрана → pH → вектор лечения
Сводит ядро воедино. **Вектор = направление + класс; препарат/доза — лечащий врач.**

| # | Двигатель | Мембрана | pH-ось | Вектор (направление) |
|---|---|---|---|---|
| Т1.1 | Рак | локально M-A / системно M-D | dual | **прервать** (онколог) — не «коррекция типа» |
| Т1.2 | Фиброз | M-S | исход | убрать драйвер фиброза + антифибротики |
| Т1.3 | Гиперплазия | M-A1/A2 | щёлочь | сдержать по драйверу |
| Т1.4 | Ветер-нервы | M-0 функц./переход | — | снять маску → успокоить по окраске |
| Т1.5 | Ветер-клиренс | M-0/M-A | щёлочь | поддержать дренаж |
| Т1.6 | Влажность-вода | M-A | щёлочь | лечить орган-причину |
| Т1.7 | Влажность-обмен | M-A2/A3 | щёлочь | снизить складирование · **GLP-1 hard-stop** |
| Т1.8 | Сухость-иммунитет | M-D + Тепло | кислота | приглушить иммунитет |
| Т1.9 | Сухость-атрофия | M-D1/D2 | кислота | нарастить (белок + нагрузка) · **GLP-1 hard-stop** |
| Т1.10 | Тепло | M-A → риск M-D | окисление | острое не трогать / хроническое гасить |
| Т1.11 | Холод | M-D1 | кислота | поднять интенсивность (тиреоид) |
| Т1.12 | Атеросклероз | M-A + M-S | щёлочь+склероз | бить по 3 ветвям + стабилизировать |

## Виды лечения для восстановления мембран
> Направление коррекции = вернуть к M-0. **Сначала — доказательное лечение реальной болезни.**

| Состояние | Направление (рамка) | Доказательно берём | Рамочные предложения (только врач) |
|---|---|---|---|
| M-A (анаболический перевес) | катаболический/окислительный вектор | образ жизни, метформин, SGLT-2, GLP-1 (Т1.7) | NAC, альфа-липоевая кислота, берберин |
| M-D (катаболический перевес) | восстановительный/анаболический | белок 1,2–1,6 г/кг + нагрузка (Т1.9), левотироксин (Т1.11) | стерол-/нутритивная поддержка |
| M-S (склероз) | остановить драйвер фиброза | убрать драйвер, антифибротики при ИЛФ (Т1.2) | — |
| Окисление (M-D2) | антиоксидантная защита | **омега-3 ПНЖК, витамин E, флавонолы, магний** (доказательно по показаниям) | — |

> Доказательно (можно брать): состав мембраны корректируем питанием (омега-3, баланс
> омега-6/3); антиоксиданты тормозят перекисное окисление; восстановление состава потенцирует
> мембранные мишени (рецептор инсулина); магний — стабилизатор мембран.
> Рамка (осторожно): «тип по pH мочи» как диагноз, селен/сульфаты «по типу», лечение «сдвигом
> pH» — не доказанная терапия.
