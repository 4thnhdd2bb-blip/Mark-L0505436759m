# METACOD — архив проекта (11.06.2026)

Автор метода: Dr. Mark Litvak. Инженер: Omer. Язык: русский.
Принцип: METACOD — навигатор (поддержка решения), НЕ штурвал. Препарат, доза и решение — за врачом.

> Это манифест внешнего архива проекта (снимок состояния на 11.06.2026). Перечисленные ниже бинарные
> артефакты (docx, json, zip, xlsx, html) хранятся в архиве у автора, а НЕ в этом git-репозитории.
> Источник истины для разборов-знаний — markdown в `docs/sources/`; источник истины для прототипа
> кабинета-опоры — `app/index.html`.

## Что в архиве

### 01_Лечение_база
- **METACOD_лечение_350.docx** — полная база лечения на 350 разборов, строго по алгоритму METACOD:
  диагноз (энергоматрица + мембрана) → направление (M-A катаболич./M-D анаболич./M-0) →
  протокол (PATTERN_1 жар-сырость / PATTERN_2 холод-сырость / DIRECT) → режим (Ян остро / Инь хронич.) →
  схема цзюнь-чэнь-цзо-ши с долями дозы (Государь полная, Министры 70–100%, Помощники 30–50%, Посланник 10–20%).
- METACOD_лечение_60.docx — первые 60 (упрощённый формат).
- METACOD_лечение_сводка.docx — лечение по 13 базовым механизмам (с выверенными дозами).
- METACOD_лечение_образец.docx — образец полного формата (12 разборов).
- **METACOD_база_лечения_350.json** — те же 350 в структурированном виде (данные для внедрения в программу).

### 02_Кабинет
- metacod_cabinet.html — кабинет врач/пациент/админ, полностью трёхъязычный (RU/EN/HE, переключатель, RTL для иврита),
  встроенный опросник (153 вопроса), дифдвижок по 13 механизмам, заключение редактируемое+переводимое,
  и ЭКРАН «База лечения 350» (поиск по болезни/МКБ → диагноз по METACOD + схема цзюнь-чэнь-цзо-ши).
  (Клиническая часть заключения пока на русском — до выверки переводов.)

### 03_Опросники_пациента
- index_ru / index_en / index_he — опросник пациента (153 вопроса), офлайн, QR, выбор языка отчёта.

### 04_PWA_приложения (офлайн, иконка на экране)
- metacod_pwa_all.zip — ОДНО приложение, одна иконка: на старте выбор языка и роли (Пациент → опросник, Врач → кабинет).
- metacod_pwa_separate.zip — 4 отдельных приложения (кабинет + опросники RU/EN/HE).
  Установка: выложить папку на https (Netlify Drop) → открыть раз с интернетом → «Добавить на экран Домой».

### 05_Omer_монорепо
- metacod-omer.zip — TypeScript Expo + Firebase монорепо с движком (дифдиагностика, лечение, безопасность),
  i18n (questionnaire.json / ui_strings.json), трёхъязычный кабинет-образец
  и shared/data/treatment_database_350.json (база 350 + README).

### 06_Переводы_на_выверку
- METACOD_перевод_клиники_RU_EN_HE.xlsx — клинические переводы (EN надёжно, HE черновик) — нужна выверка.
