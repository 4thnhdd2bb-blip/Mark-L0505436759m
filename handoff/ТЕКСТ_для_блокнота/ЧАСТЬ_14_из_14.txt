- L3 ИЗБЫТОК метаболический, M-A2: висцеральное ожирение, ИР/HOMA↑, ТГ↑/HDL↓, апноэ; мышца сохранна → ГАСИТЬ (GLP-1/SGLT-2/метформин) + снять driver (CPAP, дефицит энергии). Страховка: беречь мышцу (белок ≥1.2–1.5 + лейцин/HMB + силовые). Кейс: M-A2 архетип ~55м.
- L4 ИЗБЫТОК крови (гипервязкость), M-A2 крови: Hct↑/Hb↑, гель-сдвиг крови, тромбориск → РАЗГЕЛИТЬ (гидратация, омега-3, флеботомия при истинном/симптомном ↑Hct) + убрать драйвер (гипоксия/андрогены/PV). Страховка: ⛔ железо и тоники; не пропустить ОКС/ТЭЛА; вторичный ≠ клональный (JAK2/ЭПО). Кейс: Amir L 23м.
- L5 ФИБРОЗ-КОНСОЛИДАЦИЯ, M-S: рубец/фиброз, PCL-B; часто компенсирован → фармакологический антифиброз (ARNi + АМКР) + пластический пул + рекондиция; НЕ форсировать. Страховка: ВЕТО: энзимный лизис ⛔ при антикоагулянте/ICD; нагрузка дозируется (потолок ЧСС). Кейс: Эфи 73ж.
- L6 ПРИЧИНА⇄ЗАЩИТА (+ иммунная ось), Холод + гель-накопление: отёк/вес как ЗАЩИТА (микседема при гипотиреозе) → убрать ПРИЧИНУ (оптимизировать тиреоид); иммунную ось гасить базисной терапией. Страховка: ⛔ мочегонное на микседему, ⛔ катаболик на Холод-driven вес; при метотрексате обязательный фолат. Кейс: Мири 72ж.
- L7 РИСК ОТКАТА (обратный люк): пациент идёт правильно, но может откатиться — остаточный иммунный Ветер в сердце/почки → завершить эрадикацию + гасить остаточный Ветер + рассосать очаг; ОХРАНЯТЬ ворота Норматонии. Чек-лист ворот: курс завершён · маркёр плато/вниз · моча/АД чисты · нет шума/суставов/сыпи. Кейс: Константин 21м.
- L8 НАПРЯЖЕНИЕ ВЕКТОРОВ (can't-miss гейт), M-D + онко/тромбоз: потеря веса = мальабсорбция (кормить) ИЛИ B-симптом лимфомы (искать) → ГЕЙТ первым: исключить can't-miss; кормить параллельно, кормление не задерживает онкопоиск. Страховка: can't-miss сильнее вектора; онкология — онкологу. Кейс: Пациент-2 67м.

**Статус.** Не указан. **Р-*.** Нет. **Связи.** порог_md (M-D2), гейты can't-miss, Норматония. **Пробелы.** Не упомянуты.

## библиотека_по_мембране (030)

**Суть.** Источник: «METACOD — Библиотека лечения по мембране · ГЛУБОКАЯ v2 (2026-09-14)». Мембрана определена → берётся готовая программа: мишень · препарат из 658 с дозой-ориентиром · биомаркёр-цель · каденс мониторинга · HARD-STOP. Дозы — ОРИЕНТИР, титрация и финал за врачом; недоступность препарата закрывается движком замены (§2K, правило 7).

**Блоки (почти дословно).**

*M-A2-обмен (ожирение / МетС / стеатоз / ИР).* Программа: гиперинсулинемия → mTORC1↑, липогенез↑, аутофагия↓; SREBP/ChREBP-драйв; висцеральная липотоксичность → NF-κB, ИР. Вектор: катаболический разворот → M-A1 → M-0. Подфазы: снять энергопоток · сенситизация к инсулину · удержание веса.
- вес/инкретин: семаглутид 0.25→2.4 мг/нед п/к · тирзепатид 2.5→15 мг/нед (лира/дула — замена);
- глюкоза/кардиоренал: эмпаглифлозин 10–25 мг/сут · дапаглифлозин 10 мг;
- сенситайзер: метформин 500→2000 мг/сут (+ контроль B12);
- стеатоз/МАСГ: резметиром при MASH-фиброзе по показанию; пиоглитазон 15–30 мг осторожно;
- АД: периндоприл/рамиприл или телмисартан/валсартан;
- липиды: розува/аторвастатин по ApoB; ±эзетимиб/PCSK9.
- Добавки: берберин 500 мг ×2–3 · инозитол 2–4 г · омега-3 EPA 2 г; ЗАЩИТА МЫШЦЫ обязательна при GLP-1: белок 1.2–1.6 г/кг, креатин 3–5 г, силовая 2–3×/нед, ±лейцин/HMB.
- Цели: HbA1c <7 (индивидуально) · талия↓ · ТГ <1.7 · ApoB к цели риска · ALT/FIB-4↓ · вес −5→10 % · мышечная масса СОХРАНЕНА.
- Мониторинг: вес/талия ежемесячно · HbA1c и липиды 3 мес · FIB-4/эластография 6–12 мес · фазовый угол и мышца (BIA) 3–6 мес · B12 при метформине.
- HARD-STOP: беречь мышцу — не проскочить в M-D2 (BIA); при FIB-4↑ это уже M-S-компонент; онконастороженность при быстрой потере веса.
- Органы: печень (МАСГ → резметиром/пиоглитазон) · сердце (SGLT-2 + RAAS) · почки (SGLT-2 + финеренон) · поджелудочная (инкретины).

*M-A2-кровь (эритроцитоз / гипервязкость).* ЭПО-драйв или JAK2-клон → ↑Hct → гипервязкость → протромбоз. Вектор: разгелить + убрать драйвер.
- терапевтическая флеботомия до Hct <45 (м) / <42 (ж) — за гематологом;
- драйвер: CPAP при апноэ · отмена андрогенов/ААС · при PV — гидроксимочевина/руксолитиниб (гематолог);
- аспирин 75–100 мг при PV, после оценки ОКС;
- гидратация; омега-3.
- Добавки: гидратация + омега-3 EPA/DHA; ⛔ железо и «тоники». Цели: Hct к норме · ЭПО/JAK2 определены · тропонин норм. Мониторинг: ОАК, симптомы тромбоза.
- HARD-STOP: ⛔ железо / ЭСА · не пропустить ОКС/ТЭЛА · вторичный эритроцитоз → лечить причину, не автофлеботомия.

*M-D1 (умеренный катаболизм / саркопения).* Вектор: анаболический (белок + сила + гормон-корень).
- левотироксин 25–50 мкг → титрация по свТ4 (не по ТТГ вслепую у пожилых);
- тестостерон при лабораторном гипогонадизме — ПОСЛЕ исключения простаты;
- ⛔ отменить SGLT-2 / DPP-4 / петлевые, если сушат ятрогенно;
- белок 1.2–1.5 г/кг · B12 1000 мкг (в/м при мальабсорбции) + фолат · железо после исключения ЖКТ-источника · D3 до 40–50 нг/мл;
- CoQ10 100–200 мг · L-карнитин 1–2 г · креатин 3–5 г · α-липоевая 600 мг · лейцин/HMB.
- Цели: фазовый угол↑ · мышца и сила↑ · ферритин/B12/D в норме · вес стабилизирован. Мониторинг: BIA 3 мес · динамометрия · дефициты. HARD-STOP: не форсировать голод и катаболики; не углубить в M-D2.

*M-D2 (кахексия / тяжёлая саркопения — КРАСНАЯ ЗОНА).* Вектор: ТОЛЬКО нутритивно/анаболически + устранить причину.
- ПРИЧИНА: онко / сепсис / тяжёлая болезнь — искать (гематолог, онколог, инфекционист);
- усиленное энтеральное/парентеральное питание, белок↑, калораж↑; стимуляторы аппетита по показанию;
- анаболизм по показанию за специалистом.
- Добавки: белок 1.2–1.6 г/кг + лейцин/HMB · L-карнитин · омега-3 · B12/фолат · D3; редокс закрывать БЕЗ NAC (глутатион липосомальный, α-липоевая, селенометионин, токоферолы).
- Мониторинг: вес и мышца еженедельно · азотистый баланс.
- HARD-STOP: ⛔ метформин · берберин · SGLT-2 · GLP-1 · NAC — ЗАПРЕЩЕНЫ. ⛔ голод и дефицит калорий. ⛔ агрессивные диеты. Онконастороженность — приоритет.

*M-S (фиброз / склероз).* TGF-β↑ → миофибробласты → коллаген; ПОЛ/ферроптоз. Три столпа: снять драйвер · пластический пул · стоп-ПОЛ/антиферроптоз.
- ИЛФ: нинтеданиб 150 мг ×2 / пирфенидон титрация до 2403 мг/сут;
- HFrEF: ARNi (сакубитрил/валсартан) + спиронолактон/эплеренон;
- склеродермия: ритуксимаб / микофенолат — за ревматологом;
- драйвер-воспаление: гасить неразрешённое Тепло; D3;
- пластический пул: коллаген I+III 15–20 г · глицин 3–5 г · L-пролин 1 г + витамин C 500 ×2 · гиалуроновая 200 мг;
- стоп-ПОЛ: омега-3 EPA/DHA 1–2 г · CoQ10 · таурин;
- энзимный лизис: серрапептаза/бромелайн — ТОЛЬКО без факторов кровоточивости.
- Цели: эластометрия/FIB-4 стабилизация или ↓ · галектин-3↓. Мониторинг: 6–12 мес.
- HARD-STOP: ⛔ энзимы при антикоагулянте / ICD / тяжёлой ХСН; дифференцировать M-S ↔ M-A3 при плотной опухоли.

*M-0 (норматония):* омега-3 + магний + D3; держать, не перелечивать.
*M-A1 (ранний анаболизм):* образ жизни, обычно без лекарств; база омега-3, D3, магний; мониторинг вес/талия/гликемия раз в 6–12 мес; не начинать лекарственное гашение без показаний.
*M-A3 (гиперпролиферация / онко):* онкомаршрут; антипролиферативные ТОЛЬКО за онкологом; can't-miss гейт; глубина лечения = онкопротокол, вне L1-самолечения.

**Порядок применения:** мембрана + подтип → блок · драйвер/фаза/тип люка (атлас 8 типов, два режима) · препараты 658 → доза-ориентир → титрация врачом; нет препарата → движок замены (класс × энергия) · биомаркёр-цели и каденс · HARD-STOP и вето безопасности неотменяемы · вести до M-0; на контроле — индекс груза вниз.

**Статус.** Версия v2 от 2026-09-14; подпись врача не указана; дозы — ориентир, «финал за врачом».
**Р-*.** Нет.
**Связи.** §2K (правило 7, движок замены), база 658, типы_люка (атлас 8 типов), индекс_груза, порог_md.
**Пробелы.** Нет отдельного блока для нейродегенерации (вывод изучающего). Источники не названы отсутствующими.

## индекс_груза (031)

**Суть.** Источник: «METACOD: Долголетие — единая глава (2026-09-14) · L1/research · validated:false». Тезис: старение — накопление НЕЗАВЕРШЁННЫХ фазовых программ («люков»); молодость = способность чисто завершать программы. Механизм петлевой: застрявшая программа тратит ресурс и снижает способность завершать следующие.

**Каналы (холлмарк → незавершённая программа → тип люка).**
- клеточное старение: клетка не делится и не умирает; SASP → ядро гипотезы;
- inflammaging: провал РАЗРЕШЕНИЯ воспаления → неразрешённое Тепло (Эпикризис не закрылся);
- фиброз/жёсткость: рубец вместо регенерации → L5 (PCL-B→Норматония застрял);
- [НЕЙРО-смежное] провал аутофагии/протеостаза: накопление повреждённого белка → застой M-A (накопление) (в ключе нейродегенерация прямо не названа — вывод изучающего);
- метафламмация → L3 избыток M-A2;
- саркопения → L1 истощение (M-D/M-D2);
- онкогенез: клетка завершила НЕВЕРНУЮ программу → L8; Ветер-деление → исход Холод;
- эпигенетический шум → общий корень «потери управления»;
- теломеры: расходуемый счётчик → сенесцентный исход — закрываемый люк.

**Теломерный канал.** Теломера — расходник. Счётчик НЕ удлиняем, теломеразу ⛔ НЕ активируем (онко-вето). Косвенно: закрыть Тепло-inflammaging и M-D-оксидацию (омега-3, CoQ10, α-липоевая, снять СРБ-хронику); убрать программу; убирать сенесцентный исход. Метрика: LTL в динамике.

**Компоненты и шкалы (дословно).**
- фазовый угол PA50 (BIA): ≥6.0 → 0 · 5.0 → 30 · 4.5 → 55 · ≤4.0 → 90.
- мышца/сила (динамометрия): норма → 0 · снижение → 40 · саркопения подтверждена → 80.
- СРБ-хроника: <1 → 0 · 1–3 → 35 · 3–10 → 65 · >10 → 90.
- эластометрия/FIB-4: низкий → 0 · промежуточный → 50 · высокий → 90.
- B12/ферритин/витамин D: все в цели → 0 · один ниже → 35 · два и более → 70.
- LTL перцентиль к возрасту: ≥50-й → 0 · 25–50-й → 40 · <25-го → 80.
- эпигенетический возраст минус паспортный: ≤0 → 0 · +1–3 → 35 · +4–7 → 65 · >7 → 90.
- Расчёт: среднее ДОСТУПНЫХ суб-скоров (0–100); недоступные не подставляются нулём — выводятся в «чего не хватает» с покрытием (сколько из 7). При покрытии <3 — ориентировочный.
- Полосы: <25 низкий (удержание) · 25–50 умеренный (закрывать планово) · 50–75 высокий (закрывать активно) · ≥75 очень высокий (снять смертельные осложнения, остановить накопление).

**Применение:** мембрана → люк (фаза + тип) → груз → режим (течёт → подогнать; завис → разблокировать) → закрыть люк: гейт can't-miss → вето безопасности → снять ❌-двигатель → разблокировать → страховка от переката → контроль.

**Статус.** research-grade, **validated:false**. Охватывает регуляторно-обратимую часть старения, НЕ охватывает необратимое повреждение (теломерный счётчик, соматические мутации, сшивки). Индекс — не диагноз и не прогноз; подавать как рамку для проверки.
**Р-*.** Нет.
**Связи.** типы_люка L1/L3/L5/L8, библиотека_по_мембране, страховка от переката, can't-miss.
**Пробелы.** Индекс выводит «чего не хватает» по недоступным компонентам (LTL, эпивозраст и пр. — требуют внешних анализов). Валидации нет.

## ген_слой (051)

**Суть.** Версия v1.0 · Том IV «Гены и профилактика» + книга «Болезни — гены и НАШЕ лечение» (286 стр.). ## слой_заряда (052)

**Суть.** v1.0 · §2X · внесён 17.09.2026 по указанию врача. Повод — слова врача: «гель и золь это тоже связано с зарядом; катаболика и анаболическое состояние есть и на уровне ядра клетки, и на уровне клетки, и на уровне межклеточного пространства, и органа — ты просто глубоко это дело не изучил». Вердикт: врач прав в главном — золь⇄гель существует на ЧЕТЫРЁХ уровнях, на трёх оператор — ЗАРЯД; слой был построен только на липидном бислое — неполнота. Слой — НАВИГАТОР, НЕ ТЕРАПИЯ.

**Разбор возражения.**
- Врач прав по M2: у AMPK есть мембранная АМФ-независимая платформа: лизосомальный комплекс v-ATPase–Ragulator–AXIN–LKB1 с сенсором глюкозы через альдолазу/ФБФ — та же платформа, что у mTORC1. Утверждение «у M2 моста нет» СНЯТО 17.09.2026.
- Врач не прав в одном шаге: «падение АТФ = падение заряда цитозоля» количественно не обосновано (гидролиз АТФ при физиологическом pH почти нейтрален по заряду; 80–90% АТФ связано с Mg²⁺). Вывод верен, но не через этот шаг.
- Главная ошибка: ЗАРЯД — НЕ ОДНО ЧИСЛО (Vmem мВ, цитозольный pH, энергетический заряд Аткинсона 0–1, FCD матрикса мЭкв/г, ΔΨm). Свести в один показатель = повторить ошибку единого числа MSI, которое врач отменил.

**Четыре уровня (почти дословно).**
1. ЯДРО — заряд гистоновых хвостов. Гель: деацетилирование → конденсация; золь: ацетилирование → хроматин разрыхляется. Доказано in vitro (Gibson, Cell 2019, PMID 31543265; Shogren-Knaak, Science 2006, PMID 16469925; Allahverdi, NAR 2011, PMID 21047799). Метаболизм: ацетил-КоА через ACLY (PMID 19461003); лактилирование (PMID 31645732); β-гидроксибутират как ингибитор HDAC (PMID 23223453 — оспорено, PMID 30679586); НАД⁺/сиртуины. Измерение у человека: нет рутинного. Двигают: вориностат, белиностат, ромидепсин (CTCL); азацитидин, децитабин (МДС, PMID 19230772); таземетостат. Где ломается: заряд НЕ задаёт специфичность; HDAC-ингибиторы меняют 2–5% транскриптома, значительная часть генов ПОДАВЛЯЕТСЯ (Peart, PNAS 2005, PMID 15738394); метилирование ДНК заряд не меняет; 3D-архитектура ортогональна (PMID 28985562, 28525758). Факт: за год отозваны две регистрации HDAC-ингибиторов (ромидепсин при PTCL, панобиностат).
2. КЛЕТКА · ЦИТОЗОЛЬ — АТФ как растворитель, pH. Гель: падение АТФ и закисление → агрегация; золь: высокий АТФ 5–10 мМ. In vitro Patel, Science 2017 (PMID 28522535); дрожжи: pH 7.3→5.8 → «стекло» (Munder, eLife 2016, PMID 27003292). Измерение: ³¹P-МРС исследовательски; рутинного нет. Двигают: нагрузка (единственный надёжный, PMID 12941758); креатин +10–20% PCr (PMID 1327657); бета-аланин; бикарбонат (внеклеточный pH). Ломается: «АТФ как гидротроп» оспорено (Mehringer & Kunz 2021); стеклование у млекопитающих не воспроизведено; при стрессе коллапс полисом РАЗЖИЖАЕТ цитоплазму (Mol Cell 2024, PMID 39059370). Факт: ни одного исследования, где вмешательство у человека измеренно сдвинуло цитозольный pH/заряд в полезную сторону.
3. МЕЖКЛЕТОЧНОЕ ПРОСТРАНСТВО · МАТРИКС — FCD (мЭкв/г). САМЫЙ ТВЁРДЫЙ уровень: FCD хряща 0.10–0.25, пульпозного ядра 0.18–0.28, фиброзного кольца 0.07–0.13 (Maroudas; Nature 1976, PMID 1264261). Измерение: ²³Na-МРТ (7Т, исследовательски); dGEMRIC (PMID 15607880; сократилось из-за гадолиния); T1rho; электропроводность ex vivo. Двигают: гиалуронидаза (адъювант); протамин (антидот гепарина). 4-метилумбеллиферон (PMID 35499083) не зарегистрирован как выключатель. Три ошибки модели: коллаген — соправитель; ПОТЕРЯ ЗАРЯДА ≠ ПОТЕРЯ ВОДЫ (ранний остеоартроз — воды больше); заряд ≠ реология (длина цепи). Факт: ⛔ ФАЗОВЫЙ УГОЛ И БИОИМПЕДАНС НЕ ИЗМЕРЯЮТ ЗАРЯД МАТРИКСА (PMID 36749540).
4. ОРГАН И ТКАНЬ — Vmem и ΔΨm. Гель: гиперполяризация (дифференцировка, покой); золь: деполяризация (пролиферация). Прочно у беспозвоночных/амфибий (PMID 21276941; PMID 17329365); у млекопитающих почти всё in vitro. Измерение: нет рутинного. Двигают: электростимуляция ран, PEMF (доказательства спорны). Ломается: «высокий ΔΨm = здоровые митохондрии» — НЕВЕРНО (АФК, PMID 9369223; деполяризация → PINK1 и митофагия, PMID 20126261); Harris 2021 (PMID 33999994). Факт: IWGDF 2023 — СИЛЬНАЯ рекомендация ПРОТИВ электростимуляции при диабетической стопе (PMID 37232034); ни один ионный канал не валидированная онкомишень.

**Мост M2 снят.** Zhang, Cell Metab 2014 (PMID 25002183); Zhang, Nature 2017; Zong, Cell Research 2019 (PMID 30948787); Schmitt, Nat Commun 2022. M1 и M2 — две стороны одной мембраны. Оговорка: модель почти целиком из одной лаборатории (Lin S-C / Zhang C-S), к Li 2019 эрратум; считать твёрдо установленным нельзя, но и «моста нет» говорить нельзя. Статус: ВНЕ ИСТОЧНИКОВ ВРАЧА, по литературе, ждёт подписи.

## 4. ПАРКИНСОН И СИНУКЛЕИНОПАТИИ

Источник: `K/084 слой_паркинсона`, разделы 1–3 разобраны 21.09.2026. «Болезнь Паркинсона ведёт НЕВРОЛОГ: леводопа, агонисты, DBS — его подпись… Наш слой стоит рядом, а не вместо.»

### 4.1 Три конфликта (распоряжение врача «Чини три конфликта и RBD поднимай во флаг»)
1. **Белок × леводопа (LAT1).** `GUARD_LEVODOPA_PROTEIN`: «препарат за 30 мин до еды или через 60 мин после, основной белок — на вечер, клетчатка и кисломолочное не в один приём с препаратом». Белок не убирается — переносится. Механизм `снимаетДобавленные` (одна защита отменяет совет другой, отменённое — отдельным списком).
2. **Якорь при денервированном сердце.** `anchorТрактовкаСнята()`: при синуклеинопатии (БП, ДТЛ, МСА) Q=ЧСС/ЧД не трактуется автоматически. «Своего порога для денервированного сердца у движка нет. Выдуманный порог был бы хуже молчания.»
3. **B6 и железо.** B6 на «чистой» леводопе снижает эффект; потолок ~50 мг/сут. Железо: «ни давать без ферритина, ни выводить самодеятельно» (FAIRPARK-II: деферипрон ухудшил течение). Йохимбе — противопоказан при синуклеинопатии.

### 4.2 Часть 3 — внесено 21.09 («Вноси всё»)
- **Мукуна = леводопа**: только кабинет, подпись невролога; противопоказания — иМАО-Б (включая разагилин и сафинамид), леводопа, беременность, ССЗ-риск.
- **EGCG**: блокирует периферическую ДОФА-декарбоксилазу; печень под контролем.
- **B6 (P-5-P)** 20–25 мг, потолок 50 мг; нельзя на леводопе без ингибитора декарбоксилазы и на мукуне.
- **Цитиколин** взят; **альфа-GPC НЕ взят** («сигнал по инсульту в десятилетнем наблюдении и работа по атеросклерозу», список НЕ_БЕРЁМ, Р-ПАРК-15). Там же НЕ_БЕРЁМ: ГАМК внутрь, ФМТ вне исследований.
- Ферритин: цель 50–100, «одним числом на весь движок».
- Сенсорный блок: вибрация 30–40 Гц под стопы 20–30 мин + утяжелённое одеяло 7 % массы тела; «как СОН И КОМФОРТ, не как лечение»; восемь ворот.

### 4.3 Одеяло при RBD — **ПОДПИСАНО 21.09.2026**
«Б, пробно облегчённо»: 5 % массы тела, только бёдра и ноги, дышащая ткань, сосед предупреждён, проба 2 недели; стоп — участились эпизоды / не может выбраться / утром труднее вставать. Жёсткий запрет остаётся при апноэ, ортостатической гипотензии, невозможности снять одеяло самому, возрасте до 18 лет. Общее правило: «Запрет, который держится на механическом рассуждении без данных, записывается как ВОПРОС ВРАЧУ».

### 4.4 Кишечный блок
Уходят продуценты бутирата, приходят Akkermansia, E. faecalis (тирозиндекарбоксилаза разлагает леводопу до всасывания, карбидопа не блокирует), Escherichia/Shigella, Desulfovibrio. H. pylori ухудшает ответ, эрадикация улучшает. Пять ступеней: убрать мешающее → вода и ритм → кормить своих → заселять → держать. Клетчатка не раньше лечения СИБР; живые пробиотики нельзя при иммуносупрессии/химиотерапии/нейтропении/ЦВК.

### 4.5 Запреты
- `K/084 .⛔запрещённые_препараты_при_БП`: метоклопрамид, прохлорперазин, галоперидол, типичные нейролептики; из противорвотных — домперидон. Внесение в жёсткий список — Р-ПАРК-3 (открыт).
- `K/087`: галоперидол получил запрет «при синуклеинопатии только кветиапин и клозапин» (Р-ГЕЛЬЗОЛЬ-26 **подписан** 22.09).
- Активаторы (родиола, N-ацетил-тирозин, мукуна, йохимбе) закрыты при клинче Ветер⇄Сухость.

### 4.6 Энергии, мембрана, эталон разбора (обезличенный, мужчина ~70 лет)
- Мембрана двухуровнево: система M-D; нейрон нигры M-S (агрегация α-синуклеина как застрявшая программа очистки) + M-D; мышца/фасция — гель-ригидность.
- Энергии: ВЕТЕР ведущая, СУХОСТЬ, ХОЛОД; клинч Ветер⇄Сухость — гасить обе.
- «Затвор закрыт Холодом на уровне мышцы и оси — и одновременно… ОТКРЫТ Теплом на уровне кишечной стенки… Уровни тянут в разные стороны, и это норма для синуклеинопатии».

- Мембрана и полюс для кишки и болезни **не назначены**: пустые слоты, Р-ПАРК-4 и Р-ПАРК-11.

### 4.7 Паркинсон в единой базе (`metacod_base_415.json`)

### 2.0. Что это за пакет (00_README)

«Текущий исследовательский пакет, собранный из разработанной в чате архитектуры». Даты, автора и подписи в пакете нет. Файлы датированы 29.09. Объём крошечный: 0,6–1,1 КБ на файл. Это тезисный каркас, а не доктрина.

Статус по самому README:

Основной маршрут: Environment → Input → Barrier → Transport → Tissue → Cell/Membrane → Energy/Information → Function → Repair → Structure → Observable phenotype → Root/Causal Graph → Treatment Optimizer → Response → Digital Twin.

### 2.1. Universal Human Model / UHE

- **Координаты:** Matter, Quality, physical Energy, Information, Space, Boundary, Organization, Control, Network, Time, Mode, Life Stage. Модель записана как H(t) = F[M,Q,E,I,S,B,O,C,N | Mode, Life Stage].
- **Health Vector:** Reserve, Flexibility, Recovery, Precision, Efficiency, Switchability.
- **Принцип:** здоровье — это способность держать функцию при меняющейся нагрузке, переключаться, восстанавливаться, ремонтировать и сохранять резерв «без чрезмерной цены компенсации».

### 2.2. MOM-8 Spatial Model

- **Три оси:** X (лево–право), Y (низ–верх), Z (перед–зад).

  2. верх-перед-право: Ветер;

- **Формула:** Tissue State = f(тип клетки, ECM, перфузия, иннервация, метаболизм, механическая нагрузка, повреждение, репарация, время).
- **Сенсор должен соответствовать глубине ткани:**
  - камера — поверхность и движение;
  - BIA/BIVA — интегральный электрический фенотип;
  - US/DXA/CT/MRI — глубокая структура;
  - лаборатория — системный молекулярный слой.

### 2.5. Membrane / Cell / ECM

- **Цикл:** Boundary → Gradient → Flow → Transformation → Work → Waste → Repair → Information.
- **Мембрана:** целостность, текучесть, проницаемость и селективность, транспортёры, рецепторы, потенциал, механическое сцепление.
- **Cellular Root skeleton** (около 20 узлов): от целостности мембраны до ETC/ATP, протеостаза, аутофагии, ДНК, клеточного цикла, апоптоза и сенесценции.
- **Петля ECM ↔ клетка:** ECM → интегрины → цитоскелет → ядро, и обратно через синтез и деградацию матрикса.
- **ST-1..ST-6** сохранены как «higher-order METACOD membrane/tissue phenotypes». В итоге они должны определяться векторами измерений, а не ярлыками.

### 2.6. Root Graph / Causal Network Engine

- **Классы корня:** ROOT-O (origin), ROOT-M (maintenance), ROOT-L (limiting), ROOT-R (recovery-limiting), ROOT-A (amplifier). Защитные узлы моделируются отдельно.
- **Связи:** A→B, A←B, A↔B, A←C→B (общая причина), A~B (только ассоциация).
- **Причинная уверенность складывается из 10 критериев:** временной порядок, механизм, доза–ответ, ответ на вмешательство, обратимость, репликация, внешние данные, конфаундинг, альтернативы, неопределённость измерения.
- **Therapeutic Cut Point:** модифицируемый узел или ребро, разрыв которого прерывает патологическую петлю с наибольшей пользой при приемлемом риске.
- **Diagnostic Optimizer:** следующий вопрос или тест выбирается по ожидаемому приросту информации, клинической важности и действенности относительно цены, риска и нагрузки.

### 2.7. Treatment Response

- **Запись лечения:** TARGET → OPERATOR → MECHANISM → DOSE → TIME → EXPECTED RESPONSE → MEASUREMENT → SAFETY → STOP/ADJUST.
- **13 операторов:** ADD, REMOVE, INCREASE, DECREASE, OPEN, PROTECT/CLOSE, REDISTRIBUTE, RESTORE, RETRAIN, REPAIR, REPLACE, SUPPRESS/BLOCK, BUILD RESERVE.
- **Последовательность:** STABILIZE → CORRECT → RESTORE → TRAIN → OPTIMIZE.
- **Уровни ответа:** R1 субъективный, R2 функциональный, R3 физиологический, R4 биохимический, R5 структурный, R6 резерв и восстановление под нагрузкой.
- **Критерий успеха:** симптомы + функция + корневой процесс + резерв + приемлемая безопасность.

### 2.8. Visual Health / Resilience / Digital Twin

- Камера — структурный и динамический сенсор, «не автономный диагностический инструмент».
- **Visible State Vector:** геометрия, объём, симметрия, кожа, движение, осанка, траектория кажущегося возраста, внешние фенотипы отёка, жира и мышц.
- **Resilience Test:** база → стандартизованная безопасная нагрузка → ответ → восстановление → адаптация. Выходы: кривые ответа и восстановления, наклон утомления, асимметрия под нагрузкой, отклонение от личной базы.
- **Каденс:**
  - ежедневно: лицо, PPG, дыхание, симптомы;
  - еженедельно: функциональная нагрузка;
  - ежемесячно: морфология и BIA/BIVA;
  - периодически: анализы и визуализация.
- **Digital Twin:** predict → intervene → measure → compare → update. Главное сравнение — «сам с собой» во времени.

### 2.9. Evidence / Safety / Research Layers

- **Уровни доказательности:** E1 Established, E2 Emerging, E3 Exploratory, E4 Traditional/model.
- **Параллельные карты:**
  1. биомедицинская;
  2. физическая;
  3. Park/MOM-8 (пространство и Energy-K);
  4. **GNM — «claimed tissue/brain/phase/conflict mappings, stored separately»**.
- **Иерархия безопасности:** Red flags → биомедицинский дифференциал → ткань/UDS → подтверждение → исследовательская энергетическая интерпретация.
- **Запрет:** не выводить болезнь напрямую из красоты, формы тела, сектора MOM-8, энергии Park или карты GNM. Эти слои только порождают гипотезы.

### 2.10. Product Pipeline

- **Входы:** Symptom-first, Image-first, Data-first, Change-first.
- **Конвейер:** Observation → Safety gate → сравнение с личной базой → пространственная локализация → кандидаты-ткани → кандидаты UDS → фазовый вектор → альтернативные причинные графы → различающий вопрос или тест → клиническая верификация → Root-O/M/L/R/A → Therapeutic cut point → лечение с доказательностью и безопасностью → каскад ответа → обновление Digital Twin → мониторинг.
- **Следующий модуль:** Diagnostic Information Engine + Adaptive Intake. Каждый следующий вопрос выбирается так, чтобы максимально снизить неопределённость между оставшимися причинными моделями.

### 2.11. UMM schema draft (JSON)

- `version: "UMM-v2-draft"`.
- 21 поле события: patient_id, timestamp, mode, life_stage, space, depth, tissue, uds, phase, membrane_state, root_origin / maintenance / limiting / recovery / amplifier, reserve, energy_k, evidence_level, intervention, response, confidence.
- `evidence_levels` E1–E4.
- `safety_priority`: red_flags → biomedical_differential → verification → exploratory_layers.
